## 1. 쇼핑렌즈는 어떤 프로그램인가요

쇼핑렌즈는 쇼핑 쇼츠를 만들기 위한 윈도우 전용 프로그램입니다.
트렌드 영상과 원본 영상을 찾고, 대본을 만들고, 음성을 만들고, 장면을 맞춘 뒤 최종 영상을 내보내는 흐름으로 사용합니다.
작업이 길기 때문에 프로젝트를 저장하면서 진행하는 것이 중요합니다.

쇼핑렌즈의 기본 흐름은 다음과 같습니다.
1. 트렌드에서 요즘 반응이 좋은 쇼핑 영상을 확인합니다.
2. 제품찾기에서 원본 후보 영상을 찾습니다.
3. 작업실에서 프로젝트를 만들고 영상 준비에서 영상을 모으고 분석합니다.
4. 대본에서 대본을 만들고 음성을 생성합니다.
5. 장면 구성에서 음성 길이에 맞춰 장면을 배치합니다.
6. 자막 정리에서 원본 자막을 정리합니다.
7. 최종편집에서 자막과 효과음을 더해 영상을 내보냅니다.
8. 업로드 문구와 쿠팡 제품 링크를 준비합니다.

여기서 중요한 점은 음성이 장면보다 먼저라는 것입니다.
음성 길이가 정해져야 장면을 그 길이에 맞출 수 있기 때문에, 대본을 만든 직후에는 장면이 비어 있고 음성을 만든 뒤에 장면이 채워집니다.
처음 사용하는 사용자는 트렌드를 먼저 보고 작업실로 이동하는 흐름이 가장 쉽고, 이미 사용할 영상이 있다면 바로 작업실의 1. 영상 준비부터 시작해도 됩니다.


## 2. 화면 전체 구조

왼쪽에는 큰 메뉴가 있습니다.
트렌드, 작업실, 프로젝트, 도구, 설정이 보입니다.
프로그램을 처음 켜면 트렌드 화면으로 시작합니다.

트렌드는 쇼핑 영상 아이디어와 원본 후보를 찾는 곳입니다.
작업실은 실제 쇼츠를 만드는 곳입니다.
프로젝트는 저장해둔 작업을 다시 여는 곳입니다.

도구는 자막 지우개처럼 별도로 사용할 수 있는 기능을 모아둔 곳입니다.
설정은 인증키와 제미나이 키, 음성 서비스 키, 유튜브 검색 키를 등록하는 곳입니다.
왼쪽 아래에는 버전 표시와 챗봇 문의 버튼이 있고, 버전 표시를 누르면 업데이트를 확인할 수 있습니다.

작업실 안에는 위쪽에 번호가 매겨진 단계 탭이 있고, 화면에는 1. 영상 준비, 2. 대본, 3. 장면 구성, 4. 자막 정리, 5. 최종편집, 6. 업로드 문구, 7. 쿠팡 제품 찾기로 표시됩니다.
왼쪽에서 오른쪽으로 차례대로 진행하면 됩니다.


## 3. 처음 실행할 때 인증키 입력

쇼핑렌즈는 처음 실행할 때 인증키가 필요합니다.
인증키가 없으면 프로그램을 계속 사용할 수 없습니다.
인증키 입력 화면이 나오면 가지고 있는 인증키를 입력하고 확인을 누릅니다.

인증키가 없으면 인증키 발급받기 버튼을 눌러 발급 안내를 확인합니다.
인증키를 입력하지 않고 확인을 누르면 인증키를 입력해달라는 안내가 나옵니다.
인터넷 연결이 불안정하면 서버에 접속할 수 없다는 안내가 나올 수 있습니다.

인증이 성공하면 인증 성공 화면이 나옵니다.
이 화면에는 인증키, 만료일, 남은 기간이 표시됩니다.
확인을 누르면 쇼핑렌즈 메인 화면으로 이동합니다.

인증키는 한 개당 한 대의 컴퓨터에서만 사용할 수 있습니다.
맥에서 가상 윈도우로 사용하면 컴퓨터 정보가 매번 바뀌어 인증이 풀릴 수 있으니 윈도우에서 사용해야 합니다.
프로그램 제목 줄에는 만료일과 남은 기간이 표시되고, 영구 사용이면 영구 라이센스로 표시됩니다.


## 4. 인증 관련 문제 해결

인증키를 입력해주세요라는 안내가 나오면 인증키 칸이 비어 있는 상태입니다.
공백이 들어가지 않게 인증키를 다시 붙여넣고 확인을 누릅니다.
복사할 때 앞뒤에 빈칸이 들어가면 실패할 수 있습니다.

인터넷 연결을 확인해주세요라는 안내가 나오면 쇼핑렌즈가 인증 서버에 접속하지 못한 상태입니다.
와이파이나 인터넷 연결을 먼저 확인합니다.
회사나 공용망에서는 접속이 막힐 수 있으니 다른 인터넷으로도 확인합니다.

라이센스가 만료되었습니다라는 안내가 나오면 사용 기간이 끝난 상태입니다.
이 경우 만료 안내 창이 뜨고 1분 뒤 프로그램이 자동으로 닫히며, 확인을 누르지 않아도 닫힙니다.
계속 사용하려면 설정의 인증키 관리에서 새 인증키로 재설정해야 합니다.

이 라이센스는 다른 컴퓨터에서 사용 중입니다라는 안내가 나오면 같은 인증키를 다른 컴퓨터가 이미 쓰고 있는 상태입니다.
인증키는 한 대의 컴퓨터에서만 사용할 수 있습니다.
이미 무료 인증키를 사용하신 사용자입니다라는 안내가 나오면 무료 인증키를 이미 한 번 쓴 상태이며, 무료 인증키는 한 번만 사용할 수 있습니다.


## 5. 설정 먼저 확인하기

처음 사용할 때는 설정에서 필요한 키를 먼저 등록해야 합니다.
대본, 분석, 음성, 검색 기능은 각각 필요한 키가 없으면 중간에 멈출 수 있습니다.
특히 영상 분석과 대본 생성은 제미나이 키가 필요합니다.

설정 화면 맨 위에는 인증키 관리가 있습니다.
현재 인증키, 만료일, 남은 기간을 확인할 수 있습니다.
인증키를 바꾸려면 인증키 재설정을 누르고 새 인증키를 입력합니다.

설정 화면에는 Gemini API 관리라는 제목이 보입니다.
사용자는 이곳을 제미나이 키를 넣는 곳이라고 이해하면 됩니다.
API 모드는 구글 AI 스튜디오의 Gemini API 키와 Vertex AI Json 등록 두 가지 중에서 고를 수 있습니다.

구글 AI 스튜디오 방식은 무료로 발급받는 키를 입력하고 추가를 누르는 방식입니다.
여러 개의 제미나이 키를 등록해두면 한 키가 사용량에 걸렸을 때 다음 키를 사용할 수 있습니다.
다만 무료 제미나이 키는 구글에서 후순위로 처리되어 과부하가 자주 올 수 있고 하루 할당량이 적은 편이니 참고합니다.

관리 버튼을 누르면 등록된 키의 상태와 사용 여부를 확인할 수 있습니다.
전체 확인을 누르면 여러 키가 정상인지 한 번에 확인하며, 상태는 사용 가능, 한도 초과, 오류로 표시됩니다.
각 키 옆의 사용 버튼으로 지금 쓸 키를 정하고, 삭제 버튼으로 키를 뺄 수 있습니다.

Vertex AI Json 방식은 제공받은 300달러 무료 크레딧을 쓰는 방식으로, 서비스 계정 파일을 등록하는 방식입니다.
화면에는 파일을 드래그하거나 클릭해서 선택하라는 영역이 보이고, 파일을 등록하면 프로젝트 ID가 자동으로 표시됩니다.
Vertex 방식에서는 API 테스트 버튼이 보이며, 누르면 실제로 강아지 그림을 만들어 키가 정상인지 확인할 수 있습니다.

ElevenLabs 영역은 ElevenLabs 음성을 쓰기 위한 키를 넣는 곳입니다.
키를 입력한 뒤 저장 버튼을 누르고, 눈 모양 버튼을 누르면 입력한 키를 보거나 숨길 수 있습니다.
Typecast 영역은 타입캐스트 음성을 쓰기 위한 키를 넣는 곳이며, 같은 방식으로 입력하고 저장합니다.

유튜브 키 관리 영역은 키워드 검색과 댓글 보기에 사용됩니다.
트렌드와 제품찾기의 키워드 검색, 유튜브 영상 확인 기능을 쓰려면 유튜브 검색 키가 필요합니다.
키를 여러 개 넣어두면 사용량이 끝난 키를 건너뛰고 다른 키를 사용할 수 있으며, 유튜브 키는 AIza로 시작합니다.

설정 저장 방식은 항목마다 조금 다릅니다.
제미나이 키 추가와 Vertex 파일 등록, 모드 변경은 누르는 즉시 저장됩니다.
ElevenLabs와 Typecast 키는 저장 버튼을 눌러야 저장됩니다.


## 6. 설정에서 자주 나오는 문제

제미나이 키가 설정되지 않았습니다라는 안내가 나오면 설정에 제미나이 키가 등록되지 않은 상태입니다.
설정으로 이동해서 제미나이 키를 등록한 뒤 다시 시도합니다.
키를 등록했는데도 계속 나오면 관리 버튼에서 해당 키가 사용 중인지 확인합니다.

유튜브 키가 등록되지 않았습니다라는 안내가 나오면 키워드 검색에 필요한 유튜브 검색 키가 없는 상태입니다.
설정의 유튜브 키 관리 영역에서 키를 추가합니다.
추가한 뒤에도 안 되면 전체 확인으로 상태를 확인합니다.

서비스 계정 JSON 파일이 아닙니다라는 안내가 나오면 Vertex AI Json 영역에 맞지 않는 파일을 넣은 상태입니다.
서비스 계정에서 새 키 만들기로 받은 파일을 등록해야 합니다.
다른 형식의 파일이나 잘못 저장한 파일은 등록되지 않습니다.

JSON 파일을 읽을 수 없습니다라는 안내가 나오면 파일이 깨졌거나 프로그램이 파일 내용을 읽지 못한 상태입니다.
파일을 다시 내려받아 등록합니다.
파일 이름을 바꾸는 것은 괜찮지만 파일 내용은 수정하지 않는 것이 좋습니다.

무료 API 감지라는 안내가 나오면 등록한 키가 무료 키일 가능성이 높다는 뜻입니다.
이미지나 영상 생성에서 막힐 수 있으니, 결제와 연결된 계정의 프로젝트와 키의 프로젝트가 같은지 확인합니다.


## 7. 프로젝트 이름과 저장

작업실에서는 먼저 프로젝트 이름을 입력하고 저장하는 것이 좋습니다.
프로젝트가 저장되어야 분석 결과, 음성, 장면 구성, 최종편집 결과가 안정적으로 연결됩니다.
저장하지 않은 상태에서 일부 기능을 누르면 프로젝트를 먼저 저장하라는 안내가 나옵니다.

작업실 위쪽에는 프로젝트 이름 입력 칸이 있습니다.
처음에는 제목을 먼저 입력하고 저장을 눌러달라는 안내가 보입니다.
제목을 입력한 뒤 저장 버튼을 누르면 현재 프로젝트가 만들어집니다.

저장한 뒤에는 프로젝트 이름 칸이 고정됩니다.
새 프로젝트를 만들고 싶으면 플러스 모양 버튼을 누릅니다.
새 프로젝트를 생성하겠습니까라는 안내가 나오면 확인한 뒤 새 작업을 시작합니다.

같은 이름의 프로젝트가 이미 있다는 안내가 나오면 이름을 조금 다르게 바꾸고 저장합니다.
프로젝트 이름을 줄여달라는 안내가 나오면 이름이 너무 긴 상태입니다.
너무 긴 이름을 쓰면 저장 경로가 길어져 내보내기에서 문제가 날 수 있으니 짧고 구분되는 이름이 좋습니다.


## 8. 트렌드 화면 전체

트렌드 화면은 쇼핑 영상 아이디어를 찾는 첫 화면입니다.
위쪽에는 쇼핑 트렌드와 제품찾기 선택이 있습니다.
쇼핑 트렌드는 인기 쇼핑 쇼츠를 보는 곳이고, 제품찾기는 원본 후보 영상을 찾는 곳입니다.

쇼핑 트렌드 안에는 오늘의 트렌드, 키워드 검색, 즐겨찾기가 있습니다.
오늘의 트렌드는 이미 정리된 인기 쇼핑 쇼츠를 빠르게 보는 곳입니다.
키워드 검색은 사용자가 직접 제품명이나 키워드를 넣어 찾는 곳입니다.

즐겨찾기는 영상 카드에서 별 표시를 눌러 저장한 영상을 모아보는 곳입니다.
나중에 참고하고 싶은 영상은 바로 별 표시를 눌러두는 것이 좋습니다.
즐겨찾기한 영상이 없으면 즐겨찾기한 영상이 없다는 안내가 나옵니다.


## 9. 오늘의 트렌드 사용법

오늘의 트렌드는 쇼핑 트렌드 TOP 100을 어제, 주간, 월간 기준으로 보여줍니다.
어제는 최근 갑자기 반응이 오른 쇼츠를 빠르게 볼 때 좋습니다.
주간과 월간은 조금 더 안정적으로 반응이 이어지는 아이디어를 찾을 때 좋습니다.

이 목록은 사용자가 직접 모으는 것이 아니라 쇼핑렌즈가 미리 모아둔 인기 영상을 내려받아 보여주는 것입니다.
그래서 인터넷이 연결되어 있어야 보이며, 화면 위에는 마지막으로 갱신된 시각이 표시됩니다.
갱신 버튼은 새 데이터가 들어왔을 때만 켜지고, 새 데이터가 없으면 회색으로 비활성 상태인데 이건 정상입니다.

어제, 주간, 월간 버튼을 누르면 해당 기간의 결과가 바뀝니다.
참고로 이름은 오늘의 트렌드이지만 기본으로 보이는 기준은 어제입니다.
결과내 검색 칸은 지금 화면에 떠 있는 결과 안에서만 다시 좁혀보는 기능이며, 새로 찾아오는 검색이 아니라는 점에서 키워드 검색과 다릅니다.

영상 카드에는 순위, 썸네일, 조회수, 영상 길이, 제목, 채널 이름과 구독자 수, 제품찾기 버튼, 별 표시가 보입니다.
순위 1위부터 10위까지는 눈에 띄게 강조됩니다.
마음에 드는 영상은 별 표시를 눌러 즐겨찾기에 넣고, 채널 이름을 누르면 그 채널 페이지가 열립니다.

썸네일을 누르면 화면 안에서 영상이 바로 재생됩니다.
재생 화면에서는 재생과 멈춤, 시간 이동, 배속 선택이 있으며 배속은 0.75배부터 2배까지 고를 수 있습니다.
영상 위에서 마우스 휠을 굴리면 소리 크기가 조절되고, 스페이스바로 재생과 멈춤, ESC로 닫기를 할 수 있습니다.

재생 화면 오른쪽에는 조회수, 좋아요, 댓글 수가 표시됩니다.
댓글 칸을 누르면 댓글 목록으로 바뀌며 좋아요 많은순과 최신순으로 정렬할 수 있습니다.
댓글 보기에는 유튜브 키가 필요하며, 댓글을 볼 수 없는 영상이거나 유튜브 키를 확인해야 한다는 안내가 나오면 설정에서 유튜브 키를 확인합니다.

재생 화면에는 제품찾기, 스타일 분석, AI분석, 즐겨찾기 버튼이 있습니다.
AI분석을 누르면 그 영상을 분석해 제품 정보 및 특징, 원본찾기와 추천 검색어, 영상 흐름, 떡상 요인, 후킹 방식, CTA 방식을 정리해 줍니다.
추천 검색어를 누르면 유튜브, 틱톡, 인스타, 샤오홍슈, 도우인 중 한 곳을 골라 그 검색 페이지를 바로 열 수 있습니다.

스타일 분석을 누르면 그 영상의 말투와 구성, 연출을 분석해 대본 단계에서 참고할 자료로 저장해 둡니다.
반응이 좋은 영상을 스타일 분석으로 여러 개 모아두면, 나중에 대본을 만들 때 그 결을 따라 만들어 줍니다.
AI분석과 스타일 분석은 모두 설정에 제미나이 키가 있어야 동작합니다.


## 10. 키워드 검색 사용법

키워드 검색은 사용자가 원하는 제품명이나 키워드로 쇼핑 쇼츠를 찾는 곳입니다.
이미 찾고 싶은 상품이 있을 때 사용하면 좋습니다.
유튜브 쇼츠 주소를 넣으면 해당 영상 정보를 확인하는 용도로도 사용할 수 있습니다.

찾고 싶은 제품, 키워드 또는 유튜브 주소 입력 칸에 검색어를 넣습니다.
어제, 주간, 월간 중 원하는 기간을 고릅니다.
검색 버튼을 누르면 결과를 찾기 시작합니다.

검색 중에는 검색 버튼이 중지 버튼으로 바뀝니다.
검색이 오래 걸리거나 잘못 입력한 것을 알았다면 중지를 누릅니다.
중지하면 검색이 중지되었다는 안내가 나옵니다.

검색할 키워드를 입력해 주세요라는 안내가 나오면 입력 칸이 비어 있는 상태입니다.
검색어를 넣고 다시 검색합니다.
너무 넓은 단어보다 제품명, 상황, 사용 목적이 들어간 검색어가 좋습니다.

유튜브 영상 주소를 확인하지 못했습니다라는 안내가 나오면 주소 형식이 맞지 않는 상태입니다.
일반 영상 주소, 짧은 공유 주소, 쇼츠 주소 중 하나를 다시 붙여넣습니다.
비공개 영상이나 삭제된 영상은 정보를 찾지 못할 수 있습니다.

유튜브 키가 등록되지 않았습니다라는 안내가 나오면 설정에서 유튜브 검색 키를 먼저 넣어야 합니다.
사용 가능한 유튜브 키가 없다는 안내가 나오면 등록된 키가 막혔거나 사용량이 끝난 상태일 수 있습니다.
설정에서 키 상태를 확인하거나 다른 키를 추가합니다.


## 11. 제품찾기 화면 전체

제품찾기는 원본 영상 찾기 화면입니다.
쇼핑 쇼츠에 쓸 수 있는 유튜브, 틱톡, 인스타, 샤오홍슈, 도우인 후보 영상을 찾는 데 사용합니다.
이미지, 영상, 링크, 검색어를 단서로 사용할 수 있습니다.

상단에는 오늘 남은 검색 횟수가 표시됩니다.
검색 횟수가 모두 끝나면 그날은 더 검색할 수 없으며 오늘 검색 완료로 표시됩니다.
남은 횟수가 보이지 않으면 검색 횟수를 확인하는 중이거나 인증 상태 확인이 필요한 상황일 수 있습니다.

왼쪽에는 이미지나 영상을 넣는 영역이 있습니다.
제품 사진이나 참고 영상을 넣으면 프로그램이 그것을 보고 검색어를 만들어 바로 검색까지 진행합니다.
파일은 끌어다 놓거나 클릭해서 선택할 수 있으며, 사진이나 영상 분석에는 제미나이 키가 필요합니다.

링크 입력 칸에는 유튜브, 틱톡, 인스타, 도우인, 샤오홍슈 링크를 붙여넣을 수 있습니다.
유튜브 링크는 바로 분석하고, 다른 링크는 먼저 영상을 저장한 뒤 분석합니다.
링크를 넣고 엔터를 치면 그 영상에서 검색어를 뽑아 자동으로 검색합니다.

영어 검색어 칸은 틱톡, 인스타, 유튜브 쪽 검색에 쓰입니다.
중국어 검색어 칸은 도우인, 샤오홍슈 쪽 검색에 쓰입니다.
찾고 싶은 플랫폼에 맞는 칸에 검색어를 넣으면 됩니다.

검색어 칸 아래에는 추천 검색어 단추가 나옵니다.
누르면 그 단어가 검색 칸에 채워지고, 우클릭하면 유튜브, 틱톡, 인스타, 샤오홍슈, 도우인 검색 페이지를 바로 열 수 있습니다.
플랫폼 선택에는 전체와 각 플랫폼 단추가 있고, 검색 전에는 어디서 찾을지 고르는 용도, 검색 후에는 결과를 거르는 용도로 바뀝니다.


## 12. 제품찾기 결과 사용법

검색을 시작하면 원본 영상 후보를 찾고 있다는 안내가 나옵니다.
유튜브, 틱톡, 인스타, 샤오홍슈, 도우인을 확인 중이라는 안내가 보이면 여러 곳을 순서대로 확인하는 중입니다.
결과가 나오기까지 시간이 걸릴 수 있습니다.

결과 카드에서는 썸네일, 영상 길이, 제목, 출처, 열기, 추가 버튼을 확인합니다.
썸네일을 누르면 카드 안에서 영상이 재생되고, 재생 중 영상 위에서 마우스 휠을 굴리면 소리가 조절됩니다.
열기를 누르면 그 영상의 원본 페이지가 열리고, 추가를 누르면 아래 보관함에 들어갑니다.

오른쪽에는 추가영상 개수가 표시되며 최대 8개까지 담을 수 있습니다.
필요 없는 후보는 삭제하고, 쓸 영상만 남긴 뒤 영상 준비로 이동을 누릅니다.
영상 준비로 이동을 누르면 선택한 영상이 작업실의 1. 영상 준비로 넘어가면서 자동으로 내려받아 추가됩니다.

아직 저장한 프로젝트가 없으면 영상 준비로 이동을 누를 때 프로젝트 이름을 먼저 묻는 창이 뜹니다.
영상은 프로젝트 안에 저장되기 때문에 이름을 정해 만들어야 이어갈 수 있습니다.
같은 검색어로 다시 검색하면 새로 찾지 않고 지난번 저장본을 그대로 보여주므로, 새 결과를 원하면 검색어를 바꿔야 합니다.


## 13. 제품찾기 문제 해결

영어 또는 중국어 검색어를 입력하거나 이미지나 영상을 선택해 달라는 안내가 나오면 검색 단서가 없는 상태입니다.
검색어를 넣거나 파일을 하나 선택한 뒤 다시 검색합니다.
제품 사진이 있으면 사진을 넣는 것이 가장 이해하기 쉽습니다.

검색할 플랫폼을 하나 이상 선택해 주세요라는 안내가 나오면 모든 플랫폼 선택이 꺼진 상태입니다.
전체를 누르거나 원하는 플랫폼을 하나 이상 선택합니다.
플랫폼을 너무 많이 선택하면 시간이 더 걸릴 수 있습니다.

이미지나 영상 분석을 하려면 제미나이 키가 필요하다는 안내가 나오면 설정에 제미나이 키가 없는 상태입니다.
설정에서 제미나이 키를 등록한 뒤 다시 시도합니다.
키가 있는데도 안 되면 관리에서 그 키가 사용 중인지 확인합니다.

오늘 원본 영상 찾기 검색 가능 횟수를 모두 사용했습니다라는 안내가 나오면 당일 검색 횟수를 다 쓴 상태입니다.
다음 날 다시 시도하거나 꼭 필요한 검색어만 남겨 검색합니다.
같은 검색어를 여러 번 반복해서 누르지 않는 것이 좋습니다.

링크에서 검색어를 찾지 못했습니다라는 안내가 나오면 붙여넣은 링크만으로 제품 단서를 뽑지 못한 상태입니다.
이미지나 영상을 직접 넣어 다시 시도합니다.
가능하면 제품이 잘 보이는 사진이나 짧은 영상을 넣습니다.

링크 영상을 저장하지 못했습니다라는 안내가 나오면 링크 영상이 공개 상태가 아니거나 내려받을 수 없는 상태일 수 있습니다.
브라우저에서 링크가 열리는지 먼저 확인합니다.
열리지 않거나 로그인이 필요한 영상이면 다른 링크를 사용합니다.


## 14. 작업실 전체 흐름

작업실은 쇼핑 쇼츠를 실제로 만드는 핵심 공간입니다.
위에서 아래로 순서대로 진행하면 가장 안정적입니다.
각 단계는 앞 단계의 결과를 사용하기 때문에 중간 단계를 건너뛰면 안내 문구가 나올 수 있습니다.

작업실 단계는 1. 영상 준비, 2. 대본, 3. 장면 구성, 4. 자막 정리, 5. 최종편집, 6. 업로드 문구, 7. 쿠팡 제품 찾기입니다.
처음에는 프로젝트 이름을 입력하고 저장한 뒤 영상 준비부터 시작합니다.
가장 중요한 순서는 대본을 만들고 음성을 먼저 만든 다음 장면을 구성하는 것입니다.

작업하다가 Ready가 보이면 프로그램이 대기 중이라는 뜻입니다.
작업 중에는 진행 표시와 시간이 보일 수 있습니다.
긴 작업은 끝날 때까지 다른 버튼을 반복해서 누르지 않는 것이 좋습니다.


## 15. 1. 영상 준비는 무엇을 하는 곳인가요

영상 준비는 쇼츠 제작에 사용할 원본 영상을 모으고 분석하는 단계입니다.
제품찾기에서 넘긴 영상이나 직접 추가한 영상을 이곳에서 정리합니다.
영상 분석까지 끝내야 다음 단계에서 대본과 장면 구성이 동작합니다.

영상은 링크로 추가하거나 파일로 추가할 수 있습니다.
유튜브, 틱톡, 인스타, 도우인, 샤오홍슈 링크를 붙여넣고 다운로드를 누르면 영상을 가져옵니다.
이미 가지고 있는 영상 파일은 끌어다 놓거나 파일 선택으로 추가하며, 한 프로젝트에는 최대 50개까지 넣을 수 있습니다.

다운로드 폴더 버튼을 누르면 저장된 파일이 있는 폴더를 열 수 있습니다.
링크 영상이 실패하면 먼저 브라우저에서 그 링크가 정상적으로 열리는지 확인합니다.
영상마다 카드 하나로 표시되며, 카드를 우클릭하면 그 영상이 있는 폴더가 열립니다.

각 카드에는 처리 상태가 표시됩니다.
대기, 분할 완료, 완료, 재분석 필요, 분석 중, 실패로 나타나며, 완료는 장면 나누기와 내용 분석까지 끝난 상태입니다.
재분석 필요는 내용이 바뀌어 다시 분석해야 하는 상태입니다.

소스 영상 분석 버튼은 추가한 영상을 쇼츠 제작에 쓸 수 있도록 분석하는 버튼입니다.
분석이 끝나면 소스별 요약이 표시되고, 이 결과는 장면 구성에서 영상 구간을 고를 때 사용됩니다.
영상이 너무 길거나 장면이 많으면 분석이 어렵다는 안내가 나올 수 있으니, 이럴 때는 짧게 자르거나 필요한 구간만 사용합니다.

분석할 소스 영상을 먼저 추가해주세요라는 안내가 나오면 아직 영상이 없는 상태입니다.
프로젝트를 먼저 저장한 뒤 분석해주세요라는 안내가 나오면 프로젝트가 저장되지 않은 상태이니, 위쪽에서 이름을 저장한 뒤 다시 분석합니다.
이미 영상 준비에 있는 영상입니다라는 안내가 나오면 같은 영상을 다시 추가하려 한 상태이며 이건 정상입니다.


## 16. 2. 대본은 무엇을 하는 곳인가요

대본은 쇼핑 쇼츠에서 말할 내용을 만드는 단계입니다.
영상 준비에서 분석한 내용과 사용자가 고른 스타일을 참고해 쇼츠 대본을 만듭니다.
대본이 있어야 음성 생성과 장면 구성이 이어집니다.

화면 위에는 원본 영상 몇 개가 분석되어 있는지 표시됩니다.
화면은 왼쪽이 스타일을 고르는 칸, 오른쪽이 대본을 만드는 칸입니다.
대본을 만들려면 1. 영상 준비에서 소스 영상 분석이 끝나 있어야 합니다.

스타일은 두 가지 방법으로 정합니다.
첫째는 기본 제공되는 렌즈 스타일을 고르는 방법으로, 가치 비교형, 제품 사용 전후 비교, 정체 공개형, BEST 추천 네 가지가 있습니다.
둘째는 잘 된 유튜브 쇼츠 링크를 넣고 스타일 분석을 눌러 내 스타일로 만드는 방법이며, 이렇게 모은 내 스타일은 다른 프로젝트에서도 계속 골라 쓸 수 있습니다.

유튜브 쇼츠 링크를 입력하세요라는 안내가 나오면 링크 형식이 맞지 않는 상태입니다.
분석할 벤치 영상 링크를 입력하세요라는 안내가 나오면 링크 칸이 비어 있으니, 참고할 쇼츠 주소를 넣고 다시 스타일 분석을 누릅니다.
참고 영상 없이 진행하고 싶다면 기존 렌즈 스타일이나 내 스타일을 골라서 진행할 수 있습니다.

대본생성 버튼을 누르면 쇼핑 쇼츠 대본을 만듭니다.
소스 영상 분석이 되어 있으면 제품 장점과 장면 흐름을 더 잘 반영하며, 대본 생성이 끝나면 문장별로 표시됩니다.
대본 길이는 길이 칸에서 초 단위로 정할 수 있고 기본은 20초이며, 만들어진 대본은 직접 고칠 수 있고 글자 수가 함께 표시됩니다.

대본 사전지시에는 원하는 방향을 짧게 적을 수 있습니다.
예를 들어 첫 문장을 더 강하게, 전체 문장을 짧게, 제품명을 자연스럽게 같은 요청을 넣을 수 있습니다.
너무 많은 요청을 한 번에 넣으면 결과가 흐려질 수 있으니 핵심만 적는 것이 좋습니다.

먼저 영상 준비에서 소스 분석을 완료해주세요라는 안내가 나오면 1. 영상 준비의 분석이 끝나지 않은 상태입니다.
제미나이 키가 설정되지 않았다는 안내가 나오면 설정에서 제미나이 키를 먼저 넣어야 합니다.
대본을 만든 직후 장면이 비어 있는 것은 정상이며, 음성을 만든 뒤 장면이 채워집니다.


## 17. 대본에서 음성 만들기

대본 화면 안에서 음성도 만들 수 있습니다.
음성이 만들어져야 장면 구성에서 문장 길이에 맞게 영상 구간을 맞출 수 있습니다.
대본을 먼저 확인하고 수정한 뒤 음성생성을 누르는 것이 좋습니다.

음성을 만드는 방법은 두 가지입니다.
위쪽 음성생성 버튼을 누르면 대본 전체의 음성을 차례로 만들고, 만드는 중에는 버튼이 생성중지로 바뀝니다.
각 줄 오른쪽의 마이크 버튼을 누르면 그 줄만 따로 만들 수 있고, 줄마다 다른 목소리로 만들 수 있습니다.

음성 서비스는 ElevenLabs와 Typecast 두 가지이며 화면 아래 탭으로 고릅니다.
ElevenLabs는 모델을 v3 최신, 다국어 v2, 터보 v2.5 중에서, 읽는속도를 느림, 보통, 빠름, 더 빠름 중에서 고릅니다.
참고로 ElevenLabs에서 속도를 보통이 아닌 값으로 바꾸면 모델이 자동으로 다국어 v2로 바뀌는데, v3 최신은 속도 조절이 안 되기 때문입니다.

Typecast는 성별, 언어, 연령 같은 조건으로 목소리를 고를 수 있습니다.
감정은 자동, 기쁨, 슬픔, 화남, 속삭임 중에서 고릅니다.
목소리 선택 창에서는 조건으로 거르거나 이름으로 검색해 찾고, 미리듣기로 들어본 뒤 선택완료를 누르면 그 화자에게 목소리가 배정됩니다.

대본의 줄마다 누가 말하는지 정하는 화자 모드가 있습니다.
줄 왼쪽의 색 버튼이 화자를 나타내며 기본 화자 이름은 나레이션입니다.
화자마다 다른 목소리와 속도, 감정을 정할 수 있어 여러 명이 말하는 영상을 만들 수 있습니다.

화면에는 그 서비스의 남은 크레딧이 함께 표시됩니다.
음성이 만들어지면 아래 플레이어에서 재생해 말투와 속도가 자연스러운지 확인하고, 갱신을 누르면 현재 순서대로 이어 듣는 미리듣기가 만들어집니다.
외부에서 만든 wav나 mp3 음성 파일을 불러와 기존 음성을 바꿀 수도 있습니다.


## 18. 음성 생성 문제 해결

대본이 비어있다는 안내가 나오면 아직 만들 음성 내용이 없는 상태입니다.
대본을 먼저 만들거나 직접 입력한 뒤 음성생성을 누릅니다.
빈 문장만 있으면 음성이 만들어지지 않습니다.

프로젝트를 먼저 저장한 뒤 음성을 생성해주세요라는 안내가 나오면 프로젝트가 저장되지 않은 상태입니다.
작업실 위쪽에서 프로젝트 이름을 저장한 뒤 다시 시도합니다.
음성 파일은 프로젝트와 연결되어야 다음 단계에서 사용할 수 있습니다.

음성 목록이 아직 로드되지 않았다는 안내가 나오면 목소리 목록을 불러오는 중입니다.
잠시 기다린 뒤 다시 목소리 선택을 누릅니다.
인터넷이 느리면 목록 표시가 늦을 수 있습니다.

화자별 목소리를 먼저 선택해주세요라는 안내가 나오면 대본에 있는 화자 중 목소리가 없는 화자가 있는 상태입니다.
나레이션이나 다른 화자 항목을 확인하고, 모든 화자에 목소리를 배정한 뒤 다시 생성합니다.
현재 문장과 맞지 않는 음성이라는 안내가 나오면 글자를 고친 뒤 옛 음성을 재생하려 한 것이니 그 줄 음성을 다시 만듭니다.

남은 크레딧이 대본 글자 수보다 적다는 안내가 나오면 음성 서비스 사용량이 부족한 상태입니다.
대본을 줄이거나 사용량을 충전한 뒤 다시 시도합니다.
긴 대본은 비용과 시간이 더 많이 듭니다.

타입캐스트 사용이 일시 차단되었다는 안내가 나오면 타입캐스트가 무료 계정의 비정상 사용으로 판단해 막은 상태일 수 있습니다.
이것은 쇼핑렌즈가 아니라 타입캐스트 쪽 문제이므로 타입캐스트 홈페이지에 차단 해제를 문의해야 합니다.
급하게 작업해야 한다면 ElevenLabs로 바꿔 음성을 만들면 됩니다.


## 19. 3. 장면 구성은 무엇을 하는 곳인가요

장면 구성은 대본 문장과 영상 구간을 맞추는 단계입니다.
음성 길이에 맞게 어떤 소스 영상의 어느 부분을 쓸지 정합니다.
이 단계가 잘 되어야 최종편집에서 영상 흐름이 자연스럽게 이어집니다.

장면 구성 화면은 위쪽에 배치된 장면이 순서대로 늘어서고, 아래쪽에 소스 영상별 장면 모음이 있습니다.
소스 영상이 많으면 1-4, 5-8 버튼으로 페이지를 바꿔 볼 수 있습니다.
아직 분석된 소스 장면이 없다는 안내가 나오면 1. 영상 준비에서 소스 영상 분석이 끝나지 않은 상태입니다.

장면 매칭 버튼을 누르면 프로그램이 대본과 음성에 맞춰 장면을 자동으로 배치합니다.
매칭이 진행되는 동안 버튼이 중지로 바뀌고, 다시 누르면 멈출 수 있습니다.
매칭이 끝나면 위쪽에 문장별 장면이 표시되며, 원하는 장면이 아니면 직접 바꿀 수 있습니다.

이 기능은 문장마다 음성이 모두 만들어져 있어야 동작합니다.
최신 음성이 없는 문장이 있으면 그 번호를 알려주며 음성을 먼저 만들라고 안내합니다.
매칭할 대본과 문장별 음성이 없다는 안내가 나오면 2. 대본에서 대본을 만들고 음성을 생성한 뒤 다시 누릅니다.

초기화 버튼은 자동 매칭 결과로 되돌릴 때 사용합니다.
이미 많이 수정한 상태라면 누르기 전에 정말 되돌려도 되는지 확인합니다.
미리 보기 버튼은 현재 장면들이 어떻게 이어지는지 확인하는 버튼입니다.

장면 매칭 결과가 비어 있다는 안내가 나오면 프로그램이 사용할 장면을 찾지 못한 상태입니다.
소스 영상 분석이 제대로 끝났는지, 음성이 생성되어 있는지 확인합니다.
소스 영상이 제품과 너무 무관하면 다른 영상을 추가해 다시 분석하는 것이 좋습니다.


## 20. 장면을 직접 수정하는 방법

장면 구성에서는 누르는 위치에 따라 동작이 다릅니다.
위쪽 장면 카드는 썸네일을 누르면 그 장면의 미리보기가 열리고, 글자 부분을 누르면 그 칸이 선택됩니다.
위쪽 장면 카드를 더블클릭하면 대본 문장을 고치는 창이 열리고, 우클릭하면 그 칸에 넣을 영상을 직접 고르는 창이 열립니다.

아래쪽 소스 장면 카드는 왼쪽 클릭이 미리보기, 우클릭이 교체입니다.
소스 장면을 바꾸려면 먼저 위쪽에서 바꿀 칸을 한 번 눌러 선택한 다음, 아래 소스 장면을 우클릭하면 그 영상으로 바뀝니다.
선택한 칸이 어느 소스 장면을 쓰는지는 초록색 테두리로 표시되며, 다른 칸을 선택하면 따라 옮겨집니다.

위쪽 카드를 우클릭하거나 카드 사이의 플러스 버튼을 누르면 통합 편집 창이 열립니다.
이 창은 1. 자막, 2. 음성, 3. 영상으로 나뉘어 있습니다.
문장, 목소리, 영상 구간을 각각 확인하고 바꿀 수 있습니다.

자막 영역에서는 해당 장면의 문장을 확인하고 필요하면 짧게 줄이거나 표현을 바꿉니다.
음성 영역에서는 목소리 선택과 음성 생성이 가능하며, 특정 장면만 다른 목소리로 바꾸거나 다시 만들 수 있습니다.
여기서도 음성이 먼저이며, 음성이 없으면 음성을 생성해야 영상 선택이 열린다는 안내가 나옵니다.

영상 영역에서는 소스에서 선택, 내 영상 선택, AI 영상 만들기를 사용할 수 있습니다.
소스에서 선택은 영상 준비에서 분석한 영상 중 구간을 고르는 방식이고, 내 영상 선택은 사용자가 가진 파일을 직접 넣는 방식입니다.
선택 구간에는 시작과 끝이 초로 표시되며, 음성 길이를 기준으로 너무 짧거나 긴 구간은 조정하고 구간 반복으로 짧은 영상을 늘려 쓸 수 있습니다.

AI 영상 만들기는 장면에 맞는 새 영상을 만들고 싶을 때 사용합니다.
프롬프트 생성을 누른 뒤 AI 영상 생성을 누르면 요청이 시작되고, 저장 확인 단계가 이어질 수 있습니다.
완료 안내가 나온 뒤 장면에 적용합니다.


## 21. 장면 미리 보기

미리 보기는 현재 장면들이 실제 영상처럼 이어지는지 확인하는 기능입니다.
장면 구성을 많이 수정한 뒤에는 꼭 한 번 확인하는 것이 좋습니다.
말하는 내용과 화면이 어긋나는 부분을 빨리 찾을 수 있습니다.

미리보기 준비 중이라는 안내가 나오면 장면을 이어 붙이고 자막을 입히는 중입니다.
소스 영상이 길거나 장면 수가 많으면 시간이 걸릴 수 있으니, 준비 중에 같은 버튼을 반복해서 누르지 않습니다.
이미 만들어둔 미리 보기가 있고 장면이 바뀌지 않았다면 기존 미리 보기를 빠르게 엽니다.

장면을 수정했다면 새로 미리 보기를 만들어 확인합니다.
미리 보기에서 이상한 부분을 찾으면 장면 상세 화면으로 돌아가 수정합니다.
미리보기를 만들지 못했다는 안내가 나오면 잠시 후 다시 시도합니다.


## 22. 4. 자막 정리는 무엇을 하는 곳인가요

자막 정리는 장면 구성에 들어간 영상의 기존 자막을 정리하는 단계입니다.
원본 영상에 이미 자막이 있으면 쇼핑렌즈가 새로 넣는 자막과 겹칠 수 있습니다.
이 단계에서 원본 자막을 지우거나 흐리게 처리하면 최종 영상이 더 깔끔해집니다.

자막 정리 화면에는 장면 영상 목록이 보입니다.
새로고침을 누르면 현재 장면 구성을 다시 불러옵니다.
영상 준비와 달리 여기서는 새 영상을 끌어다 넣거나 링크로 받는 기능은 막혀 있고, 장면 구성에서 정한 영상만 들어옵니다.

방법은 자막 제거와 자막 블러가 있습니다.
자막 제거는 글자를 지우고 배경을 그려 채우는 방식이고, 자막 블러는 글자를 흐리게 덮는 방식입니다.
배경이 복잡한 영상은 자막 블러가 더 자연스러울 수 있습니다.

범위는 자동감지, 좁게, 보통, 넓게 중에서 선택합니다.
좁게는 글자 주변만 정리하고, 넓게는 자막 박스까지 넓게 처리합니다.
제품이 자막 근처에 있으면 좁게나 보통부터 시도하는 것이 좋습니다.

블러 강도와 페더는 자막 블러를 선택했을 때 중요합니다.
블러 강도가 높을수록 더 흐려지고, 페더가 높을수록 가장자리가 부드럽게 보입니다.
너무 강하면 해당 부분이 뿌옇게 떠 보일 수 있습니다.

전체 자막 지우기는 선택한 영상 전체에 적용합니다.
상세 화면에서는 박스 자동감지와 박스 전부 지우기를 사용할 수 있고, 자동감지가 놓친 자막은 직접 영역을 조정해 다시 처리합니다.
처리가 끝나면 원본과 결과를 나란히 비교해 볼 수 있고, 결과 위에서 우클릭하면 자막 제거를 취소해 되돌릴 수 있습니다.


## 23. 자막 정리 문제 해결

자막이 깨끗하게 안 지워지는 이유는 원본 영상 배경과 자막이 섞여 있기 때문입니다.
특히 자막 뒤에 제품, 손, 얼굴, 움직이는 배경이 있으면 완벽하게 지우기 어렵습니다.
이럴 때는 제거보다 블러가 더 안정적일 수 있습니다.

자막 주변까지 이상하게 흐려지면 범위가 너무 넓은 상태일 수 있습니다.
범위를 보통이나 좁게로 바꾸고 다시 시도합니다.
블러 강도도 조금 낮춰 확인합니다.

자동감지가 자막 위치를 못 찾으면 자막이 작거나 화면과 색이 비슷한 상태일 수 있습니다.
상세 화면에서 박스를 직접 잡거나 다른 방식으로 처리합니다.
그래도 어렵다면 해당 장면을 다른 영상으로 바꾸는 것이 더 빠를 수 있습니다.


## 24. 5. 최종편집은 무엇을 하는 곳인가요

최종편집은 완성 영상의 화면 스타일, 자막 스타일, 배경음악, 효과, 내보내기를 처리하는 단계입니다.
장면 구성과 자막 정리가 끝난 뒤 최종적으로 확인하는 곳입니다.
이 단계에서 편집 준비를 먼저 해야 미리보기와 내보내기가 안정적으로 작동합니다.

최종편집 화면 위쪽에는 편집준비와 내보내기 버튼이 있습니다.
편집준비는 음성을 분석해 장면별 자막을 자동으로 만들고 미리보기 영상을 만드는 과정입니다.
내보내기는 완성 파일을 만드는 과정입니다.

편집준비를 누르면 편집 준비 설정 창이 나옵니다.
이 창에서 트랜지션, 영상 원본소리 보존, 무음 삭제, 영상 효과를 선택합니다.
무음 삭제는 적용 안함, 표준, 타이트, 이어짐 중에서, 영상 효과는 효과 없음, 자동 모드, 줌 인 아웃, 화면 이동, 유영 효과, 복합 연출, 좌우 반전 중에서 고른 뒤 편집 준비 시작을 누릅니다.

장면 구성에 연결된 문장 음성이 없다는 안내가 나오면 2. 대본에서 음성이 만들어지지 않았거나 장면에 연결되지 않은 상태입니다.
대본 화면에서 음성을 생성하고 장면 구성에서 장면 매칭을 다시 확인합니다.
음성이 없으면 최종편집에서 길이를 맞출 수 없습니다.

TTS 음성과 현재 장면 구조가 일치하지 않는다는 안내가 나오면 음성을 만든 뒤 장면을 더하거나 빼서 개수가 맞지 않는 상태입니다.
대본 화면에서 음성을 다시 만든 뒤 편집 준비를 다시 합니다.
최종편집으로 넘길 장면 데이터가 없다는 안내가 나오면 3. 장면 구성에서 장면 매칭을 먼저 완료합니다.

편집 준비 중이라는 안내가 나오면 음성과 영상을 확인하고 미리보기 영상을 만드는 중입니다.
미리보기 영상 생성 중이라고 표시되면 잠시 기다립니다.
장면 구성에서 장면을 바꿨거나 대본 화면에서 음성을 다시 만들었다면 편집 준비를 다시 해야 합니다.


## 25. 최종편집 화면 구성

왼쪽에는 비디오 캔버스가 있습니다.
현재 영상 화면과 자막 위치를 확인하는 곳입니다.
재생 버튼, 시간 표시, 속도, 볼륨 조절도 함께 보입니다.

오른쪽에는 텍스트 에디터가 있습니다.
문장별 자막을 확인하고 수정할 수 있습니다.
자막 문장을 바꾸면 영상 화면에서도 확인할 수 있습니다.

상단 도구에는 굵게, 기울임, 글꼴, 크기, 글자 색상, 배경, 테두리, 그림자가 있습니다.
자막 위치는 세로 위치 조절로 바꾸고, 자막 길이는 짧게와 보통 중에서 선택합니다.
필터는 영상 색감을 원본, 벨비아, 크로스, 시네마틱, 따뜻하게, 차갑게, 블리치 중에서 고를 때 사용합니다.

오른쪽 위에는 음성 켜기와 자막 켜기 스위치가 있습니다.
자막 스위치를 끄면 영상에서 자막이 빠지고, 음성 스위치를 끄면 소리가 무음이 되되 길이와 타이밍은 그대로 유지됩니다.
말소리 없는 영상이나 자막 없는 영상을 만들 때 사용합니다.

AI 효과음, 배경음, 템플릿 버튼도 도구에 있습니다.
배경음은 영상 전체에 들어갈 음악을 선택할 때 사용합니다.
템플릿은 화면에 고정으로 올릴 글자나 이미지, 상하단 박스를 저장하고 불러오는 데 사용합니다.


## 26. 자막 편집 방법

자막은 오른쪽 텍스트 에디터에서 문장별로 표시됩니다.
문장을 클릭하면 해당 장면 쪽으로 미리보기가 이동합니다.
문장을 수정하면 최종 영상에 들어갈 자막 내용도 바뀝니다.

각 자막에는 시작 시간과 끝 시간이 표시되며, 시간을 눌러 직접 바꿀 수 있습니다.
말과 자막이 살짝 어긋나면 시간을 조금 조정합니다.
시간을 크게 바꾸면 다음 문장과 겹칠 수 있으니 조금씩 확인합니다.

문장을 나누고 싶으면 그 위치에서 엔터를 눌러 둘로 나눕니다.
문장을 합치고 싶으면 줄 끝에서 Del을 눌러 아래 문장과 합칩니다.
너무 긴 자막은 한 화면에서 읽기 어려우니 짧게 나누는 것이 좋습니다.

특정 문장만 색을 바꾸고 싶으면 그 문장의 색상 버튼을 사용합니다.
전체 자막 색상과 다르게 강조할 수 있습니다.
너무 많은 색을 섞으면 영상이 산만해 보일 수 있습니다.

자막을 의미 단위로 자연스럽게 나누는 작업은 편집 준비를 할 때 자동으로 처리됩니다.
편집 준비 중에 음성을 분석해 문장을 보기 좋게 나눠 줍니다.
나눈 결과가 어색하면 텍스트 에디터에서 직접 다듬으면 됩니다.


## 27. AI 효과음

AI 효과음은 영상 내용에 맞는 소리를 새로 만들어 까는 기능입니다.
장면마다 소리가 들어가면 쇼츠가 더 살아날 수 있지만, 너무 많으면 말소리를 방해할 수 있습니다.
처음에는 필요한 장면에만 적게 넣는 것이 좋습니다.

AI 효과음 창에는 AI 효과음 사용과 제미나이로 분석 후 자동 추천이 보입니다.
만들 소리 칸에 원하는 소리를 적거나, 자동 추천을 켜면 미리보기 영상을 보고 어울리는 소리를 추천해 줍니다.
빼고 싶은 소리를 적을 수도 있고, 볼륨도 조절합니다.

AI 효과음은 컴퓨터 안에서 직접 만들어지기 때문에 따로 크레딧이 차감되지 않습니다.
다만 그래픽 메모리가 부족해서 효과음을 만들지 못했다는 안내가 나오면 무거운 다른 프로그램을 닫고 다시 시도합니다.
효과음을 만들려면 먼저 프로젝트를 저장하고 편집준비로 미리보기 영상을 만들어 두어야 합니다.


## 28. 배경음악

배경음악은 영상 전체에 들어갈 음악을 선택하는 기능입니다.
배경음이 있으면 영상 분위기가 좋아질 수 있지만, 말소리보다 커지면 전달력이 떨어집니다.
볼륨을 낮게 시작해서 미리보기로 확인하는 것이 좋습니다.

배경음악 선택 창에는 파일을 놓는 영역이 보입니다.
음악 파일을 끌어다 놓거나, 프로그램 폴더의 배경음악 폴더에 파일을 넣으면 목록에 나타납니다.
볼륨을 조절한 뒤 적용을 누릅니다.

배경음이 너무 크면 음성 내용이 잘 안 들릴 수 있습니다.
이럴 때는 볼륨을 낮추고 다시 미리보기로 확인합니다.
쇼츠는 짧기 때문에 음악 시작 부분이 너무 길면 지루하게 느껴질 수 있습니다.


## 29. 내보내기

내보내기는 최종 영상을 실제 파일로 만드는 단계입니다.
편집 준비가 끝나지 않았거나 음성 파일이 없으면 내보내기가 실패할 수 있습니다.
먼저 미리보기에서 문제가 없는지 확인한 뒤 내보내는 것이 좋습니다.

내보내기 메뉴에는 전체 영상 내보내기, SRT 자막 내보내기, 캡컷 프로젝트 내보내기가 있습니다.
전체 영상 내보내기는 완성 영상을 만드는 기능이고, SRT 자막 내보내기는 자막 파일만 따로 저장하는 기능입니다.
캡컷 프로젝트 내보내기는 캡컷에서 이어 편집할 수 있도록 자료를 정리하는 기능입니다.

내보낸 완성 영상은 프로젝트 폴더의 완성영상 폴더에 저장됩니다.
내보내기가 완료되면 내보내기 완료 안내가 나오고, 폴더 열기를 누르면 저장 위치를 바로 확인할 수 있습니다.
QR 안내가 보이면 같은 인터넷에 연결된 휴대폰으로 그 코드를 찍어 작업물을 바로 받을 수 있습니다.


## 30. 내보내기 문제 해결

프로젝트를 먼저 저장해주세요라는 안내가 나오면 현재 작업이 저장되지 않은 상태입니다.
작업실 위쪽에서 프로젝트 이름을 저장한 뒤 다시 내보냅니다.
저장되지 않은 프로젝트는 결과 파일 위치를 안정적으로 만들기 어렵습니다.

음성 파일이 없습니다라는 안내가 나오면 2. 대본에서 음성을 생성하지 않은 상태입니다.
대본으로 돌아가 음성생성을 먼저 진행합니다.
그다음 장면 구성과 편집 준비를 다시 확인합니다.

자막이 없습니다라는 안내가 나오면 편집 준비가 끝나지 않았거나 자막 자료가 만들어지지 않은 상태입니다.
최종편집에서 편집준비를 먼저 완료합니다.
편집 준비가 실패했다면 장면 구성과 음성 연결을 다시 확인합니다.

저장 경로가 너무 길다는 안내가 나오면 프로젝트 이름이나 폴더 위치가 너무 긴 상태입니다.
프로젝트 이름을 짧게 만들거나 더 짧은 위치에서 작업합니다.
특수문자가 많은 이름도 피하는 것이 좋습니다.

디스크 공간이 부족하다는 안내가 나오면 저장 공간이 모자란 상태입니다.
불필요한 영상 파일을 지우고 다시 내보냅니다.
최종 영상은 임시 파일을 크게 만들 수 있으니 여유 공간이 필요합니다.

파일에 접근할 수 없다는 안내가 나오면 결과 파일이나 폴더가 다른 프로그램에서 열려 있거나 백신이 막은 상태일 수 있습니다.
동영상 플레이어, 캡컷, 파일 탐색기 미리보기를 닫고, 백신에서 쇼핑렌즈를 예외 처리한 뒤 다시 시도합니다.
QR로 휴대폰 전송이 안 되면 휴대폰과 컴퓨터가 같은 인터넷에 있는지 확인하고, 안 되면 폴더 열기로 파일을 직접 옮깁니다.


## 31. 6. 업로드 문구는 무엇을 하는 곳인가요

업로드 문구는 완성한 영상에 붙일 제목과 설명을 만드는 단계입니다.
유튜브 제목, 유튜브 설명, 인스타 설명을 각각 여러 가지 스타일로 만들어줍니다.
업로드 전에 문구를 미리 준비하면 게시 시간을 줄일 수 있습니다.

업로드 문구 만들기 버튼을 누르면 대본을 바탕으로 문구를 만듭니다.
유튜브 제목 3개, 유튜브 설명 3개, 인스타 설명 3개가 표시되며, 카드마다 서로 다른 스타일로 나옵니다.
각 카드 옆의 복사를 눌러 원하는 문구를 바로 사용할 수 있고, 카드 안에서 직접 고치면 자동으로 저장됩니다.

제목만 다시, 유튜브 설명만 다시, 인스타 설명만 다시 버튼이 있습니다.
전체는 괜찮은데 특정 부분만 마음에 안 들 때 사용합니다.
다시 만들면 기존 문구가 바뀔 수 있으니 마음에 드는 문구는 먼저 복사해 둡니다.

대본이 없어서 업로드 문구를 만들 수 없다는 안내가 나오면 대본이 비어 있는 상태입니다.
대본을 먼저 만들거나 입력한 뒤 다시 시도합니다.
업로드 문구를 만드는 중 문제가 발생했다는 안내가 나오면 잠시 후 다시 시도합니다.


## 32. 7. 쿠팡 제품 찾기는 무엇을 하는 곳인가요

쿠팡 제품 찾기는 영상에 맞는 쿠팡 상품 후보를 찾는 단계입니다.
완성 영상과 대본을 참고하거나, 검색어나 이미지로 후보를 찾을 수 있습니다.
상품 링크를 정리해두면 업로드 설명에 넣기 쉽습니다.

쿠팡 후보 찾기 버튼은 현재 작업 내용을 바탕으로 상품 후보를 찾습니다.
최종 영상과 대본이 준비되어 있으면 더 잘 찾으며, 이 자동 찾기는 프로젝트가 열려 있어야 동작합니다.
키워드 선택 또는 직접 입력 칸에 제품명이나 특징을 넣어 검색할 수도 있고, 제품 캡처 이미지를 넣어 찾을 수도 있습니다.

결과는 쿠팡 후보 영역에 카드로 표시됩니다.
각 카드에는 상품 이미지, 열기, 복사, 삭제 버튼이 있습니다.
열기는 상품 페이지를 확인하는 버튼이고, 복사는 해당 링크를 복사하는 버튼입니다.

링크 전체 복사는 결과에 있는 쿠팡 링크를 한 번에 복사하는 기능입니다.
업로드 설명에 여러 후보를 정리할 때 유용합니다.
비우기를 누르면 현재 후보 목록을 지웁니다.

이 기능은 쇼핑렌즈 오토라는 크롬 확장 프로그램을 통해 동작합니다.
그래서 확장 프로그램 연결이 끊기면 검색이 안 되며, 검색이 오래 걸릴 수 있습니다.
검색 도중에는 즉시 중지나 중지 버튼으로 멈출 수 있습니다.


## 33. 쿠팡 제품 찾기 문제 해결

검색어를 입력해주세요라는 안내가 나오면 직접 검색할 단어가 비어 있는 상태입니다.
제품명이나 핵심 특징을 넣고 다시 검색합니다.
너무 긴 문장보다 짧은 핵심 단어가 좋습니다.

프로젝트를 먼저 열어주세요라는 안내가 나오면 프로젝트를 열지 않은 채 자동 찾기를 누른 상태입니다.
프로젝트를 먼저 열고 다시 시도합니다.
자동 찾기는 최종 영상과 대본을 사용하기 때문에 프로젝트가 필요합니다.

쇼핑렌즈 오토 연결이 끊겼으니 확장 프로그램을 새로고침한 뒤 다시 검색해 달라는 안내가 나오면 브라우저 쪽 연결이 정상적이지 않은 상태입니다.
확장 프로그램을 새로고침하고 쇼핑렌즈에서 다시 검색합니다.
그래도 안 되면 브라우저를 닫았다가 다시 여는 것이 도움이 됩니다.

검색 시간이 너무 오래 걸려 멈췄다는 안내가 나오면 결과 확인 시간이 길어진 상태입니다.
잠시 후 같은 검색어로 다시 시도합니다.
검색어를 더 구체적으로 줄이면 시간이 줄어들 수 있습니다.

쿠팡 링크가 엉뚱하게 나오면 검색 단서가 넓거나 영상 속 제품 단서가 부족한 상태일 수 있습니다.
제품명, 색상, 용도, 특징을 더 구체적으로 넣어 다시 검색합니다.
똑같은 링크와 똑같은 그림은 자동으로 중복 제거됩니다.


## 34. 프로젝트 메뉴

프로젝트 메뉴는 저장한 작업을 다시 여는 곳입니다.
작업을 중간에 멈췄다면 이 메뉴에서 기존 프로젝트를 선택해 이어갈 수 있습니다.
프로젝트 카드를 누르면 그 프로젝트가 열리고 자동으로 작업실로 이동합니다.

프로젝트가 보이지 않으면 아직 저장한 프로젝트가 없거나 다른 위치에 저장된 상태일 수 있습니다.
작업실에서 프로젝트 이름을 입력하고 저장했는지 확인합니다.
저장하지 않고 프로그램을 닫으면 이어서 열 수 있는 자료가 부족할 수 있습니다.

프로젝트를 지우려면 카드의 휴지통 버튼을 누르고 확인합니다.
현재 사용중인 프로젝트라 삭제할 수 없다는 안내가 나오면 다른 프로젝트를 연 뒤 지웁니다.
프로젝트 폴더가 사용 중이어서 삭제할 수 없다는 안내가 나오면 그 폴더를 탐색기에서 닫고 다시 시도합니다.

기존 프로젝트를 열면 작업실 단계들이 저장된 상태로 복구됩니다.
다만 외부 파일을 이동하거나 지웠다면 일부 영상이나 음성이 보이지 않을 수 있습니다.
프로젝트 작업 중에는 원본 파일을 임의로 옮기지 않는 것이 좋습니다.


## 35. 도구 메뉴

도구 메뉴는 작업실과 별도로 사용할 수 있는 기능을 모아둔 곳입니다.
현재는 자막 지우개를 사용할 수 있고, 나머지는 준비 중으로 표시됩니다.
쇼츠 제작과 별개로 영상 속 기존 자막을 지우고 싶을 때 유용합니다.

자막 지우개는 영상 속 자막을 자동으로 감지하고 제거하거나 흐리게 처리합니다.
링크를 붙여넣어 영상을 가져오거나, 가지고 있는 영상 파일을 추가할 수 있습니다.
추가한 뒤 자막 제거 또는 자막 블러를 선택해 처리합니다.

도구 메뉴의 자막 지우개는 작업실 4. 자막 정리와 목적이 비슷합니다.
차이는 작업실은 현재 프로젝트 장면과 연결되어 있고, 도구 메뉴는 독립적으로 사용할 수 있다는 점입니다.
프로젝트와 상관없이 영상 하나만 정리하고 싶으면 도구 메뉴가 더 간단합니다.


## 36. 업데이트 확인

왼쪽 아래 버전 표시를 누르면 업데이트 확인을 할 수 있습니다.
확인하는 동안 표시가 확인중으로 바뀝니다.
최신 버전이면 현재 최신 버전을 사용 중이라는 안내가 나오고, 새 버전이 있으면 업데이트 안내가 표시됩니다.

업데이트 중에는 프로그램을 닫거나 설치 파일을 지우지 않는 것이 좋습니다.
설치 파일이 막히면 실행 중인 쇼핑렌즈를 먼저 종료합니다.
백신이나 보안 프로그램이 설치 파일을 검사하는 동안 잠시 기다려야 할 수도 있습니다.


## 37. QnA 버튼

왼쪽 아래 QnA 버튼은 사용 중 질문을 할 수 있는 챗봇을 여는 버튼입니다.
사용자가 어느 화면에서 막혔는지 말하면 챗봇이 해당 단계 기준으로 안내할 수 있습니다.
오류 문구를 그대로 보내면 더 정확하게 답변할 수 있습니다.

질문할 때는 화면 이름과 버튼 이름을 함께 말하는 것이 좋습니다.
예를 들어 작업실 3. 장면 구성에서 장면 매칭을 눌렀는데 안내가 나왔다고 말하면 됩니다.
스크린샷이 있으면 더 빠르게 확인할 수 있습니다.


## 38. 자주 묻는 질문

### 처음 켰는데 무엇부터 해야 하나요?
먼저 설정에서 인증키와 필요한 키를 등록합니다.
그다음 트렌드에서 아이디어를 보고, 작업실에서 프로젝트 이름을 저장한 뒤 1. 영상 준비부터 시작합니다.

### 어떤 키들이 필요한가요?
대본 생성과 영상 분석 기능에는 제미나이 키가 필요합니다.
트렌드와 제품찾기의 키워드 검색과 댓글 보기에는 유튜브 키가, 음성 만들기에는 ElevenLabs나 Typecast 키가 필요합니다.

### 트렌드의 어제, 주간, 월간은 어떻게 다른가요?
어제는 최근에 빠르게 반응이 오른 영상을 보는 기준입니다.
주간과 월간은 조금 더 오래 반응이 이어진 영상을 보는 기준이며, 기간은 이 세 가지뿐입니다.

### 쇼핑 트렌드와 제품찾기는 무엇이 다른가요?
쇼핑 트렌드는 인기 쇼핑 쇼츠를 참고하는 곳입니다.
제품찾기는 내가 만들 영상에 사용할 원본 후보를 찾는 곳입니다.

### 제품찾기와 쿠팡 제품 찾기는 무엇이 다른가요?
제품찾기는 쇼츠에 쓸 영상 후보를 찾는 기능입니다.
쿠팡 제품 찾기는 업로드 설명에 넣을 상품 링크 후보를 찾는 기능입니다.

### 작업실에서 꼭 순서대로 해야 하나요?
처음에는 순서대로 하는 것이 가장 안정적입니다.
앞 단계 결과가 뒤 단계에서 필요하기 때문에 건너뛰면 안내 문구가 나올 수 있습니다.

### 프로젝트를 꼭 저장해야 하나요?
네, 저장해야 합니다.
분석 결과, 음성, 장면, 내보내기 파일이 프로젝트와 연결되기 때문입니다.

### 소스 영상 분석은 꼭 해야 하나요?
네, 해야 합니다.
대본 생성과 자동 장면 매칭이 모두 소스 영상 분석 결과를 사용하기 때문입니다.

### 대본은 만들었는데 장면 매칭이 안 됩니다.
음성이 아직 만들어지지 않았거나 소스 영상 분석이 끝나지 않았을 가능성이 큽니다.
대본 화면에서 음성을 생성하고, 영상 준비에서 소스 영상 분석을 완료한 뒤 다시 시도합니다.

### 대본을 만들었는데 장면이 비어 있어요.
정상입니다.
쇼핑렌즈는 음성을 만든 뒤에 장면이 배치되는 순서이므로, 음성을 만들고 3. 장면 구성에서 장면 매칭을 하면 채워집니다.

### 음성생성이 안 됩니다.
대본이 비어 있거나, 프로젝트가 저장되지 않았거나, 목소리가 선택되지 않았을 수 있습니다.
대본, 저장 상태, 화자별 목소리 선택을 순서대로 확인합니다.

### 목소리 목록이 안 보입니다.
인터넷 연결이 느리거나 음성 서비스 목록을 불러오는 중일 수 있습니다.
잠시 기다린 뒤 갱신하거나 다시 목소리 선택을 눌러봅니다.

### 타입캐스트 음성이 갑자기 다 안 만들어져요.
타입캐스트가 무료 계정의 비정상 사용으로 판단해 막은 경우일 수 있습니다.
이것은 쇼핑렌즈가 아니라 타입캐스트 쪽 문제이니 타입캐스트에 문의하거나, 급하면 ElevenLabs로 음성을 만듭니다.

### 제미나이 키가 없으면 무엇이 안 되나요?
영상 분석, 스타일 분석, 대본 생성 같은 기능이 막힐 수 있습니다.
설정에서 제미나이 키를 먼저 등록하는 것이 좋습니다.

### 유튜브 키가 없으면 무엇이 안 되나요?
트렌드와 제품찾기의 키워드 검색, 댓글 보기, 유튜브 영상 확인 기능이 막힐 수 있습니다.
설정의 유튜브 키 관리 영역에서 키를 추가합니다.

### 원본 영상 자막은 언제 지우는 게 좋나요?
원본 자막이 새 자막과 겹칠 것 같으면 미리 지우는 것이 좋습니다.
영상 준비에서 미리 정리하거나, 자막 정리에서 장면 영상의 자막을 정리합니다.

### 자막 제거와 자막 블러 중 무엇을 써야 하나요?
배경이 단순하면 자막 제거가 깔끔할 수 있습니다.
배경이 복잡하거나 제품이 자막 뒤에 있으면 자막 블러가 더 자연스러울 수 있습니다.

### 배경음악을 직접 넣을 수 있나요?
네, 넣을 수 있습니다.
프로그램 폴더의 배경음악 폴더에 음악 파일을 넣으면 목록에 자동으로 나타납니다.

### 자막 없이 영상을 만들 수 있나요?
네, 만들 수 있습니다.
최종편집에서 자막 스위치를 끄면 자막 없이 내보낼 수 있습니다.

### 편집준비는 왜 해야 하나요?
최종 영상을 만들기 전에 음성을 분석해 자막을 만들고 미리보기 영상을 준비하는 과정입니다.
이 과정을 해야 미리보기와 내보내기가 안정적으로 작동합니다.

### 내보내기 전에 무엇을 확인해야 하나요?
음성이 생성되어 있는지, 장면 구성이 끝났는지, 편집준비가 완료되었는지 확인합니다.
미리보기로 자막 위치와 소리 크기도 확인합니다.

### 내보낸 파일은 어디서 확인하나요?
내보내기 완료 안내에서 폴더 열기를 누르면 저장 위치가 열립니다.
완성 영상은 프로젝트 폴더의 완성영상 폴더에 저장됩니다.

### 휴대폰으로 파일을 바로 받고 싶습니다.
내보내기 완료 화면에 QR 안내가 보이면 휴대폰으로 스캔해 받을 수 있습니다.
컴퓨터와 휴대폰이 같은 인터넷에 연결되어 있어야 합니다.

### 업로드 문구가 마음에 안 듭니다.
제목만 다시, 유튜브 설명만 다시, 인스타 설명만 다시 버튼을 사용합니다.
대본 자체가 어색하면 대본을 먼저 고친 뒤 다시 만드는 것이 좋습니다.

### 쿠팡 링크가 엉뚱하게 나옵니다.
검색어가 너무 넓거나 영상 속 제품 단서가 부족할 수 있습니다.
제품명, 용도, 색상, 특징을 더 구체적으로 넣어 다시 검색합니다.

### AI 영상 생성이 오래 걸립니다.
영상 생성과 저장 확인에는 시간이 걸릴 수 있습니다.
진행 안내가 바뀌고 있다면 기다리고, 멈춘 것 같으면 인터넷 연결과 제미나이 키 상태를 확인합니다.

### 영상 처리가 너무 느려요.
그래픽카드가 없으면 처리가 많이 느릴 수 있습니다.
영상이 너무 길거나 장면이 많으면 더 오래 걸리니, 짧게 자르거나 필요한 구간만 사용합니다.

### 작업 중 프로그램을 꺼도 되나요?
긴 작업이 진행 중일 때는 끄지 않는 것이 좋습니다.
중간에 꺼야 한다면 작업이 끝난 뒤 프로젝트를 저장하고 종료합니다.


## 39. 단계별 빠른 안내

### 트렌드만 보고 싶을 때
1. 왼쪽 메뉴에서 트렌드를 누릅니다.
2. 쇼핑 트렌드에서 오늘의 트렌드를 봅니다.
3. 어제, 주간, 월간 중 원하는 기준을 고릅니다.
4. 마음에 드는 영상은 별 표시로 저장합니다.

### 원본 영상을 찾고 싶을 때
1. 트렌드에서 제품찾기를 누릅니다.
2. 이미지, 영상, 링크, 검색어 중 하나를 넣습니다.
3. 플랫폼을 선택하고 검색을 누릅니다.
4. 마음에 드는 결과를 추가하고 영상 준비로 이동을 누릅니다.

### 새 쇼츠를 만들고 싶을 때
1. 작업실에서 프로젝트 이름을 입력하고 저장합니다.
2. 영상 준비에서 원본 영상을 추가합니다.
3. 소스 영상 분석을 실행합니다.
4. 대본에서 스타일을 고르고 대본생성을 진행합니다.
5. 같은 화면에서 음성생성을 눌러 음성을 만듭니다.
6. 장면 구성에서 장면 매칭을 실행합니다.
7. 자막 정리에서 원본 자막을 정리합니다.
8. 최종편집에서 편집준비 후 내보내기합니다.
9. 업로드 문구와 쿠팡 제품 찾기를 진행합니다.

### 이미 가진 영상으로 만들고 싶을 때
1. 작업실에서 프로젝트를 저장합니다.
2. 영상 준비에 가진 영상을 추가합니다.
3. 소스 영상 분석을 실행합니다.
4. 이후 대본, 음성, 장면 구성 순서로 진행합니다.

### 자막만 지우고 싶을 때
1. 왼쪽 메뉴에서 도구를 누릅니다.
2. 자막 지우개를 엽니다.
3. 영상 파일이나 링크를 추가합니다.
4. 자막 제거 또는 자막 블러를 선택합니다.
5. 결과를 확인하고 저장된 폴더를 엽니다.

### 쿠팡 링크만 찾고 싶을 때
1. 작업실에서 쿠팡 제품 찾기를 엽니다.
2. 키워드 선택 또는 직접 입력 칸에 제품명을 넣습니다.
3. 검색을 누릅니다.
4. 결과에서 열기로 확인하고 복사를 누릅니다.


## 40. 챗봇이 오류 질문을 받을 때 확인할 순서

먼저 사용자가 어느 화면에 있는지 확인합니다.
트렌드인지, 제품찾기인지, 작업실의 몇 번째 단계인지 물어봅니다.
화면 이름을 알면 해결 방법을 훨씬 빠르게 찾을 수 있습니다.

두 번째로 사용자가 본 안내 문구를 그대로 확인합니다.
안내 문구가 정확하면 이 문서의 문제 해결 부분을 기준으로 답변합니다.
문구가 기억나지 않으면 마지막으로 누른 버튼을 물어봅니다.

세 번째로 필요한 준비가 되어 있는지 확인합니다.
프로젝트 저장, 영상 추가, 소스 영상 분석, 대본 생성, 음성 생성, 장면 매칭, 편집 준비 중 어느 단계가 빠졌는지 봅니다.
대부분의 문제는 앞 단계가 아직 끝나지 않아서 생깁니다.

특히 음성과 장면의 순서를 확인합니다.
쇼핑렌즈는 음성을 먼저 만들고 장면을 배치하므로, 장면이 비거나 매칭이 안 되면 음성이 만들어졌는지부터 봅니다.
음성이 없는 문장이 있으면 그 문장의 음성을 먼저 만들게 안내합니다.

네 번째로 설정 상태를 확인합니다.
제미나이 키, 유튜브 검색 키, ElevenLabs 키, Typecast 키, 인증키가 필요한 기능에서 빠져 있을 수 있습니다.
설정에서 등록과 상태 확인을 안내합니다.

마지막으로 인터넷과 파일 상태를 확인합니다.
링크 영상이 공개 상태인지, 저장 공간이 충분한지, 결과 파일이 다른 프로그램에서 열려 있지 않은지 확인합니다.
이렇게 확인해도 안 되면 오류 문구와 화면 캡처를 요청합니다.


## 41. 사용자가 이해하기 쉬운 답변 예시

### 질문: 장면 매칭을 눌렀는데 안 돼요.
답변: 장면 매칭은 대본, 음성, 소스 영상 분석이 모두 있어야 작동합니다. 먼저 1. 영상 준비에서 소스 영상 분석이 끝났는지 확인하고, 2. 대본에서 음성생성을 완료한 뒤 다시 장면 매칭을 눌러보세요.

### 질문: 내보내기가 안 돼요.
답변: 내보내기는 편집 준비가 끝난 뒤에 가능합니다. 5. 최종편집에서 편집준비를 먼저 완료하고, 미리보기가 정상인지 확인한 다음 다시 내보내기를 눌러보세요.

### 질문: 제미나이 키가 없다고 나와요.
답변: 영상 분석이나 대본 생성에 필요한 키가 설정에 등록되지 않은 상태입니다. 왼쪽 설정으로 이동해서 Gemini API 관리 영역에 키를 추가한 뒤 다시 시도하세요.

### 질문: 원본 자막이 새 자막이랑 겹쳐요.
답변: 원본 영상에 이미 들어 있던 자막이 남아 있어서 겹치는 상황입니다. 작업실의 4. 자막 정리에서 해당 장면 영상을 선택하고 자막 제거나 자막 블러를 적용해보세요.

### 질문: 쿠팡 후보가 이상해요.
답변: 검색 단서가 넓어서 관련 없는 상품이 섞였을 수 있습니다. 제품명, 색상, 용도처럼 더 구체적인 단어를 넣고 다시 검색해보세요.

### 질문: 제품찾기 검색 횟수를 다 썼다고 나와요.
답변: 오늘 사용할 수 있는 원본 영상 찾기 횟수를 모두 사용한 상태입니다. 다음 날 다시 시도하거나, 꼭 필요한 검색어만 정리해서 검색하는 것이 좋습니다.

### 질문: 음성은 있는데 장면 길이가 어색해요.
답변: 음성 길이와 영상 구간 길이가 잘 맞지 않는 상태일 수 있습니다. 3. 장면 구성에서 해당 장면을 열고 선택 구간의 시작과 끝을 조정한 뒤 미리보기로 확인하세요.

### 질문: 배경음악 때문에 말이 잘 안 들려요.
답변: 배경음악 볼륨이 말소리보다 큰 상태입니다. 5. 최종편집에서 배경음을 열고 볼륨을 낮춘 뒤 미리보기로 다시 확인하세요.

### 질문: 자막 제거가 지저분해요.
답변: 자막 뒤 배경이 복잡하면 완벽하게 지워지기 어려울 수 있습니다. 자막 블러로 바꾸거나 범위를 좁게 조정한 뒤 다시 처리해보세요.

### 질문: 타입캐스트 음성이 안 만들어져요.
답변: 타입캐스트가 무료 계정 사용을 일시적으로 막은 경우일 수 있습니다. 이것은 쇼핑렌즈 문제가 아니라 타입캐스트 쪽 문제이니, 타입캐스트에 문의하시거나 급하실 때는 ElevenLabs로 바꿔 음성을 만들어보세요.

### 질문: 프로젝트가 안 보여요.
답변: 저장하지 않은 작업은 프로젝트 메뉴에서 다시 열기 어렵습니다. 작업실 위쪽에서 프로젝트 이름을 입력하고 저장했는지 먼저 확인해보세요.


## 42. 좋은 작업 습관

프로젝트 이름은 짧고 알아보기 쉽게 만듭니다.
예를 들어 상품명과 날짜를 함께 넣으면 나중에 찾기 쉽습니다.
너무 긴 이름은 저장이나 내보내기에서 문제가 될 수 있습니다.

트렌드 영상은 참고용으로 보고 그대로 따라 하지 않습니다.
반응이 좋은 구조, 첫 문장, 제품 보여주는 방식만 참고합니다.
대본과 장면은 내 제품에 맞게 다시 만드는 것이 좋습니다.

원본 영상은 너무 많이 넣지 않습니다.
필요한 영상만 넣어야 분석과 장면 매칭이 빨라집니다.
비슷한 영상이 많으면 결과가 오히려 헷갈릴 수 있습니다.

대본은 음성 생성 전에 꼭 읽어봅니다.
어색한 문장을 그대로 음성으로 만들면 뒤에서 수정할 일이 많아집니다.
문장을 짧게 다듬으면 쇼츠에서 보기 좋습니다.

장면 구성 후에는 미리보기를 꼭 확인합니다.
말하는 내용과 화면이 맞는지, 제품이 잘 보이는지, 장면 전환이 어색하지 않은지 봅니다.
문제가 있으면 최종편집 전에 고치는 것이 빠릅니다.

최종편집에서는 한 번에 많은 효과를 넣지 않습니다.
자막, 배경음, AI 효과음, 필터가 모두 강하면 영상이 산만해질 수 있습니다.
핵심 제품이 잘 보이고 말소리가 잘 들리는 것이 가장 중요합니다.

내보내기 전에는 저장 공간을 확인합니다.
영상 작업은 임시 파일이 생길 수 있어 생각보다 많은 공간이 필요합니다.
공간이 부족하면 내보내기 중에 멈출 수 있습니다.


## 43. 쇼핑렌즈 전체 요약

쇼핑렌즈는 트렌드를 찾고, 원본 영상을 고르고, 쇼츠 대본과 음성을 만든 뒤, 장면을 구성하고 최종 영상까지 내보내는 프로그램입니다.
가장 중요한 흐름은 저장, 영상 준비와 분석, 대본, 음성, 장면 구성, 자막 정리, 최종편집, 내보내기이며, 음성이 장면보다 먼저라는 점을 기억하면 됩니다.
문제가 생기면 어느 단계가 아직 준비되지 않았는지 먼저 확인하면 대부분 해결할 수 있습니다.

사용자가 챗봇에 질문하면 화면 이름, 누른 버튼, 표시된 안내 문구를 기준으로 답변합니다.
답변은 짧고 쉽게 하되, 사용자가 바로 따라 할 수 있는 순서로 안내합니다.
이 문서의 목적은 사용자가 쇼핑렌즈를 혼자서도 끝까지 사용할 수 있게 돕는 것입니다.

# 쇼핑렌즈(ShoppingLens) 완벽 사용 가이드

## 쇼핑렌즈는 윈도우 전용 프로그램입니다.
- 쇼핑렌즈는 사용자의 컴퓨터에 설치되어 동작하는 로컬 프로그램입니다.
- 1개의 인증키는 1대의 PC에서만 사용 가능합니다.
- 컴퓨터 사양에 따라 일부 기능의 속도가 달라질 수 있습니다. (자막 삭제 속도, AI 효과음 생성 등)

## 개요
쇼핑렌즈(ShoppingLens)는 AI 기반 쇼핑 쇼츠 자동 제작 도구입니다.
트렌드 파악, 벤치마킹 분석, 원본 소스 찾기, 대본 생성, 음성(TTS) 생성,
대본과 장면 자동 매칭, 자막 제거, 최종편집, 썸네일 제작, 쿠팡 파트너스 링크,
자동 업로드까지 쇼핑 쇼츠 제작의 전 과정을 하나의 프로그램에서 처리할 수 있습니다.

쇼핑 쇼츠는 타이밍과 소재 수집이 굉장히 중요합니다.
쇼핑렌즈는 매일 자동으로 인기 쇼핑 영상을 수집해 주기 때문에,
빠르게 소재를 잡아 멀티 플랫폼(유튜브, 틱톡, 인스타그램 등)에 올려 수익화할 수 있습니다.

## 프로그램 전체 구조

쇼핑렌즈는 좌측 사이드바의 메인 메뉴와, 작업실 내부의 단계별 작업 흐름으로 구성되어 있습니다.

### 메인 메뉴 (좌측 사이드바)
- 트렌드: 인기 쇼핑 영상 확인(쇼핑 트렌드)과 원본 소스 수집(제품 찾기)
- 작업실: 영상 제작의 핵심 공간 (단계별 작업 흐름)
- 프로젝트: 저장된 프로젝트 관리
- 도구: 독립 도구 모음 (자막 지우개 등)
- 설정: 인증키, API 키, 음성, 서비스 연동 설정
- 버전 표시: 현재 사용 중인 버전을 확인할 수 있습니다.
- 챗봇 버튼(물음표): 쇼핑렌즈 도우미 AI에게 사용법을 즉시 물어볼 수 있습니다.
- 홈페이지 바로 가기: 홈페이지로 이동합니다.

### 작업실 작업 흐름 (7단계)
1. 영상 준비 - 소스 영상 다운로드와 AI 분석 (장면 분할 + 장면별 내용 분석)
2. 대본 - 벤치 스타일 분석 + 소스 분석 결과를 토대로 AI 대본 생성, 음성(TTS) 생성
3. 장면 구성 - 대본 문장과 소스 장면을 자동 매칭, 세부 교체와 편집
4. 자막 정리 - 사용할 장면 부분만 자막 제거 또는 블러 처리
5. 최종편집 - 편집 준비(미리보기 생성), 자막 스타일, 템플릿, AI 효과음, 썸네일, 내보내기
6. 쿠팡 제품 찾기 - 영상 속 제품을 쿠팡에서 자동 검색, 수익화 링크 생성
7. 자동 업로드 - 버퍼 연동으로 여러 채널에 즉시 발행 또는 예약 발행

## 다운로드 및 설치

### 다운로드
1. 다운로드 페이지에서 쇼핑렌즈를 다운로드합니다.
2. 다운로드 페이지 우측에 있는 '쇼렌 AI 효과음'은 별도의 프로그램입니다. AI 효과음 기능을 사용할 분만 아래 영상을 참고하여 설치하세요.
영상 링크 : https://youtu.be/6nu6UzdTjZM

### 설치
1. 다운로드한 설치 파일을 더블 클릭하여 설치합니다.
2. 컴퓨터에 1.5GB 이상의 여유 공간이 필요합니다. 용량이 부족하면 컴퓨터 용량을 비운 뒤 실행해 주세요.
3. 되도록 바탕 화면에 설치하는 것을 권장합니다.
4. 설치는 약 1분에서 2분 정도 걸립니다.
5. 설치가 완료되면 마침 버튼을 눌러주세요. 잠시 후 인증키 입력 창이 나타납니다.
6. 설치가 완료되면 프로그램 바로 열기 파일과 쇼핑렌즈 폴더가 생성됩니다.

### 설치 폴더 구성
쇼핑렌즈 폴더를 열면 여러 폴더와 파일이 있습니다. 주요 항목은 다음과 같습니다:
- 쇼핑렌즈 오토 폴더: 크롬에 설치하는 확장 프로그램 (그록 AI 영상 생성, 각 플랫폼 영상 즉시 다운로드용)
- 프로젝트 폴더: 작업한 프로젝트들이 저장되는 폴더
- 배경음악 폴더: 자주 쓰는 배경음악 파일을 넣어두면 최종편집에서 바로 사용할 수 있습니다.
- uninstall 파일: 프로그램을 삭제할 때 사용하는 파일

### 삭제(uninstall) 시 주의
- uninstall을 실행해도 프로젝트 폴더는 삭제되지 않습니다.
- 작업한 내용이 사라질까 염려하지 않으셔도 됩니다.

## 쇼핑렌즈 오토 (크롬 확장 프로그램)

### 쇼핑렌즈 오토란?
- 그록(Grok)을 이용한 AI 영상 생성과, 틱톡, 도우인, 샤오홍슈, 인스타그램에서 영상을 보다가 즉시 소스를 다운로드하는 기능을 해주는 크롬 확장 프로그램입니다.

### 설치 방법
1. 크롬 브라우저를 열고 우측 상단의 점 세 개 버튼을 누릅니다.
2. 확장 프로그램 > 확장 프로그램 관리를 클릭합니다.
3. 우측 상단의 개발자 모드를 켭니다.
4. 좌측에 생긴 '압축 해제된 확장 프로그램을 로드합니다' 버튼을 클릭합니다.
5. 설치된 쇼핑렌즈 폴더로 들어가서, 그 안의 쇼핑렌즈 오토 폴더가 선택된 상태로 폴더 선택을 누릅니다.
6. 설치가 완료됩니다.

### 확장앱 업데이트 (중요)
- 쇼핑렌즈 프로그램이 업데이트되면 확장 프로그램도 같이 업데이트해야 합니다.
- 방법 1: 크롬 확장 프로그램 관리 화면에서 쇼핑렌즈 오토의 새로 고침 버튼을 누릅니다.
- 방법 2: 확장 프로그램을 삭제한 뒤 처음 설치했던 방법으로 다시 설치합니다.

### 고정(핀)과 사이드바
- 크롬 우측 상단의 퍼즐 버튼을 누르면 쇼핑렌즈 오토가 보입니다.
- 핀 버튼을 누르면 고정되어 바로 누를 수 있습니다.
- 클릭하면 사이드바 형태로 열립니다.

### 인증 연동
- 확장앱에 인증키를 따로 넣을 필요가 없습니다.
- 본 프로그램(쇼핑렌즈)에서 인증을 완료하면 확장앱도 자동으로 인증됩니다.
- 인증 전에는 인증 안내 창이 표시됩니다.

### 플랫폼별 다운로드 버튼
- 틱톡: 영상 화면과 탐색 화면에 다운로드 버튼이 생기며, 누르면 즉시 다운로드됩니다.
- 인스타그램: 영상 화면에 다운로드 버튼이 표시됩니다.
- 도우인: 영상 화면에 다운로드 버튼이 표시됩니다.
- 샤오홍슈: 사용자에 따라 매번 QR코드 로그인이 필요한 경우가 있습니다.
- 링크 복사, 붙여넣기 과정 없이 영상을 보다가 바로 다운로드할 수 있는 것이 장점입니다.

## 처음 시작하기: 인증 및 공지 확인

### 인증키 입력
1. 프로그램을 실행하면 인증키 입력 창이 나타납니다.
2. 인증키를 입력하고 확인을 누르면 "컴퓨터에 연결되었습니다"라는 안내가 뜹니다.
3. 확인을 누르면 프로그램이 시작됩니다.
- 쇼핑렌즈는 로컬 프로그램이기 때문에 하나의 인증키는 하나의 PC에서만 사용 가능합니다.

### 공지사항 팝업 (꼭 확인하세요)
- 프로그램 시작 시 팝업 공지사항이 뜹니다.
- 중요한 내용은 항상 공지에 기록되므로 반드시 확인하시기 바랍니다.
- 공지의 게시일이 바뀌었다면 내용이 갱신된 것이니 꼭 다시 확인하세요.
- 공지에서 확인할 수 있는 내용 예시:
  - 자막 제거 사용법 영상
  - 타입캐스트 20만 무료 크레딧 받는 법 (튜브렌즈가 타입캐스트 최초 파트너십, 첫 달 무료 20만 크레딧)
  - 버텍스 300달러 크레딧 받는 법 영상 (https://youtu.be/x4kTl5yuTMY)
- 구글 관련 내용은 정책이 자주 바뀌므로, 해당 영상의 고정 댓글과 더보기란도 함께 확인하세요.

### 저작권 및 이용 책임 안내
- 타인의 영상을 사용하는 것은 원작자가 문제를 제기하면 문제가 될 수 있습니다.
- 어떤 영상을 사용하든 그 책임은 사용자 본인에게 있습니다.
- 안전하게 사용하는 방법:
  1. 원작자에게 영상 사용을 허락받기
  2. 유튜브에서 검색 후 우측 상단의 필터 버튼을 누르고, 크리에이티브 커먼즈를 선택해서 나오는 영상 사용하기
- 쇼핑렌즈는 타인의 영상을 무분별하게 사용하는 것을 권장하지 않습니다.

## 설정

설정 메뉴에서 쇼핑렌즈 사용에 필요한 키와 연동을 관리합니다.
왼쪽 서브 메뉴: 구글키(제미나이, 유튜브), 음성 설정(일레븐랩스, 타입캐스트), 서비스 연동(쿠팡 파트너스, 버퍼)

### 인증키 관리
- 설정 제일 상단에서 본인의 인증키를 확인할 수 있습니다.
- 우측에서 만료일을 확인할 수 있습니다.

### 구글키 관리 (제미나이 API) - 필수
쇼핑렌즈는 영상 분석, 대본 생성, 장면 매칭 등에 제미나이 API를 사용합니다.
등록 방식은 두 가지입니다.

#### 방식 1: 구글 AI 스튜디오의 제미나이 API 키
- 가장 받기 쉬운 방법입니다.
- 쇼핑렌즈는 이미지 생성을 하지 않기 때문에 무료 제미나이 API 키로도 사용이 가능합니다.
- 다만 구글이 무료 API 키의 우선순위를 낮게 두고 있어 다음 한계가 있습니다:
  - 하루 할당량이 매우 적습니다. (하루 20번도 안 될 수 있음)
  - 과부하가 자주 일어나 429 에러나 503 에러가 자주 뜹니다.
- 키는 여러 개를 등록할 수 있습니다. 하나가 한도에 걸리면 다음 키로 자동 로테이션됩니다.
- 주의: 구글 계정 하나당 제미나이 키 하나만 받아서 사용해야 합니다.
  - 10개를 등록하려면 10개의 구글 계정에서 각각 키를 받아야 합니다.
- 받는 법: 우측의 '제미나이 키 받는 법' 버튼을 누르면 안내 영상이 나옵니다.

#### 방식 2: 버텍스 AI JSON 등록
- 버텍스 모드를 선택하면 우측 버튼이 '버텍스 키 받는 법'으로 바뀌고, 해당 안내 영상을 볼 수 있습니다.
- 버텍스 JSON 받는 법 및 300달러 무료 크레딧 받는 법 영상 링크 : https://youtu.be/x4kTl5yuTMY
- 구글은 신규 사용자에게 300달러(약 45만원) 무료 크레딧을 제공합니다. 3달 동안 사용할 수 있습니다. (구글 정책은 변경될 수 있습니다)
- 유료 제미나이 키와 동일한 등급이라 우선순위가 높고 넉넉하게 사용할 수 있습니다.
- 쇼핑렌즈는 이미지 생성을 하지 않기 때문에 3달 동안 300달러를 다 못 쓸 수도 있을 만큼 넉넉합니다.
- 받는 과정이 다소 까다로울 수 있으니 안내 영상을 그대로 따라 하세요.
- 받은 JSON 파일을 드래그 앤 드롭으로 등록합니다.

#### API 테스트
- 등록 후 'API 테스트' 버튼을 누르세요.
- 제대로 등록되었다면 석세스(success) 문구와 함께 강아지 이미지가 표시됩니다.

### 유튜브 API 관리 (선택)
- 트렌드의 키워드 검색과 댓글 확인에 사용됩니다.
- 필수가 아닌 선택 사항입니다.
- '유튜브 키 받는 법' 버튼의 영상을 참고해 등록하세요.
- 관리에서 여러 개를 등록해서 사용할 수 있습니다.

### 음성 설정 (TTS)
글자를 음성으로 바꿔주는 서비스를 등록합니다. 일레븐랩스와 타입캐스트 두 가지를 지원합니다.

#### 일레븐랩스 (ElevenLabs)
- 무료 가입 시 한 달에 1만 크레딧이 제공됩니다. (대략 1만 자 분량, 정책 변경 가능)
- 다음 달에 다시 1만 크레딧이 채워집니다.
- 한국어로 퀄리티 높은 목소리를 쓰려면 유료 사용을 권장합니다.
- '키 받는 법' 버튼의 영상을 참고해 등록하세요.

#### 타입캐스트 (Typecast)
- 튜브렌즈가 타입캐스트와 최초 파트너십을 맺어, 첫 달 20만 크레딧을 무료로 받을 수 있습니다. (공지 팝업의 영상 참고, 정책 변경 가능)
- '타입캐스트 키 받는 법' 버튼의 영상을 참고해 등록하세요.
- 주의: 타입캐스트는 한 명의 사용자가 2개 이상의 무료 계정으로 API를 사용하려고 하면 차단됩니다.
  - 무료로 사용할 때는 반드시 하나의 아이디로만 사용하세요.

### 서비스 연동

#### 쿠팡 파트너스
- 본인의 쿠팡 파트너스 API를 등록해 두면, 쿠팡 제품 찾기에서 찾은 제품 링크가 본인의 수익화 링크로 즉시 자동 변환됩니다.
- '키 받는 법' 영상을 참고해 등록하세요.

#### 버퍼 (Buffer) 계정 관리
- 버퍼 사이트에 본인의 유튜브, 틱톡, 인스타그램, Threads, X.com 채널을 등록하고 버퍼 키를 쇼핑렌즈와 연동하면, 만든 영상을 채널마다 수동으로 올릴 필요 없이 자동으로 업로드할 수 있습니다.
- 버퍼 무료 계정에는 총 3개의 채널을 등록할 수 있습니다. (버퍼 정책은 변경될 수 있습니다)
  - 유튜브만 3개도 가능하고, 유튜브 1개 + 틱톡 1개 + 인스타 1개 같은 조합도 가능합니다.
- 더 많은 채널을 관리하고 싶다면 다른 무료 계정을 만들어 그 키를 추가하면 됩니다.
- 쇼핑렌즈에는 총 5개의 버퍼 계정을 연결할 수 있습니다. (2026년 8월 17일 v1.4.3 업데이트로 3개에서 5개로 늘었습니다)
  - 계정 5개 x 채널 3개 = 최대 15개 채널을 관리하실 수 있습니다.
- '버퍼키 받는 법' 영상을 참고해 등록하세요.

## 트렌드 메뉴

트렌드 메뉴 상단은 2개의 탭으로 구성됩니다.
- 쇼핑 트렌드: 인기 쇼핑 영상을 확인하는 공간
- 제품 찾기: 원본 소스를 찾는 공간

### 쇼핑 트렌드 - 오늘의 트렌드
- 오늘의 트렌드, 키워드 검색, 즐겨찾기 3개의 탭으로 구성됩니다.
- 어제 / 주간 / 월간 탭에서 조회수 높은 순으로 자동 수집된 영상 100개를 확인할 수 있습니다.
  - 어제: 어제 올라온 영상 중 조회수 높은 순
  - 주간: 일주일간 조회수 높은 순
  - 월간: 한 달간 조회수 높은 순
- 별도로 검색하지 않아도 매일 자동으로 업데이트됩니다.
- 조회수 관련 정보는 1시간에 한 번씩 업데이트됩니다. 갱신 버튼이 활성화되면 눌러서 순위와 조회수 변화를 확인할 수 있습니다.
- 대부분 쇼핑 영상이지만 종종 쇼핑과 관련 없는 영상이 뜰 수도 있습니다.
- 수집 특성상 직접 촬영 영상보다 중국 플랫폼 원본을 재편집한 영상이 많이 수집됩니다. (직접 촬영 영상이 뜰 수도 있습니다)

### 쇼핑 트렌드 - 키워드 검색
- 유튜브 API를 등록해 두면 원하는 키워드로 검색할 수 있습니다.
- 예: "쿠팡템"을 검색해 어제 올라온 영상을 조회수 순으로 확인
- 검색창에 영상 주소(URL)를 붙여넣으면 해당 영상을 직접 가져올 수도 있습니다.
  - 가져온 영상은 분석, 스타일 참조, 제품 찾기에 활용할 수 있습니다.

### 쇼핑 트렌드 - 즐겨찾기와 결과 내 검색
- 영상의 별표를 누르면 즐겨찾기에 모아둘 수 있습니다.
- 영상을 하나씩 보다가 마음에 드는 것을 즐겨찾기에 두고, 그것들만 분별해서 작업하면 유용합니다.
- 우측 상단의 '결과 안에 검색' 입력창: 수집된 탑100 안에서 원하는 소재만 걸러서 볼 수 있습니다.
  - 예: "세탁"을 입력하면 세탁 관련 영상만 표시됩니다.

### 영상 팝업 (영상 카드 클릭)
- 화면을 클릭하면 해당 영상을 바로 볼 수 있습니다.
- 영상 화면에 마우스를 대고 휠을 위아래로 움직이면 볼륨이 조절됩니다.
- 하단의 속도 부분에 마우스를 대고 휠을 움직이면 재생 속도가 조절됩니다.
- 우측에는 영상 제목, 채널명, 구독자 수, 업로드 일자와 시간, 영상 길이가 표시됩니다.
- 채널명을 클릭하면 해당 채널로 바로 이동합니다.
- 조회수, 좋아요 수, 댓글 수를 확인할 수 있습니다.
- 댓글을 클릭하면(유튜브 API 등록 시) 댓글도 확인할 수 있습니다.

### 댓글 활용 팁
- 댓글에는 시청자들의 니즈가 잘 담겨 있습니다.
- 좋아요를 많이 받은 댓글 위주로 참고해서 제목을 짓거나 대본과 자막에 반영하면, 조회수 상승과 전환율 향상에 큰 도움이 됩니다.

### AI 분석
- 탑100 영상 중 상위 20개는 AI 분석이 이미 완료되어 있습니다. (완료된 것은 회색으로 표시)
- 그 외 영상은 AI 분석 버튼을 눌러 직접 분석할 수 있습니다.
- '지금 분석'을 다시 눌러 새로 분석하는 것도 가능합니다.
- 더 나은 영상을 만들려면 분석 결과를 공부하는 것을 적극 권장합니다.

#### AI 분석 결과에 포함되는 내용
- 제품 정보: 어떤 제품인지, 특징이 무엇인지
- 원본 찾기 추천 검색어: 한글, 영어, 중국어 키워드
  - 키워드를 클릭하면 유튜브, 틱톡, 인스타, 샤오홍슈, 도우인 검색 메뉴가 떠서 즉시 검색할 수 있습니다.
  - 검색 결과 화면에 뜨는 다운로드 버튼을 누르면 자동으로 다운로드되어 소스 확보가 빠르게 끝납니다.
  - 영어 키워드는 유튜브, 틱톡, 인스타에서, 중국어 키워드는 샤오홍슈, 도우인에서 사용하는 것을 권장합니다.
- 영상 흐름: 영상이 어떤 순서와 구성으로 만들어졌는지
- 떡상 요인: 이 영상이 조회수가 높은 이유 분석
- 후킹 방식: 세 가지로 나누어 분석합니다.
  - 비주얼 훅: 영상 초반을 어떤 장면으로 잡았는지
  - 멘트 훅: 초반 멘트를 어떤 것으로 치고 들어오는지
  - 후킹 포인트: 영상 전반의 후킹 포인트
- CTA 방식: 행동 유도가 있는 경우 어떤 식으로 유도하는지 (없으면 없다고 표기)

### 제품 찾기 버튼과 스타일 분석 버튼
- 제품 찾기 버튼: 이 영상의 제품을 분석해 원본 영상 소스를 찾아줍니다. (제품 찾기 탭으로 자동 이동)
  - 영상 팝업 안에도 있고 목록 화면에도 있습니다.
- 스타일 분석 버튼: 이 영상의 말투, 흐름, 후킹 등을 분석해서 대본 생성에 참조할 수 있게 합니다.
  - 스타일 분석을 해두면 원할 때마다 그 스타일로 대본을 생성할 수 있습니다.
  - 분석 중에 창을 닫고 작업실로 넘어가도 분석은 이어서 진행됩니다.

## 트렌드 - 제품 찾기 탭

벤치마킹할 영상의 원본 소스를 여러 플랫폼에서 자동으로 수집하는 공간입니다.

### 제품 찾기 실행
- 쇼핑 트렌드에서 제품 찾기 버튼을 누르면 이 탭으로 자동 이동합니다.
- 해당 영상에서 키워드를 추려내고, 그 키워드로 유튜브, 틱톡, 인스타, 샤오홍슈, 도우인에서 후보 영상을 수집합니다.
- 플랫폼별로 몇 개를 찾았는지 표시됩니다. (특정 플랫폼에서 검색이 안 될 수도 있습니다)

### 남은 검색 횟수
- 우측 상단에 남은 검색 횟수가 표시됩니다.
- 하루에 10번 수집이 가능합니다.
- 다음 날로 넘어가도 누적되지는 않습니다.
- 10번이면 하루 2개에서 3개 이상의 영상을 만들기에 충분하고, 각 플랫폼에서 확장앱 다운로드 버튼으로 직접 수집하는 방법도 있습니다.

### 키워드 활용
- 화면에 영어 키워드와 중국어 키워드가 배치되어 있습니다.
  - 영어 키워드 공간: 틱톡, 인스타, 유튜브에서 검색
  - 중국어 키워드 공간: 도우인, 샤오홍슈에서 검색
- 키워드에서 마우스 우클릭을 하면 원하는 플랫폼으로 들어가 즉시 검색할 수 있습니다.
- 다른 키워드를 클릭하면 검색 키워드가 바뀝니다.
- 본인이 생각한 키워드를 직접 기재해서 검색하는 것도 가능합니다.

### 드래그 앤 드롭으로 검색
- 가지고 있는 영상 파일을 드래그 앤 드롭으로 넣으면, AI가 영상을 분석해 새 키워드를 뽑아 다시 검색해 줍니다.
- 이미지도 동일하게 가능합니다. 이미지를 넣으면 분석 후 키워드를 뽑아 자동으로 검색합니다.

### 링크로 제품 찾기
- 제일 위 입력칸에 유튜브, 틱톡, 인스타, 도우인, 샤오홍슈 링크를 넣으면, 자동으로 다운로드하고 분석해서 키워드를 추출한 다음 제품을 찾아줍니다.

### 이 영상으로 제품 찾기 (1.2.8 버전 이후)
- 스토리 방식의 벤치 영상은 본 제품과 관련 없는 장면이 섞여 있어, AI가 혼동해 다른 제품이 뜨기도 합니다.
- 이럴 때는 같은 제품이 잘 나오는 영상을 하나 찾아 후보에 추가하세요.
- 그 영상에 마우스 우클릭을 하면 '이 영상으로 제품 찾기' 버튼이 생깁니다.
- 이 버튼을 누르면 해당 제품으로만 이루어진 영상을 기준으로 더 정확한 키워드를 뽑아, 제품에 가까운 영상 위주로 더 많이 찾아줍니다.

### 소스 후보 고르기 요령
- 썸네일을 보고 내가 찾는 제품 같으면 영상을 클릭해서 시청하세요. (클릭 재생, 휠 볼륨 조절 가능)
- 약간의 시간을 투자해 꼼꼼하게 보는 것을 권장합니다.
- 원테이크 영상보다 컷별로 분할된 영상이 좋습니다. 분할된 장면들을 AI가 자동으로 잘라서 붙여주기 때문입니다.
- 자막이 없는 소스가 가장 좋습니다. 중국 플랫폼(샤오홍슈 등)에는 자막 없는 영상이 많습니다.
- 자막이 있다면 얇고 적은 것, 제품을 가리지 않는 것이 좋습니다. 자막이 3줄씩 크게 있으면 지웠을 때 좋아 보이지 않을 수 있습니다.

### 소스 추가와 영상 준비로 이동
- 마음에 드는 영상에서 추가를 누르면 초록색 테두리가 생겨 어떤 영상을 추가했는지 알 수 있습니다.
- 총 8개까지 추가할 수 있습니다.
- 추가를 마쳤으면 '영상 준비로 이동'을 누릅니다.

## 작업실 1단계: 영상 준비

### 프로젝트 생성과 자동 다운로드
1. '영상 준비로 이동'을 누르면 작업실의 영상 준비 화면으로 넘어갑니다.
2. 프로젝트가 없다면 프로젝트 이름을 정하는 창이 뜹니다. 이름을 넣고 엔터를 누르면 프로젝트가 생성됩니다.
3. 제품 찾기에서 추가한 영상들이 순차적으로 자동 다운로드됩니다.

### 화면 구성과 기능
- 영상을 더블클릭하면 큰 화면으로 다시 볼 수 있습니다. (휠 볼륨 조절, 하단 속도 조절)
- 상단 입력창에 유튜브, 틱톡, 인스타, 도우인, 샤오홍슈 링크를 넣어 영상을 추가로 다운로드할 수 있습니다.
- 다운로드 폴더 버튼을 누르면 다운로드된 파일을 확인할 수 있습니다.

### 영상 분석 (필수)
- 소스를 다 모았으면 영상 분석 버튼을 누릅니다.
- 수집한 영상들을 분석해서 장면을 쪼개고, 장면별로 어떤 내용인지 AI가 분석합니다.
- 영상마다 몇 개의 장면으로 나뉘었는지 표시되고, 순차적으로 진행되어 하단에 완료 표시가 뜹니다.
- 영상 6개 기준 약 3분 정도 걸립니다.
- 분석 후 영상을 더블클릭하면 제품이 무엇인지, 소스의 역할, 핵심 내용, 전체 분석 내용, 장면별 내용을 확인할 수 있습니다.

## 작업실 2단계: 대본과 음성(TTS)

대본 탭에서 대본 생성과 음성(TTS) 생성을 모두 진행합니다.
대본 부분은 크게 두 가지 섹션으로 나뉩니다.
- 스타일 섹션: 벤치마킹할 스타일을 관리
- 대본 생성 섹션: 스타일과 소스 분석을 토대로 대본 생성

### 스타일 섹션
- 벤치하고 싶은 영상이 있다면 링크를 넣어 분석시킬 수 있습니다.
- 기본으로 4개의 스타일이 세팅되어 있습니다:
  1. 가치형: 저렴한 제품의 가치를 높여서 대본을 짜는 방식
  2. 사용 전후 비교형: 사용 전과 후를 비교해서 대본을 생성
  3. 정체공개형: 처음에 무엇인지 제대로 알려주지 않고 궁금증을 유발하는 방향
  4. 베스트 추천형: 여러 제품을 소개할 때 베스트 1, 2, 3으로 뽑아내는 방식

### 벤치 영상 스타일 분석 (권장)
- 일반적으로는 트렌드 탭에서 조회수 높은 영상을 골라 스타일 분석을 눌러 사용합니다.
- 분석이 완료되면 대본 탭 스타일 섹션 하단에 그 스타일이 추가됩니다.
- 스타일을 클릭하면 후킹, 영상 흐름, 제품 노출 방식, CTA 유무, 작성 지침 분석 내용을 확인할 수 있습니다.

### 내 스타일 직접 만들기 (2026년 8월 18일 v1.4.4 추가)

기본 렌즈 스타일 4개 말고, 원하는 말투와 대본 구성을 직접 적어 두고 반복해서 쓸 수 있습니다.

#### 어디에 있나요
2. 대본 화면에서 벤치 스타일 목록 오른쪽 위에 있는 [＋ 내 스타일 추가] 버튼을 누르시면 됩니다.

#### 만드는 방법
1. [＋ 내 스타일 추가]를 누릅니다.
2. 스타일 이름에 알아보기 쉬운 이름을 적습니다.
3. 사용자 지시에 원하는 말투와 대본 작성 방식을 적습니다.
4. [저장]을 누릅니다.
5. 저장한 스타일은 기본 렌즈 스타일 4개 바로 아래에 나옵니다.
6. 만든 스타일 카드를 선택한 뒤 평소처럼 대본을 생성합니다.

내 스타일은 여러 개 만드실 수 있습니다.

#### 사용자 지시에는 무엇을 적나요
원하는 내용을 자유롭게 적으시면 됩니다. 아래를 함께 적으면 결과가 더 분명해집니다.
- 어떤 말투로 쓸지
- 첫 문장을 어떻게 시작할지
- 어떤 순서로 설명할지
- 제품의 어떤 장점을 강조할지
- 마지막 문장을 어떻게 끝낼지
- 쓰지 않았으면 하는 표현이 있는지

예시입니다.
"친한 친구에게 추천하듯 자연스럽게 말해 주세요. 첫 문장은 제품의 의외성을 강하게 보여 주세요.
문제 상황, 제품 사용, 달라진 결과 순서로 전개하고 마지막에는 구매를 강요하지 말고 궁금증이 남게 끝내 주세요."

프롬프트 작성 형식은 정해져 있지 않습니다.
평소 말하듯 적어도 AI가 내용을 파악해 대본에 반영합니다.

#### 만든 스타일 수정하기
내 스타일 카드 왼쪽의 색상 표시를 누릅니다.
스타일 이름이나 사용자 지시를 바꾼 뒤 [저장]을 누르시면 됩니다.
색상 표시에는 스타일 이름의 첫 글자가 나옵니다. 스타일마다 색이 달라서 여러 개를 만들어도 구분하기 쉽습니다.

#### 만든 스타일 삭제하기
내 스타일 카드 오른쪽의 [X] 버튼을 누르면 지워집니다.

#### 알아두면 좋은 점
- 내 스타일은 한 프로젝트에서만 쓰는 것이 아니라 모든 프로젝트에서 같이 씁니다.
- 내 스타일은 이 컴퓨터에 저장되므로 쇼핑렌즈를 지웠다가 다시 설치해도 그대로 남습니다.
- 스타일 이름과 사용자 지시는 둘 다 적으셔야 하고, 이미 저장된 이름과 같은 이름은 쓸 수 없습니다.
- 대본을 만들기 전에 쓰실 내 스타일 카드가 선택되어 있는지 확인해 주세요. 선택된 카드는 파란색 테두리로 표시됩니다.
- 사용자 지시는 원본 소스의 제품과 내용을 바꾸는 기능이 아니라, 대본의 말투와 구성 방향을 정하는 기능입니다.

### 대본 생성
1. 대본 길이를 정합니다. (예: 15초로 설정하면 15초 내외로 생성)
2. 원하는 스타일을 선택합니다.
3. 대본 생성을 누르면, 영상 준비에서 분석한 소스 내용과 선택한 스타일을 토대로 대본이 생성됩니다.

### 대본 수정
- 생성된 대본은 직접 수정할 수 있습니다.
- 예를 들어 첫 문장이 마음에 안 들면 원하는 문장으로 바꿔주면 됩니다.
- AI가 만든 대본을 그대로 쓰기보다, 수정할 부분이 보이면 다듬는 것을 권장합니다.

### 대본 사전지시
- 대본을 만들기 전에 지시하고 싶은 사항이 있다면 '대본 사전지시'에 미리 글을 작성해 두세요.
- 그 내용을 반영해서 대본이 생성됩니다.

### 음성(TTS) 생성

대본이 완성되면 같은 대본 탭에서 음성을 생성합니다.

#### 서비스 선택과 크레딧 확인
- 설정에서 등록한 일레븐랩스 또는 타입캐스트로 음성을 만듭니다.
- 서비스 옆에 남은 크레딧이 표시됩니다.

#### 목소리 선택
- 목소리 선택을 누르면 목소리 목록이 뜨고, 모두 미리 듣기가 가능합니다.
- 자주 쓰는 목소리는 옆의 별표를 눌러 즐겨찾기 해두면, 다음에 열었을 때 제일 상단에 표시됩니다.

#### 읽는 속도
- 속도를 선택할 수 있습니다.
- 쇼핑 쇼츠는 이탈을 줄이기 위해 빠름 또는 더 빠름을 권장합니다.

#### 음성 생성
- 상단의 음성 생성 버튼을 누르면 전체 대본이 음성으로 생성됩니다.
- 완료되면 하단에서 전체 듣기가 가능합니다.

#### 문장별 부분 재생성 (크레딧 절약)
- 쇼핑렌즈는 문장별로 음성 생성이 가능합니다.
- 특정 문장만 다시 만들고 싶으면 해당 문장의 마이크 버튼을 누르세요. 그 문장만 재생성되어 크레딧을 아낄 수 있습니다.
- 활용 예시 1: TTS가 잘못 읽는 경우
  - 예를 들어 "X 라지 사이즈"를 "엑셀 사이즈"로 읽는다면, 대본에서 그 부분을 한글로 "엑스 라지 사이즈"로 바꾼 뒤 그 문장만 재생성하면 됩니다.
- 활용 예시 2: 특정 문장의 볼륨이 약하게 들리는 경우
  - 해당 문장만 다시 생성하면 됩니다.
- 정리: 전체 생성은 상단의 음성 생성 버튼, 부분 수정은 문장의 마이크 버튼, 전체 듣기는 하단에서 하시면 됩니다.

#### 타입캐스트 차단 주의
- 음성 생성 시 "타입캐스트에서 음성 생성이 일시적으로 차단되었습니다"라고 뜰 수 있습니다.
- 타입캐스트는 한 명의 사용자가 2개 이상의 무료 계정으로 API를 사용하려고 하면 차단합니다.
- 무료로 사용할 때는 반드시 하나의 아이디로만 접속하세요.
- 크레딧이 있는 정상 계정으로 변경하면 다시 생성됩니다.

## 작업실 3단계: 장면 구성

쇼핑렌즈의 핵심 기능 중 하나인 장면 매칭이 있는 탭입니다. 대본과 소스 장면을 자동으로 매칭해 줍니다.

### 화면 구성
- 위: 장면 구성 섹션 (대본 문장별 카드)
- 아래: 소스 섹션 (소스별 장면 카드)

### 소스 섹션
- 소스 1부터 4까지 표시되고, 아래 버튼을 누르면 소스 5부터 8이 나타납니다. (페이지 2개로 나뉨)
- 영상 준비에서 분석을 완료하면 소스들이 장면별로 전부 나뉘어 표시됩니다.
- 장면 카드를 클릭하면 해당 장면만 반복 재생되고, 장면의 내용, 활용 포인트, 구간을 바로 확인할 수 있습니다.
- 전체 재생 버튼을 누르면 소스 영상 전체를 볼 수 있습니다.
  - 재생 중 상단의 장면 번호가 장면이 바뀔 때마다 바뀝니다.
  - 원하는 장면에서 일시정지하면 그 장면이 몇 번째인지 확인해 두었다가 교체나 사용에 활용할 수 있습니다.
- 모든 목록은 가로 형태이며, 마우스 휠을 움직이면 가로로 스크롤됩니다.
- 소스마다 색상이 다르게 표시되어 구별하기 쉽습니다.

### 장면 구성 섹션
- 대본 탭에서 만든 대본이 문장별로 카드에 들어가 있습니다.
- 각 문장의 음성이 몇 초인지 표시되어 있습니다.

### 장면 매칭 (핵심 기능)
- 장면 매칭 버튼을 누르면 각 대본 문장에 맞는 장면을 AI가 골라 자동으로 배치합니다.
- 어떤 소스의 몇 번째 장면이 배치되었는지 표시됩니다. (예: 소스 3-3은 소스 3의 세 번째 장면)
- 장면 시간이 대부분 3초에서 5초 이내로 배치되어 중복도에 걸릴 위험도 낮습니다.

### 장면 확인 (미리보기)
- 구성 카드의 썸네일을 클릭하면 TTS 음성과 함께 그 장면을 확인할 수 있습니다.
  - 장면 내용, 영상 구간, 활용 포인트 분석도 함께 표시됩니다.
- 상단의 미리보기 버튼을 누르면 배치된 장면 전체를 한 번에 이어서 확인할 수 있습니다.

### 장면 교체
- 자동 교체: 구성 카드에서 마우스 우클릭 > 장면 자동 교체를 누르면 AI가 두 번째 후보 장면으로 교체해 줍니다.
- 수동 교체:
  1. 교체하고 싶은 구성 카드를 클릭합니다. (파란색 테두리로 선택 표시)
  2. 아래 소스 섹션에서 원하는 장면을 마우스 우클릭하면 그 장면으로 바뀝니다.

### 음성 길이에 맞춘 속도 자동 조절
- 장면 길이와 음성 길이가 달라도 자동으로 시간을 계산해 맞춰줍니다.
- 장면이 음성보다 짧으면: 느리게 재생해서 맞춥니다. (슬로우 효과처럼)
- 장면이 음성보다 길면: 속도를 빠르게 해서 맞춥니다.

### 장면 합치기
- 나뉘어 있는 장면들을 합치고 싶다면 Ctrl을 누른 상태에서 원하는 장면들을 클릭합니다. (주황색으로 표시)
- 건너뛰기는 안 되고 순차적으로만 합칠 수 있습니다.
- 선택 후 마우스 우클릭 > 합치기를 누르면 장면이 합쳐집니다.
- 원하는 구성 카드를 선택하고, 합친 장면에 마우스 우클릭 > '이 장면으로 선택'을 누르면 적용됩니다.
- 다시 풀고 싶으면 마우스 우클릭 > 합치기 해제를 누르면 다시 분할됩니다.

### 영상 직접 선택 (세부 편집 팝업)
- 구성 카드에서 마우스 우클릭 > 영상 직접 선택을 누르면 팝업이 뜹니다.
- 팝업에서 할 수 있는 것:
  - 자막(대본 문장) 수정과 음성 재생성 (보통은 대본 탭에서 이미 완료했을 테니 크게 쓸 일은 없습니다)
  - 구간 반복: 현재 선택된 구간을 반복 재생으로 확인
  - 시작점을 정한 뒤 '음성 길이' 버튼을 누르면 음성 길이에 맞게 끝점이 자동 세팅됩니다.
  - 다른 소스를 즉시 선택해서 원하는 구간을 잡는 것도 가능합니다.
  - 시작 구간과 끝점을 직접 설정할 수도 있습니다.
  - 구간을 음성보다 길게 잡으면, 음성 시간 안에 다 돌아가도록 자동으로 빠르게 재생됩니다.
- 사용자가 직접 구간을 설정하면 카드 표시가 유저의 유(U)로 바뀝니다.

### AI 영상 만들기 (그록 연동, 후킹 인트로)
쇼핑렌즈의 핵심 기능 중 하나입니다. 첫 장면을 AI 영상으로 만들어 시청자가 넘길 수 없게 후킹할 수 있습니다.
1. 소스 중에서 선명하면서 제품이 잘 보이는 장면을 선택합니다.
2. AI 영상 만들기를 클릭하면 아래에 프롬프트 입력 공간이 나옵니다.
3. 어떻게 입력할지 모르겠다면 준비된 버튼 중 하나를 눌러 프롬프트를 생성하거나, 직접 입력해도 됩니다.
   - 프롬프트 생성을 누르면 선택한 이미지와 대본을 인식해서 AI 영상용 프롬프트를 만들어 줍니다.
4. AI 영상 생성을 누르면 그록 창이 열립니다.
5. 브라우저 위의 쇼핑렌즈 오토를 열면, 보고 있던 이미지와 프롬프트가 자동으로 입력되어 영상이 생성됩니다.
6. 마음에 들면 브라우저를 꺼도 됩니다. 쇼핑렌즈 화면에 생성된 영상이 자동으로 들어옵니다.
7. 원하는 구간을 선택하고 영상 직접 선택을 누르면 적용됩니다.
- 주의: AI 영상을 만들려면 슈퍼 그록에 가입하고 크롬에 미리 로그인해 두어야 합니다.

### 초기화와 카드 추가
- 우측 끝의 초기화 버튼: 처음 장면 매칭한 상태로 되돌립니다.
- 플러스(+) 버튼: 카드 사이에 새 카드를 추가합니다.
  - 다만 대본은 대본 탭에서 만들고 수정한 뒤 장면 구성으로 넘어오는 것이 훨씬 편하고 충돌이 없으므로, 거의 쓸 일이 없습니다.

## 작업실 4단계: 자막 정리

### 화면 구성
- 소스 전체를 불러오는 것이 아니라, 장면 구성에서 사용된 부분만 자동으로 잘라서 불러옵니다.
- 필요한 부분만 자막을 제거하면 되므로 시간이 크게 절약됩니다.

### 자막 지우기 실행
- 자막이 있는 영상만 골라서 처리하면 됩니다. (자막 없는 영상은 넘어가세요)
- 부분 선택: 영상을 클릭해 초록색 테두리가 생긴 것만 자막 제거
- 전체: 상단 우측의 '전체 자막 지우기'로 하나씩 전부 제거
- 더블클릭하면 영상 안에서 세부적으로 자막을 지우는 것도 가능합니다.
- 자막 지우기의 디테일한 내용은 공지 팝업에 있는 자막 제거 영상을 참고하세요.

### 자막 제거 방식과 블러 방식
- 자막 제거: 자막을 지우고 배경을 채우는 방식
  - 그래픽 카드가 있으면 빠르게, 없으면 CPU로 천천히 처리됩니다.
- 자막 블러: 자막 부분을 흐리게 가리는 방식
  - 그래픽 카드와 상관없이 CPU로 처리됩니다.
  - 패더 조정과 블러 강도 조정이 가능합니다.

### 장면 크기 조정하기 (가장 많이 나오는 질문입니다)

⚠️ 아래와 같은 질문은 전부 여기 자막 정리 탭으로 안내하세요. 최종편집으로 안내하면 안 됩니다.
- 위아래에 검은 칸이 생겨요 / 상하 여백이 생겨요 / 좌우 검은 여백이 생겨요
- 화면이 꽉 안 차요 / 풀화면으로 바꾸고 싶어요 / 화면 가득 채우고 싶어요
- 원본이 1대1인데 9대16으로 하니까 여백이 생겨요
- 장면 구성에서는 꽉 찼는데 최종편집으로 넘어가니 작아져요 / 잘려 보여요
- 장면 하나만 확대, 축소, 이동하고 싶어요

#### 왜 이런 일이 생기나요
장면마다 가져온 소스가 다르고, 소스마다 원래 크기와 비율이 다릅니다.
1대1 영상, 가로 영상, 세로 영상이 섞여 있으면 쇼츠 비율인 9대16에 안 맞는 장면이 생깁니다.
그 남는 자리가 검은 칸으로 보이는 것입니다.

화면상으로는 비율이 맞아 보여도 실제 크기가 다른 경우가 있습니다.
그래서 최종편집으로 넘어가면 위아래가 잘리거나 여백이 생깁니다.

#### 그래서 어디서 고치나요
자막 정리 탭에서 장면을 하나씩 조정하셔야 합니다.
장면마다 소스 크기가 다르기 때문에, 장면별로 맞춰주는 것 말고는 방법이 없습니다.

최종편집에서 하는 조정은 영상 전체에 똑같이 적용됩니다.
그래서 어떤 장면은 맞고 어떤 장면은 더 어긋나게 되므로, 이 문제의 해결책이 아닙니다.

#### 방법
1. 자막 정리 탭에서 바꾸고 싶은 장면 영상을 더블 클릭해서 들어갑니다.
2. [화면 조정] 버튼을 누릅니다.
3. 플러스, 마이너스 버튼을 누르거나 마우스 휠을 굴려서 확대, 축소합니다.
4. 마우스로 끌어서 위치를 옮깁니다.

#### 저장과 적용
- 저장 버튼은 없습니다. 조정하신 뒤 그냥 나오시면 저장됩니다.
- 조정을 마치신 뒤에는 최종편집으로 가서 [편집 준비 시작]을 다시 눌러야 결과물에 반영됩니다.
- 이걸 안 누르시면 아무리 조정해도 그대로입니다. 여백이 계속 보인다고 하시면 이것부터 확인하세요.

#### 그래도 여백이 남아 있다면
- 미리보기에서 화면이 꽉 차 있지 않으면 내보내기를 해도 똑같습니다. 미리보기부터 확인하세요.
- 여백이 남은 장면이 하나라도 있으면 그 장면만 다시 조정하시면 됩니다.
- 조정한 뒤 [편집 준비 시작]을 다시 눌렀는지 확인하세요.

### 결과 확인과 재처리
- 완료된 영상에는 완료 표시가 뜹니다.
- 더블클릭하면 원본과 비교 모드로 확인할 수 있습니다.
- 글자 주변이 찌그러져 보이거나 다른 글자까지 인식된 경우:
  - 직접 부분 지정(범위)을 훑어서 늘려준 뒤 그 부분만 다시 자막 지우기를 실행하세요.
- 일그러짐이 싫다면 자막 블러 방식으로 바꿔서 처리하면 깔끔하게 가려집니다.

---

## 작업실 5단계: 최종편집

최종편집 탭에서는 미리보기 생성(편집 준비), 자막 스타일, 필터, 배경음, 템플릿,
AI 효과음, 썸네일, 화면 조정, 내보내기까지 마무리 작업을 진행합니다.

### 편집 준비
- 편집 준비 버튼을 누르면 자막 정리된 영상과 TTS를 종합해 하나의 미리보기 영상을 만들어 줍니다.
- 편집 준비 클릭 시 선택 가능한 옵션:
  - 트랜지션: 장면에서 장면으로 넘어갈 때 부드럽게 전환되는 효과
  - 영상 원본 소리 보조: 원본 소스의 소리를 그대로 나오게 하는 기능 (거의 사용하지 않습니다)
  - 무음 삭제: 표준 / 타이트 / 이어짐 중 선택
    - 쇼핑 쇼츠는 빠른 전환이 중요하므로 이 세 가지로 준비되어 있습니다.
    - 이어짐: 한 문장이 끝나는 타이밍에 살짝 겹치면서 다음 문장이 이어지는 방식 (가장 빠른 느낌)
  - 영상 효과: 효과 없음 / 자동모드 / 줌인 / 줌아웃 / 화면이동 / 유형효과 / 복합연출 / 좌우반전
    - 중복도를 벗어나기 위한 효과들입니다. 원하는 것으로 선택해 적용하세요.
- 옵션을 정한 뒤 편집준비 시작을 누르면 미리보기 영상이 만들어집니다.

### 폰트 직접 넣기 (됩니다)

⚠️ 폰트를 직접 넣는 것은 됩니다. 안 된다고 답하면 안 됩니다.

쇼핑렌즈가 설치된 폴더 안에 [폰트] 라는 폴더가 있습니다. 여기에 폰트 파일을 넣으시면 됩니다.
경로는 ShoppingLens 폴더 안의 폰트 폴더입니다.

넣을 수 있는 파일은 ttf 또는 otf 입니다.

※ 확장앱이나 확장 프로그램을 까는 것이 아닙니다.
  폰트 파일 자체를 폴더에 넣는 것입니다.
  사용자가 확장앱 이라고 물어보시면 확장자를 말씀하시는 것일 수 있으니,
  쇼핑렌즈 오토 같은 크롬 확장 프로그램 이야기로 넘어가지 마세요.
  ttf 또는 otf 파일을 폰트 폴더에 넣으시면 된다고 안내하세요.

### 자막 스타일
- 폰트: 상단에서 마우스 휠로 폰트를 바꿀 수 있습니다. 개성 있는 폰트들이 준비되어 있습니다.
  - 기본으로 들어 있는 폰트 말고 원하는 폰트를 직접 넣어서 쓰실 수도 있습니다. 위 [폰트 직접 넣기] 참고.
- 크기: 원하는 크기로 조절할 수 있습니다.
- 위치: 메인 자막을 클릭한 채 드래그해서 원하는 위치로 옮길 수 있습니다.
- 색상: A 버튼을 눌러 글씨 색상을 바꿀 수 있습니다.
- 배경: 배경을 눌러 자막 배경을 넣을 수 있습니다.
- 테두리 / 그림자: 원하는 쪽을 선택해 정도를 조절할 수 있습니다.
  - 참고 설정 예시: 그림자에서 번짐과 흐림을 13 정도, 거리를 0으로 두는 세팅
- 자막 길이: 짧게 / 보통 중 선택할 수 있습니다.

### 필터
- 필터를 클릭하면 영상의 감성을 원하는 대로 바꿀 수 있습니다.
- 본인 채널의 톤 앤 매너에 맞게 선택해서 사용하세요.

### 배경음
- 쇼핑 쇼츠는 보통 영상을 내보낸 뒤 유튜브에서 음악을 입히는 경우가 많습니다.
- 미리 넣고 싶다면 배경을 눌러 파일을 드래그 앤 드롭으로 넣으면 됩니다.
- 또는 쇼핑렌즈 폴더 안의 배경음악 폴더에 자주 쓰는 음악을 넣어두면 프로그램에서 바로 선택할 수 있습니다.

### 템플릿
템플릿을 클릭하면 우측이 템플릿 편집 화면으로 바뀝니다. 썰 형식 쇼핑 영상에 특히 유용합니다.

#### 상단 박스 / 하단 박스
- 체크하면 화면 위 또는 아래에 박스(기본 검은색)가 나타납니다.
- 색상 변경, 높이 조절, 투명도 조절이 가능합니다.
- 흐림과 그라데이션을 없애는 것도 가능합니다.

#### 텍스트 추가
- 텍스트를 원하는 만큼 계속 추가할 수 있습니다.
- 더블 클릭하면 원하는 위치에 바로 텍스트가 만들어집니다.
- Delete 키로 지울 수 있습니다.
- 텍스트를 클릭한 상태로 마우스 휠을 움직이면 크기가 조절됩니다.
- 폰트, 색상, 각도를 개별로 바꿀 수 있습니다.

#### 편집 보조 기능
- 자석 기능: 이동하다 보면 중앙 등 기준선에 살짝 달라붙어 정렬이 쉽습니다.
- Shift를 누른 채 움직이면 중앙 정렬이 수월합니다.
- Ctrl+Z: 되돌리기 / Ctrl+Shift+Z: 다시 실행
- Ctrl+C, Ctrl+V: 복제 (폰트, 크기, 각도 설정까지 그대로 복제됩니다)
- Ctrl+클릭으로 여러 개를 함께 선택한 뒤 마우스 우클릭 > 그룹 묶기를 하면 함께 이동, 확대, 축소됩니다.
- 마우스 우클릭 > 잠금: 선택되지 않게 고정 (다른 것을 편집할 때 유용) / 그룹 잠금 해제, 그룹 해제도 우클릭에서 가능합니다.
- 템플릿이 선택된 상태에서 화면을 선택하고 마우스 휠을 움직이면 화면 확대, 축소가 가능합니다. 옆의 버튼으로 크기 조절도 가능합니다.
- 미리캔버스 기능들과 흡사하다고 보시면 됩니다.

#### 템플릿 선택하기
- 템플릿 선택하기 버튼을 누르면 썰 쇼핑에 유용한 템플릿들이 정리되어 있습니다.
- 색상별, 모양별로 선택해서 사용할 수 있습니다.
- 선택 후 화면 크기와 위치를 조절하고, 텍스트 추가하기로 채널명과 제목 등을 넣으면 썰 영상 형태가 완성됩니다.

#### 템플릿 저장 / 불러오기 / 이미지 추가
- 템플릿 저장하기: 만든 템플릿(채널명 포함)을 저장해 두면, 템플릿 선택하기에서 언제든 다시 불러올 수 있습니다.
  - 템플릿은 보통 반복 작업에 사용하므로 저장해서 쓰는 것을 권장합니다.
- 템플릿 불러오기: 미리캔버스 등에서 만든 템플릿 이미지를 불러와 적용할 수 있습니다.
- 이미지 추가하기: 로고 같은 이미지를 불러와 원하는 곳에 배치할 수 있습니다.

### 화면 조정 (영상 전체)

⚠️ 중요 : 화면 크기 조정은 두 군데에서 하고, 하는 곳에 따라 적용 범위가 다릅니다.
- 영상 전체를 한 번에 조정 → 최종편집 탭 (아래 내용)
- 장면 하나만 따로 조정 → 자막 정리 탭 (작업실 4단계 자막 정리의 [장면 하나만 크기 조정하기] 참고)

최종편집에서 하는 조정은 영상 전체에 적용됩니다. 장면마다 따로 적용되지 않습니다.

⚠️ 아래 질문에는 이 기능을 안내하면 안 됩니다. 전부 자막 정리 탭으로 안내하세요.
- 검은 칸, 상하 여백, 좌우 여백이 생긴다
- 화면이 꽉 안 찬다, 풀화면으로 바꾸고 싶다
- 원본이 1대1이라 여백이 생긴다
- 최종편집으로 넘어가니 잘려 보인다, 작아진다
이런 것은 장면마다 소스 크기가 달라서 생기는 일이라 전체 조정으로는 해결되지 않습니다.

이 기능은 모든 장면을 똑같이 한 번에 키우거나 줄이고 싶으실 때만 씁니다.

#### 방법
1. 최종편집에서 [템플릿] 버튼을 누릅니다.
2. 화면을 클릭합니다.
3. 마우스 휠을 굴려 크기를 키우거나 줄입니다.
4. 마우스로 끌어서 위치를 옮깁니다.

장면 하나만 조정하고 싶으시면 최종편집이 아니라 자막 정리 탭에서 하셔야 합니다.

### 음성 / 자막 켜고 끄기
- 우측 상단의 음성 버튼을 끄면 음성 없이 내보낼 수 있습니다.
- 우측 상단의 자막 버튼을 끄면 자막 없이 음성만 나오게 내보낼 수 있습니다.

### AI 효과음 (쇼렌 AI 효과음)

#### 사용 조건 (중요)
- AI 효과음은 모든 분이 사용하기는 어렵습니다.
- 용량이 많이 필요합니다. (약 20GB)
- 그래픽 카드가 있어야 사용하기가 수월합니다.
  - 참고 예시: 5070Ti 그래픽 카드 기준, 20초 영상의 효과음 생성에 약 2분 내외
  - CPU만으로 하면 같은 20초 영상도 30분이 걸릴 수 있습니다.
- 그래픽 카드가 있는 분들만 사용하시기를 권장합니다.
- 다운로드 페이지의 '쇼렌 AI 효과음'을 별도로 설치해야 하며, 자세한 내용은 쇼렌 AI 효과음 사용법 영상을 참고하세요.
영상 링크 : https://youtu.be/6nu6UzdTjZM

#### 사용 방법
1. 최종편집에서 효과음 만들기를 누릅니다.
2. 미리보기로 만든 영상을 AI가 파악해서, 밋밋한 영상에 어울리는 효과음을 자동으로 생성합니다.
3. 생성 후 볼륨 조절과 미리 듣기가 가능합니다.
4. 적용을 누르면 영상에 효과음이 입혀집니다.
- 효과음이 들어가면 영상의 생동감과 퀄리티가 크게 올라갑니다.
- 더 자세한 내용은 쇼렌 AI 효과음 사용법 영상을 참고하세요 : https://youtu.be/6nu6UzdTjZM

### 내 효과음 (직접 넣는 효과음)

사용법 영상 : https://youtu.be/WZit5vJ9E0M

#### AI 효과음과 무엇이 다른가요
- AI 효과음은 AI가 알아서 만들어 주지만, 컴퓨터 사양이 받쳐줘야 쓸 수 있습니다.
- 내 효과음은 사양과 상관없이 누구나 쓸 수 있습니다. 원하는 자리에 원하는 소리를 직접 넣는 방식입니다.
- 넣을 소리가 없으신 분들을 위해 기본 효과음 480개를 준비해 두었습니다. 패널 왼쪽 위의 [효과음 480개 받기] 버튼을 누르시면 자동으로 받아집니다. 다 받으면 그 버튼은 사라집니다.

#### 어디에 있나요
- 최종편집 화면에서 [내 효과음]을 누르면 오른쪽 창이 내 효과음 화면으로 바뀝니다.
- 오른쪽 위의 [닫기]를 누르면 원래 화면으로 돌아옵니다.
- 썸네일 화면, 템플릿 화면에도 [닫기]와 [뒤로] 버튼이 있어서 빠져나오기 쉽게 되어 있습니다.

#### 파형 보는 법
- 위쪽은 영상 전체의 파형입니다.
- 위쪽 파형에서 네모난 범위를 마우스로 잡아 옮기면, 그 구간이 아래쪽 '가까이 보기'에 크게 나옵니다.
- 크게 보면서 정확한 자리를 잡으라는 뜻입니다. 아래쪽 화면에서도 마우스로 좌우 이동이 됩니다.
- 마우스 휠로도 좌우 이동이 됩니다.

#### 효과음 넣는 방법
1. 파형에서 소리를 넣고 싶은 자리로 맞춥니다.
2. [＋ 여기에 넣기]를 누릅니다. 그 자리에 종 모양 표시가 생깁니다.
3. 표시를 클릭하면 주변이 노란색이 됩니다. 선택되었다는 뜻입니다.
4. 아래쪽 목록에서 원하는 소리를 고르면 바로 적용됩니다.

#### 소리 찾는 방법
목록이 480개라 그냥 찾기는 어렵습니다. 네 가지로 찾으실 수 있습니다.
- 파일 이름 그대로 검색
- 초성 검색 : ㅃㅇ 이라고 치면 뾰옹, 뾰잉 같은 소리가 나옵니다.
- 떠오르는 단어로 검색 : 키보드 라고 치면 타자 치는 소리, 찰칵, 클릭 같은 어울리는 소리가 나옵니다. 슈욱, 쓱 처럼 소리 흉내를 내셔도 됩니다.
- 미리듣기 : 목록 옆에서 소리를 미리 들어보실 수 있습니다.

#### 넣은 소리 다듬기
- 구간 들어보기 : 효과음 앞뒤 1초 정도만 반복해서 들어볼 수 있습니다.
- 위치 미세 조정 : 효과음을 선택한 뒤 키보드 좌우 키로 옮길 수 있습니다. 마우스로 하시려면 [위치 조정] 버튼을 쓰시면 됩니다. 한 번에 0.1초, 더 작은 버튼은 0.02초씩 움직입니다.
- 소리 크기 : 소리 크기 항목에 마우스 휠을 올리면 커지고 내리면 작아집니다.
- 재생 : 파란색 선을 원하는 위치에 두고 스페이스 바를 누르면 재생됩니다. 다시 누르면 멈춥니다.

#### 효과음 지우기
효과음을 선택한 뒤 아래 넷 중 아무거나 하시면 됩니다.
- [삭제] 버튼 누르기
- Delete 키
- Backspace 키
- 마우스 오른쪽 클릭

#### 자주 쓰는 소리 모아두기
- 소리 옆의 별표를 누르면 즐겨찾기가 되어 목록 맨 위에 고정됩니다.
- [파일 불러오기]로 내 컴퓨터에 있는 효과음을 가져와 쓰실 수 있습니다.
- 목록은 위에서부터 즐겨찾기, 내가 넣은 소리, 기본 효과음 480개 순서로 나옵니다. 직접 넣으신 소리가 위에 오기 때문에 480개 사이에 파묻히지 않습니다.

### 썸네일

#### 배경 장면 선택
- 썸네일을 클릭하면 우측이 썸네일 만들기 화면으로 바뀝니다.
- 위쪽 슬라이더로 영상에서 원하는 위치의 장면을 골라 썸네일 배경으로 쓸 수 있습니다.
- 어떤 장면이 좋을지 모르겠다면 'AI 추천 장면'을 누르세요. AI가 영상 전체를 파악해 5가지 장면을 추천해 줍니다.
- 화면을 클릭해서 확대, 이동, 축소가 가능합니다.
- 좌우 반전 버튼으로 화면을 반전할 수 있습니다.

#### 썸네일 꾸미기
- 더블 클릭으로 문구를 입력할 수 있습니다. (예: "개발자도 놀란 저금통의 비밀")
- 폰트, 색상, 각도를 바꿀 수 있고, 그룹 지정과 크기 조절도 가능합니다. (템플릿과 같은 편집 기능)
- 도형: 동그라미 등으로 강조하고 싶은 것을 표시할 수 있습니다. (두께, 크기 조절)
- 선: 구분선 등을 만들 수 있습니다.
- 스티커: 사람들이 많이 쓸 법한 것들이 준비되어 있습니다.
- 화살표: 10가지가 준비되어 있습니다. 이동, 좌우 반전, 확대가 가능합니다.
- 마우스 우클릭으로 맨 뒤로 보내기, 잠금 등이 가능합니다.

#### 장면 고정 (배경 비교)
- 위의 장면 고정을 누르면 현재 장면이 고정됩니다.
- 다른 장면으로 바꿔 테스트해 보다가, 고정 장면을 클릭하면 원래 장면으로 돌아옵니다.
- 여러 배경을 바꿔보면서 어떤 게 더 효과적일지 비교해 보세요.

#### 썸네일 완성
- 마음에 드는 썸네일이 완성되면 아래의 썸네일 완성을 누릅니다.
- 자동으로 업스케일링(선명하게 키우기)이 됩니다.
- 마지막에 영상 내보내기로 mp4를 뽑으면, 영상의 맨 앞 프레임이 자동으로 썸네일로 들어갑니다.
- 모바일에서 업로드하거나, PC로 올린 뒤 모바일의 수정 기능으로 썸네일을 지정할 수 있습니다.

#### 이미지 / 배경 교체
- 이미지: 본인이 추가하고 싶은 이미지를 불러올 수 있습니다.
- 배경: 배경 자체를 다른 이미지로 교체합니다. 미리캔버스 등에서 작업한 것을 배경으로 불러올 수도 있습니다.

### 영상 내보내기
- 편집이 끝나면 내보내기로 mp4 영상을 뽑습니다.
- 내보낸 영상은 프로젝트 폴더 안의 최종영상 폴더에 저장됩니다.
- 썸네일 완성을 해두었다면 영상의 맨 앞 프레임에 썸네일이 자동으로 들어갑니다.
- 배경음악을 미리 넣지 않았다면, 내보낸 뒤 유튜브에서 음악을 입히는 방법을 많이 사용합니다.
- 2026년 8월 30일 v1.4.7부터 내보내기 메뉴 안에 [쇼렌 화질 개선 (무료)] 와 [Vmake 화질 개선 (유료)] 스위치가 생겼습니다.
  둘 중 하나만 켜집니다. 자세한 내용은 문서 맨 끝의 [2026년 8월 30일 업데이트]를 보세요.
- 2026년 8월 22일부터 내보내기 메뉴 안에 [업로드 전 AI 검수] 스위치가 생겼습니다.
  올리기 전에 AI가 영상을 훑어보고 워터마크나 주의할 장면을 알려주는 기능입니다.
  자세한 내용은 문서 맨 끝의 [2026년 8월 22일 업데이트 - 업로드 전 AI 검수]를 보세요.

## 작업실 6단계: 쿠팡 제품 찾기

### 어떤 기능인가요?
- 영상 속 제품을 쿠팡에서 자동으로 찾아주는 기능입니다.
- 벤치마킹한 영상의 채널(인포크 링크 등)에서 제품을 확인할 수도 있습니다.
- 다만 다음과 같은 경우에 이 기능을 사용하면 유용합니다:
  - 관리가 부실해 품절인 경우
  - 다른 상품을 추가로 고르고 싶은 경우
  - 비슷한 제품을 여러 개 등록하고 싶은 경우

### 쿠팡 후보 찾기 사용법
1. 쿠팡 후보 찾기를 누르면 크롬 창이 열립니다.
2. 영상을 분석해 제품이 잘 나오는 장면을 캡처하고, 구글 렌즈로 쿠팡 제품을 자동 추적합니다.
3. 총 4번에 걸쳐 자동으로 검색하며, 4개의 캡처와 함께 쿠팡 제품 후보들이 하단에 표시됩니다.
4. 맞지 않는 후보는 마우스 우클릭이나 X 버튼으로 삭제할 수 있습니다.
5. 후보를 클릭하면 쿠팡에서 해당 제품을 바로 확인할 수 있습니다.
6. 링크를 복사해서 본인의 쿠팡 파트너스에 넣어 수익화 링크를 만들거나, 쇼핑 태그가 있다면 제품 태그를 만들 수 있습니다.

### 쿠팡 파트너스 연동 시 (편리)
- 설정 > 서비스 연동에서 쿠팡 파트너스 API를 등록해 두면, 후보 검색 완료 후 일부 제품의 복사 버튼이 초록색으로 표시됩니다.
- 초록색 복사 버튼 = 이미 본인의 수익화 링크로 자동 변환된 상태입니다. 복사해서 인포크 링크 등록 등 원하는 곳에 즉시 사용하면 됩니다.
- 초록색으로 안 뜨는 제품은 품절이거나, 판매자가 쿠팡 파트너스 연결을 허용하지 않은 제품입니다.

### 추가 검색
- 비어 있는 플러스(+) 버튼으로 이미지를 불러오거나 드래그 앤 드롭으로 넣어 검색할 수 있습니다.
- 원하는 키워드를 직접 넣어 검색할 수도 있습니다.
- 추천 키워드도 함께 제공됩니다.

## 작업실 7단계: 자동 업로드

제작 완료된 영상을 즉시 업로드하거나 예약 발행하는 기능입니다.
여러 플랫폼, 여러 채널에 올리는 시간을 크게 줄여줍니다.

⚠️ 2026년 8월 30일 v1.4.7부터 도구 탭에도 자동 업로드가 생겼습니다.
  쇼핑렌즈로 만들지 않은 영상을 올리실 때는 도구 탭에서 하시면 됩니다.
  여기 작업실 7단계는 그 프로젝트의 완성 영상 전용입니다.
  자세한 내용은 문서 맨 끝의 [2026년 8월 30일 업데이트]를 보세요.

⚠️ 이 아래 내용은 2026년 8월 20일 업데이트 전에 쓴 것입니다.
  지금은 플랫폼이 5개(YouTube, Instagram, TikTok, Threads, X.com)이고 문구 선택 화면도 바뀌었습니다.
  자동 업로드를 안내하실 때는 문서 맨 끝의 [2026년 8월 20일 업데이트 - 자동 업로드]를 먼저 보세요.
  앞뒤가 다르면 그쪽이 맞습니다.

### 사전 준비 (필수)
- 설정 > 서비스 연동 > 버퍼 계정 관리에서 버퍼 API를 등록해야 연동됩니다.
- 설정하지 않았다면 '버퍼키 받는 법' 영상을 보고 추가하세요.

### 채널 선택
- 자동 업로드에 들어오면 좌측에 본인의 채널들이 표시됩니다.
- 전체 선택 / 전체 해제 버튼이 있고, 어떤 계정에 몇 개를 올릴지 확인할 수 있습니다.
- 주의: 체크를 잘 확인하세요. 체크를 안 보고 올리면 같은 영상을 같은 채널에 2중, 3중으로 올리는 실수가 생길 수 있습니다.

### 플랫폼별 문구 입력
- 유튜브 클릭: 제목과 설명글 입력
- 인스타그램 클릭: 설명글 입력
- 틱톡 클릭: 설명글 입력
- 하나를 작성한 뒤 '현재 설명 전체 적용'을 누르면 모든 플랫폼에 동일하게 적용됩니다.

### 업로드 문구 자동 생성
- '업로드 문구 선택' 버튼을 누르면 영상을 분석해 제목과 설명글을 자동으로 추천해 줍니다.
- 생성되는 내용:
  - 유튜브 제목: 스타일별 3개
  - 유튜브 스타일 설명글: 3개
  - 인스타 스타일 설명글: 3개
- 제목만 다시, 유튜브 설명만 다시, 인스타 설명만 다시 부분 재생성도 가능합니다.
- 마음에 드는 것을 고르고 '선택한 문구 적용'을 누르면 지정됩니다.
- 적용 후 원하는 대로 직접 수정할 수 있습니다.
- 주의: 인포크 링크를 사용하는 경우 "프로필 링크 몇 번에서 확인할 수 있습니다" 같은 문구의 숫자는 본인 상황에 맞게 직접 수정해야 합니다.

### 공개 설정과 AI 표시
- 유튜브: AI 영상 여부 체크, 전체 공개 / 일부 공개 / 비공개 선택 (보통은 전체 공개)
- 인스타그램: AI 표시와 피드 표시 선택
- 틱톡: AI 표시 선택

### 발행
- 지금 발행: 즉시 발행합니다.
- 예약 발행: 팝업에서 원하는 날짜와 시간을 선택해 예약합니다.
  - 영상을 미리 만들어 두고 원하는 날짜와 시간에 여러 개를 예약해 두면 편리합니다.
- 발행한 것들은 우측 사이드에서 확인할 수 있고, 가장 최근 것이 상단에 표시됩니다.
- 아직 발행되지 않은 예약 건은 클릭하면 팝업에서 취소할 수 있습니다.
- 발행된 것은 게시물 열기를 눌러 즉시 확인할 수 있습니다.

## 도구 메뉴

### 자막 지우개 (독립 도구)
- 작업실 흐름과 별개로, 아무 영상이나 불러와서 자막을 제거할 수 있는 독립 도구입니다.
- 영상 속 자막을 자동 감지하고 깔끔하게 제거합니다.
- 새로운 도구가 계속 추가될 예정입니다.

## 프로젝트 메뉴

- 저장된 프로젝트 목록을 확인하고 불러올 수 있습니다.
- 프로젝트를 클릭하면 해당 프로젝트를 불러와 작업실에서 이어서 작업할 수 있습니다.
- 프로젝트 카드의 삭제 버튼으로 프로젝트를 삭제할 수 있습니다. 단, 현재 열려 있는 프로젝트는 삭제할 수 없습니다.
- 작업 내용(다운로드한 소스, 분석 결과, 대본, 음성, 장면 구성, 편집 상태 등)은 프로젝트 단위로 자동 저장됩니다.
- 프로젝트 파일은 쇼핑렌즈 폴더 안의 프로젝트 폴더에 저장되며, 프로그램을 삭제해도 남아 있습니다.

## 챗봇 (쇼핑렌즈 도우미)

- 좌측 사이드바 하단의 물음표(챗봇) 버튼을 누르면 AI에게 즉시 물어보고 답변을 받을 수 있습니다.
- 처음 사용하며 궁금한 점이 많을 때 적극 활용하세요.
- AI의 답변은 다소 틀릴 수 있으니 참고용으로 사용하시기 바랍니다.

## 에러 메시지 안내 및 문제 해결

### 프로그램 설치 파일 다운로드가 되지 않는 경우
- 본인이 사용하는 백신 프로그램(V3, 알약, 윈도우 디펜더 등)과 바이러스 및 위협방지의 '실시간 보호 기능'을 잠시 끄고 다운로드해 보세요.
- 다운로드와 설치가 끝나면 실시간 보호 기능을 다시 켜 주세요.

### 기능이 동작하지 않는 경우 (버튼이 안 눌리거나 반응 없음)
먼저 다음 세 가지를 확인하세요:
1. 인증키를 입력했는지 확인
2. 설정에서 제미나이 API 키(또는 버텍스 JSON)를 등록했는지 확인 (API 테스트로 석세스 확인)
3. 프로젝트가 생성되어 있는지 확인 (작업실 기능은 프로젝트가 있어야 동작합니다)

### 영상 분석, 대본 생성, 장면 매칭이 실패하는 경우
- 제미나이 API 키(또는 버텍스 JSON)가 올바르게 등록되어 있는지 확인하세요.
- 인터넷 연결이 정상적인지 확인하세요.
- API 할당량이 초과되지 않았는지 확인하세요. (무료 키는 할당량이 매우 적습니다. 429 에러 항목 참고)
- 쇼핑렌즈는 문제가 생기면 자동으로 재시도합니다. 재시도 표시가 뜨면 잠시 기다려 주세요.

### 편집 준비 결과가 이상하거나 수정 사항이 반영되지 않는 경우
- 장면 교체, 화면 조정, 음성 재생성 등을 한 뒤에는 편집 준비 시작을 다시 눌러야 반영됩니다.

### 영상 내보내기가 실패하는 경우
- 컴퓨터의 저장 공간이 충분한지 확인하세요.
- 내보내려는 영상 파일을 다른 프로그램(재생기 등)이 열어두고 있지 않은지 확인하세요.
- 편집 준비를 다시 실행한 뒤 내보내기를 다시 시도해 보세요.

### 429 에러 (할당량 초과)
- 원인: 제미나이 API 사용량 한도 초과입니다. 무료 키는 하루 할당량이 매우 적어 자주 발생합니다.
- 해결:
  1. 제미나이 키를 여러 개 등록해 두세요. 자동 로테이션됩니다. (구글 계정 하나당 키 1개)
  2. 잠시 후 다시 시도하거나 다음 날 다시 시도하세요.
  3. 근본 해결: 버텍스 AI JSON(300달러 무료 크레딧)을 등록하면 우선순위가 높아 쾌적하게 사용할 수 있습니다. (받는 법 영상: https://youtu.be/x4kTl5yuTMY)

### 503 에러 / 과부하 에러
- 원인: 구글 서버 과부하입니다. 무료 키는 우선순위가 낮아 더 자주 발생합니다.
- 해결: 잠시 후 다시 시도하세요. 자주 발생하면 버텍스 AI JSON 등록을 권장합니다.
- 참고: 쇼핑렌즈는 문제가 생기면 자동으로 재시도합니다. "서버 과부하, 재시도 중..." 표시가 뜨면 기다려 주세요.

### 제미나이 키가 유효하지 않다는 안내
- 원인: 등록한 제미나이 API 키가 잘못되었거나 만료, 정지된 상태입니다.
- 해결: 설정 > 구글키 관리에서 키를 다시 확인하거나 새 키를 발급받아 등록하세요.
  - 등록 후 API 테스트를 눌러 석세스와 강아지 이미지가 뜨는지 확인하세요.

### 타입캐스트 음성 생성이 일시적으로 차단되었다는 안내
- 원인: 타입캐스트는 한 명의 사용자가 2개 이상의 무료 계정으로 API를 사용하는 것을 차단합니다.
- 해결: 무료 사용 시 반드시 하나의 아이디로만 사용하세요. 크레딧이 남아 있는 정상 계정으로 변경하면 다시 생성됩니다.
- 참고: 이는 쇼핑렌즈의 문제가 아니라 타입캐스트 정책에 의한 차단입니다.

### 음성(TTS) 크레딧 부족
- 원인: 일레븐랩스 또는 타입캐스트의 크레딧을 모두 사용했습니다.
- 해결: 크레딧이 충전될 때까지 기다리거나, 유료 결제 또는 다른 TTS 서비스로 전환하세요.
- 참고: 문장별 부분 재생성을 활용하면 크레딧을 크게 아낄 수 있습니다.

### 제품 찾기 검색 횟수 소진
- 원인: 제품 찾기 수집은 하루 10회로 제한됩니다.
- 해결: 다음 날 다시 시도하세요. (다음 날로 넘어가도 횟수가 누적되지는 않습니다)
- 대안: 각 플랫폼에서 쇼핑렌즈 오토의 다운로드 버튼으로 직접 수집한 뒤, 영상 준비에 링크나 파일로 추가할 수 있습니다.

### AI 효과음 관련 에러
- "기존 AI 효과음 파일이 아직 사용 중이라 새 파일로 바꾸지 못했습니다": 미리듣기를 멈춘 뒤 다시 만들어 주세요.
- "그래픽 메모리가 부족해서 효과음을 만들지 못했습니다": 다른 프로그램(게임, 영상 편집 등)을 닫고 다시 시도하세요.
- "효과음 계산이 너무 오래 멈춰 있어 자동으로 멈췄습니다": 무거운 프로그램을 닫고 다시 시도하세요. 계속 반복되면 그래픽 카드 메모리가 부족한 컴퓨터일 수 있습니다.
- "미리보기 영상을 찾지 못했습니다": 먼저 편집 준비를 다시 실행한 뒤 시도하세요.
- 자동 추천 문장 생성 문제: 잠시 후 다시 시도하거나, 자동 추천을 끄고 직접 입력해 주세요.

### 자막 제거가 너무 느린 경우
- 원인: 그래픽 카드가 없거나 사용할 수 없는 환경에서는 CPU로 처리되어 느립니다.
- 해결: 블러 방식을 사용하거나, 자막이 없는 소스를 우선 선택하는 것도 방법입니다.

### 그록 AI 영상 생성이 안 되는 경우
- 슈퍼 그록에 가입되어 있는지, 크롬에 그록 로그인이 되어 있는지 확인하세요.
- 쇼핑렌즈 오토 확장앱이 설치되어 있는지, 최신 버전으로 새로 고침되어 있는지 확인하세요.
- 프로그램 업데이트 후에는 확장앱도 새로 고침 또는 재설치가 필요합니다.

### 발행(업로드)이 실패로 표시되는 경우
- 발행 후 완료 확인까지 시간이 걸리는 경우가 있습니다.
- 실패로 표시되더라도 실제로는 올라갔을 수 있으니, 우측 발행 목록과 실제 채널을 함께 확인해 보세요.
- 같은 영상을 다시 발행하기 전에 실제 채널에 올라갔는지 꼭 확인하세요. (중복 업로드 방지)

## 자주 묻는 질문 (FAQ)

### Q: 완전히 무료로 사용할 수 있나요?
A: 여기서 말하는 무료는 쇼핑렌즈 이용료(인증키)가 아니라, 외부 AI 서비스 비용에 대한 이야기입니다. 외부 서비스는 원한다면 처음부터 끝까지 무료로도 가능합니다. 쇼핑렌즈는 이미지 생성을 하지 않아 무료 제미나이 API 키로도 사용이 가능합니다. 다만 무료 키는 할당량이 적고(하루 20번도 안 될 수 있음) 429, 503 에러가 자주 발생합니다. 쾌적하게 쓰려면 버텍스 AI JSON(300달러 무료 크레딧, 3달)을 권장합니다.

### Q: 제미나이 키는 몇 개까지 등록할 수 있나요?
A: 여러 개 등록할 수 있으며, 한도에 걸리면 자동으로 다음 키로 로테이션됩니다. 단, 구글 계정 하나당 키 하나만 받아야 합니다. 10개를 등록하려면 10개의 구글 계정이 필요합니다.

### Q: 버텍스 JSON은 어떻게 받나요? 300달러 무료 크레딧은 어디서 받나요?
A: 아래 영상을 보고 그대로 따라 하시면 됩니다. 받은 JSON 파일은 설정 > 구글키 관리에서 버텍스 모드를 선택하고 드래그 앤 드롭으로 등록하세요.
영상 링크 : https://youtu.be/x4kTl5yuTMY

### Q: 버텍스 등록이 잘 됐는지 어떻게 확인하나요?
A: 설정의 API 테스트 버튼을 누르세요. 석세스 문구와 강아지 이미지가 뜨면 정상입니다.

### Q: 유튜브 API는 꼭 등록해야 하나요?
A: 아니요, 선택 사항입니다. 트렌드의 키워드 검색과 댓글 확인 기능에만 필요합니다.

### Q: 제품 찾기 검색 횟수가 부족해요.
A: 하루 10회이며 다음 날 초기화됩니다(누적 안 됨). 10회로도 하루 2개에서 3개 이상 영상 제작이 가능하고, 각 플랫폼에서 확장앱의 다운로드 버튼으로 직접 수집하는 방법도 있습니다.

### Q: 제품 찾기에서 엉뚱한 제품이 나와요.
A: 스토리 방식의 벤치 영상은 관련 없는 장면이 섞여 AI가 혼동할 수 있습니다. 같은 제품이 잘 나오는 영상을 후보에 추가한 뒤, 그 영상에 마우스 우클릭 > '이 영상으로 제품 찾기'를 사용하면 정확도가 올라갑니다. (1.2.8 버전 이후)

### Q: 어떤 소스 영상을 골라야 하나요?
A: 컷별로 분할된 영상, 자막이 없거나 얇은 영상이 좋습니다. 중국 플랫폼(샤오홍슈, 도우인)에는 자막 없는 영상이 많습니다. 자막이 제품을 가리지 않는 것이 좋습니다.

### Q: 소스는 몇 개까지 추가할 수 있나요?
A: 총 8개까지 추가할 수 있습니다.

### Q: 대본이 마음에 안 들어요.
A: 세 가지 방법이 있습니다. 1) 생성된 대본을 직접 수정, 2) 다른 스타일을 선택해 재생성, 3) 대본 사전지시에 원하는 방향을 적고 재생성. 조회수 높은 벤치 영상을 스타일 분석해서 그 스타일로 생성하는 것도 효과적입니다.

### Q: TTS가 단어를 이상하게 읽어요.
A: 대본에서 해당 부분을 소리 나는 대로 한글로 풀어쓴 뒤(예: "X 라지"를 "엑스 라지"로), 그 문장만 마이크 버튼으로 재생성하세요. 크레딧도 아낄 수 있습니다.

### Q: 특정 문장만 볼륨이 작게 들려요.
A: 해당 문장만 마이크 버튼으로 다시 생성해 보세요.

### Q: 장면 매칭 결과가 마음에 안 들어요.
A: 구성 카드에서 마우스 우클릭 > 장면 자동 교체(2순위 후보로 교체)를 쓰거나, 카드를 클릭한 뒤 아래 소스 섹션에서 원하는 장면을 마우스 우클릭하면 그 장면으로 바뀝니다.

### Q: 장면이 대본(음성)보다 짧거나 길면 어떻게 되나요?
A: 자동으로 시간이 계산되어 맞춰집니다. 짧으면 느리게(슬로우), 길면 빠르게 재생됩니다.

### Q: 나눠진 장면을 하나로 합칠 수 있나요?
A: 네. Ctrl을 누른 채 장면들을 순서대로 클릭(주황색 표시)한 뒤 마우스 우클릭 > 합치기를 누르세요. 건너뛰기는 안 되고 순차적으로만 가능합니다. 해제도 우클릭에서 가능합니다.

### Q: AI 영상 만들기(그록)가 안 돼요.
A: 슈퍼 그록 가입과 크롬 로그인이 되어 있는지, 쇼핑렌즈 오토 확장앱이 설치되어 있고 최신 상태인지 확인하세요.

### Q: 자막 제거하면 화면이 찌그러져요.
A: 인식 범위가 부족했을 수 있습니다. 더블클릭해서 부분 지정을 늘려 다시 실행해 보세요. 일그러짐이 싫다면 자막 블러 방식으로 바꾸면 깔끔하게 가려집니다.

### Q: 원본 영상의 소리를 살리고 싶어요.
A: 편집 준비 옵션에서 '영상 원본 소리 보조'를 켜면 원본 소스의 소리가 함께 나옵니다.

### Q: 배경음악은 어떻게 넣나요?
A: 최종편집의 배경에서 드래그 앤 드롭으로 넣거나, 쇼핑렌즈 폴더 안의 배경음악 폴더에 파일을 넣어두면 프로그램에서 바로 선택할 수 있습니다. 내보낸 뒤 유튜브에서 음악을 입히는 방법도 많이 씁니다.

### Q: 만든 템플릿(채널명 포함)을 계속 쓰고 싶어요.
A: 템플릿 저장하기를 누르면 저장되고, 템플릿 선택하기에서 언제든 다시 불러올 수 있습니다.

### Q: AI 효과음은 누구나 쓸 수 있나요?
A: 용량 약 20GB가 필요하고 그래픽 카드가 있어야 수월합니다. 그래픽 카드 기준 20초 영상에 약 2분, CPU만으로는 30분이 걸릴 수도 있어 그래픽 카드가 있는 분들에게만 권장합니다. 별도의 '쇼렌 AI 효과음' 설치가 필요합니다.
설치와 사용법 영상 링크 : https://youtu.be/6nu6UzdTjZM

### Q: 썸네일은 유튜브에 어떻게 적용되나요?
A: 썸네일 완성을 누르면 자동 업스케일되고, mp4 내보내기 시 영상의 맨 앞 프레임으로 들어갑니다. 모바일 업로드 시 또는 PC 업로드 후 모바일의 수정 기능에서 썸네일로 지정할 수 있습니다.

### Q: 쿠팡 복사 버튼이 초록색이 아니에요.
A: 초록색은 본인의 수익화 링크로 자동 변환된 상태입니다. 초록색이 아닌 것은 품절이거나 판매자가 쿠팡 파트너스 연결을 허용하지 않은 제품입니다.

### Q: 버퍼 무료 계정은 채널을 몇 개까지 등록하나요?
A: 무료 계정당 3개입니다. (유튜브만 3개도 가능, 유튜브+틱톡+인스타 조합도 가능) 쇼핑렌즈에는 버퍼 계정을 5개까지 연결할 수 있어 최대 15개 채널 관리가 가능합니다.

### Q: 같은 영상이 같은 채널에 두 번 올라갔어요.
A: 발행 전 채널 체크박스를 꼭 확인하세요. 체크 상태를 확인하지 않으면 같은 채널에 중복으로 올라갈 수 있습니다.

### Q: 예약 발행을 취소하고 싶어요.
A: 우측 발행 목록에서 아직 발행되지 않은 예약 건을 클릭하면 팝업에서 취소할 수 있습니다.

### Q: 확장앱에 다운로드 버튼이 안 보여요.
A: 크롬 확장 프로그램 관리에서 쇼핑렌즈 오토가 켜져 있는지 확인하고, 새로 고침 버튼을 누르거나 재설치해 보세요. 프로그램 업데이트 후에는 확장앱도 꼭 업데이트해야 합니다.

### Q: 샤오홍슈에서 다운로드하려니 자꾸 로그인하라고 해요.
A: 샤오홍슈는 사용자에 따라 매번 QR코드 로그인이 필요한 경우가 있습니다. 로그인 후 이용해 주세요.

### Q: 다른 컴퓨터에서도 같은 인증키를 쓸 수 있나요?
A: 아니요. 쇼핑렌즈는 로컬 프로그램이라 하나의 인증키는 하나의 PC에서만 사용 가능합니다.

### Q: 프로그램을 삭제하면 작업물도 사라지나요?
A: uninstall을 해도 프로젝트 폴더는 삭제되지 않습니다.

## 작업 흐름 요약 (Quick Reference)

### 빠른 시작 가이드
1. 설치 후 인증키 입력, 공지사항 확인
2. 쇼핑렌즈 오토 확장앱을 크롬에 설치
3. 설정에서 제미나이 키(또는 버텍스 JSON) 등록, TTS 키 등록 (선택: 유튜브 API, 쿠팡 파트너스, 버퍼)
4. 트렌드 > 쇼핑 트렌드에서 벤치마킹할 인기 영상 선택 (AI 분석 참고, 스타일 분석 실행)
5. 제품 찾기로 원본 소스 수집, 마음에 드는 소스 추가 (최대 8개)
6. 영상 준비로 이동 > 프로젝트 생성 > 자동 다운로드 > 영상 분석
7. 대본 탭에서 스타일 선택 후 대본 생성, 수정
8. 음성(TTS) 생성, 필요한 문장만 부분 재생성
9. 장면 구성 > 장면 매칭 > 미리보기로 확인, 필요 시 교체와 세부 조정 (AI 영상 인트로 활용 가능)
10. 자막 정리에서 필요한 부분만 자막 제거 또는 블러
11. 최종편집 > 편집 준비 > 자막 스타일, 템플릿, 필터 설정 (선택: AI 효과음, 썸네일)
12. 쿠팡 제품 찾기로 수익화 링크 확보 (선택)
13. 내보내기 또는 자동 업로드(지금 발행 / 예약 발행)

## ✨ AI 추천 썸네일 문구

최종편집 탭 오른쪽 썸네일 패널에서 대본을 읽고 썸네일에 얹을 두 줄 문구를 8개 만들어 줍니다.
조회수가 잘 나온 쇼츠 썸네일들을 분석해서 정리한 8가지 유형(궁금증 유발, 명령 지시, 반전, 비교 등)으로
각각 한 개씩 뽑아 주기 때문에, 서로 다른 느낌의 문구를 한 번에 비교해 볼 수 있습니다.

### 사용법
1. 대본을 먼저 만들어 주세요. 대본이 없으면 문구를 만들 수 없습니다.
2. 최종편집 탭으로 이동해 오른쪽 썸네일 패널을 엽니다.
3. 썸네일에 쓸 장면을 화면에 띄웁니다.
4. [✨ AI 추천 문구] 버튼을 누릅니다.
5. 잠시 뒤 문구 카드 8개가 두 줄로 나타납니다.
6. 마음에 드는 카드를 클릭하면 그 문구가 썸네일 화면 위쪽에 바로 얹힙니다.
7. 다른 카드를 클릭하면 방금 얹은 문구가 새 문구로 교체됩니다.
   단, 그 문구를 직접 옮기거나 고치셨다면 지우지 않고 그대로 두고 새 문구를 추가합니다.
8. 마음에 드는 게 없으면 [✨ AI 추천 문구]를 다시 눌러 새로 뽑을 수 있습니다. 누를 때마다 새로 만듭니다.
9. 카드가 화면을 많이 차지하면 [▲ 접기]로 접어 둘 수 있습니다.

### 알아두면 좋은 점
- 뽑은 문구는 프로젝트에 저장됩니다. 프로그램을 껐다 켜도 카드가 그대로 남아 있습니다.
- 문구는 대본 내용을 바탕으로 만듭니다. 대본에 없는 내용을 지어내지 않습니다.

### ★ 화면에 보이는 장면을 같이 보고 만듭니다
문구를 만들 때 대본만 보는 것이 아니라, 버튼을 누르는 순간 썸네일 화면에 깔려 있는 장면을 같이 봅니다.
그래서 그 장면과 어울리는 문구가 우선적으로 나옵니다.

여기서 중요한 점이 있습니다.
AI가 추천해 준 장면 5장 중에서 고른 것만 되는 것이 아닙니다.
직접 다른 장면으로 바꿔 놓으셨어도, 그때 화면에 보이는 그 장면을 그대로 보고 만듭니다.

- AI 추천 장면을 골랐을 때 : 그 장면을 보고 만듭니다.
- 직접 다른 장면으로 바꿨을 때 : 바뀐 그 장면을 보고 만듭니다.
- 장면을 바꾼 뒤 버튼을 다시 누르면 : 새 장면에 맞춰 문구가 다시 나옵니다.

즉, 장면을 먼저 정해 놓고 문구를 뽑으시면 그 장면에 어울리는 문구를 받으실 수 있습니다.
아직 아무 장면도 안 깔았다면 대본만 보고 만듭니다.
그리고 배경 장면만 봅니다. 그 위에 이미 얹어 놓은 글자나 꾸미기는 보지 않습니다.

## 🖥 자막 지우개 CPU 선택 버튼

자막 정리 탭과 도구 > 자막 지우개 화면에 [CPU] 버튼이 생겼습니다.

### 왜 필요한가요
자막 지우기는 기본적으로 그래픽 카드를 사용합니다. 그런데 오래된 그래픽 카드를 쓰시는 분들 중에
자막 지우기를 시작하자마자 오류가 나거나 프로그램이 꺼지는 경우가 있었습니다.
이럴 때 [CPU] 버튼을 켜시면 그래픽 카드를 아예 쓰지 않고 처리합니다.

### 사용법
1. 자막 정리 탭 위쪽의 [CPU] 버튼을 누릅니다.
2. 버튼에 파란 불이 들어오면 켜진 상태입니다.
3. 그 상태로 자막 지우기를 실행하면 됩니다.
4. 한 번 켜 두면 프로그램을 껐다 켜도 그대로 유지됩니다.

### 알아두면 좋은 점
- CPU로 처리하면 그래픽 카드보다 느립니다. 그래픽 카드로 문제없이 되신다면 끄고 쓰시는 게 빠릅니다.
- 오류 없이 잘 되고 계시다면 굳이 켜실 필요 없습니다.

## ⏳ 영상 분석 사용량 안내 팝업

영상 준비 탭에서 장면 분석을 할 때, 구글이 요청을 잠시 막는 경우가 있습니다.
예전에는 아무 안내 없이 실패로만 표시됐는데, 이제는 왜 멈췄는지 알려 드립니다.

### 이렇게 바뀝니다
- 구글이 막으면 그 자리에서 멈추고 안내창이 뜹니다.
- 안내창에서 [상세 내용 보기]를 누르면 구글이 보낸 원문을 그대로 확인할 수 있습니다.
- 헛되이 계속 다시 시도하지 않습니다. 잠시 뒤에 [다시 분석]을 직접 눌러 주시면 됩니다.
- 이미 분석이 끝난 영상은 다시 하지 않습니다. 실패한 영상만 다시 합니다.

### 자주 막히신다면
구글 AI 스튜디오 키를 무료로 쓰고 계시면 하루에 쓸 수 있는 횟수가 매우 적습니다.
소스 영상 몇 개만 분석해도 금방 막힙니다.
자주 막히신다면 구글 AI 스튜디오에서 결제를 연결하시거나, 버텍스 방식으로 바꾸시는 것을 권장합니다.
(버텍스 받는 법은 이 문서 위쪽의 안내 영상을 참고해 주세요.)

## 🛠 장면 편집 튕김 최적화

장면 구성에서 장면 영상을 하나씩 눌러 확인하시다가 화면이 멈추거나
프로그램이 응답 없음 상태가 되는 일이 있었습니다. 그 부분을 손봤습니다.

### 왜 그런 일이 생겼나요
쇼핑렌즈는 컴퓨터 사양과 그때그때 상황에 영향을 받습니다.

  편집에 집중하실 때는 닫아 두시는 편이 가볍습니다.

## 🔔 기본 효과음 480개 받기

내 효과음 보관함에 넣어 쓰실 수 있는 효과음 480개를 준비했습니다.
버튼 한 번만 누르시면 알아서 받아서 넣어 드립니다.

### 어디에 있나요
최종편집 화면에서 자막 목록 아래에 있는 [내 효과음] 패널을 여시면,
맨 위 왼쪽에 [⬇ 효과음 480개 받기] 버튼이 있습니다.

### 받는 방법
1. 내 효과음 패널을 엽니다.
2. 왼쪽 위의 [⬇ 효과음 480개 받기]를 누릅니다.
3. 화면 위쪽에 진행 상황이 나옵니다. 예) 효과음 받는 중 45%
4. 다 되면 보관함에 480개가 들어와 있습니다.

받는 데 걸리는 시간은 인터넷 속도에 따라 다릅니다. 보통 1분에서 5분입니다.
받는 동안에도 프로그램은 그대로 쓰실 수 있습니다.

### 다 받으면 버튼이 사라집니다
전부 받으신 뒤에는 버튼이 보이지 않습니다.

### 어떤 효과음이 들어 있나요
9가지로 나뉘어 있습니다.

- 강조 약 170개 : 쿵, 퍽, 팡 같은 타격음. 가격이나 핵심을 강조할 때
- 전환 약 70개 : 휙, 슉. 화면이 바뀔 때
- 반응 약 60개 : 웃음, 박수, 환호, 놀람
- 전자 약 55개 : 치지직, 삐, 전자음
- 알림 약 45개 : 띵, 띠링. 뭔가 나타날 때
- 사물 약 45개 : 연필, 형광펜, 카메라 셔터, 문, 시계
- 클릭 약 40개 : 딸깍, 찰칵, 뽁
- 동물 13개 : 닭, 개, 염소, 모기
- 음악 5개 : 빵빠레, 나팔

파일 이름은 분류_이름_번호 형태입니다.
예를 들면 사물_형광펜쓱_01, 강조_퍽 이런 식입니다.
이름만 봐도 어떤 소리인지 알 수 있게 정리했습니다.

### ★ 검색이 똑똑해졌습니다
효과음 이름 그대로가 아니어도 찾을 수 있습니다.
소리마다 사람들이 떠올릴 만한 말을 열 개 넘게 붙여 두었습니다.

예를 들어 사물_형광펜쓱 이라는 소리는 이렇게 찾힙니다.
- 형광펜 : 이름 그대로
- 마커, 하이라이터 : 같은 물건을 부르는 다른 말
- 밑줄, 긋기, 쓱싹 : 그 소리가 나는 동작
- marker : 영어로 쳐도 됩니다

초성으로도 찾힙니다. ㅃㅇ 이라고 치면 뾰잉, 뽁 같은 소리들이 나옵니다.

### 목록이 세 칸으로 나뉩니다
소리 고르는 창을 열면 위에서부터 이렇게 보입니다.

1. 즐겨찾기 : 별을 눌러 둔 소리들
2. 내가 넣은 소리 : 직접 파일을 불러와서 넣으신 것
3. 기본 효과음 : 이번에 받으신 480개

직접 넣으신 소리가 위에 오기 때문에 파묻히지 않습니다.

### 알아두면 좋은 점
- 효과음은 모든 프로젝트에서 같이 씁니다. 한 번 받으면 어느 프로젝트를 열어도 그대로 있습니다.
- 프로그램을 새 버전으로 업데이트해도 받아 둔 효과음은 지워지지 않습니다.
- 컴퓨터에 차지하는 공간은 약 230MB입니다.
- 소리 크기는 프로그램이 쓰는 기준(평균 -20dB)에 맞춰 미리 맞춰 두었습니다.
  직접 넣으시는 파일과 크기 차이가 나지 않습니다.

### 효과음 지우기
프로그램 안에는 지우는 버튼이 없습니다.
쇼핑렌즈를 끄고, shoppinglens 폴더 안 내효과음 에서 파일을 지우시면 됩니다.

### 다시 받기
지운 뒤 쇼핑렌즈를 켜면 [⬇ 효과음 ○개 받기] 버튼이 다시 나타납니다.
누르시면 자동으로 지운 것만 받아옵니다.

### 자주 묻는 질문

Q. 받기 버튼이 안 보입니다.
A. 이미 480개를 다 받으셨다는 뜻입니다. 소리 고르는 창을 열어 기본 효과음 칸을 확인해 보세요.

Q. 받다가 멈췄습니다. 다시 눌러도 되나요?
A. 됩니다. 이미 받은 것은 건너뛰고 못 받은 것만 이어서 받습니다. 중복으로 쌓이지 않습니다.

Q. 인터넷이 끊겨서 실패했습니다.
A. 효과음을 받지 못했습니다 인터넷 연결을 확인해주세요 라는 안내가 뜹니다.
   연결을 확인하신 뒤 다시 누르시면 됩니다.

Q. 480개가 너무 많아서 찾기 힘듭니다.
A. 검색창에 원하는 느낌을 쳐 보세요. 타격, 휙, 박수, 카메라처럼 치시면 그것만 나옵니다.
   자주 쓰는 소리는 별을 눌러 즐겨찾기에 넣으시면 맨 위에 모입니다.

Q. 제가 직접 넣은 효과음이 사라지나요?
A. 아닙니다. 직접 넣으신 것과 기본 효과음은 따로 표시되고, 받기를 눌러도 덮어쓰지 않습니다.

Q. 이름을 바꿔도 되나요?
A. 됩니다. 다만 이름을 바꾸시면 그 소리에 붙어 있던 검색 단어는 따라가지 않습니다.
   예를 들어 사물_형광펜쓱_01 을 내형광펜 으로 바꾸시면 마커 로는 더 이상 안 찾힙니다.

Q. 효과음을 어떻게 넣나요?
A. 받으신 뒤 사용법은 기존 내 효과음 사용법과 같습니다.
   파형에서 소리를 넣고 싶은 자리를 고르고 [＋ 여기에 넣기]를 누른 뒤 원하는 소리를 고르시면 됩니다.

## Threads와 X.com 자동 업로드

기존 YouTube, Instagram, TikTok에 더해 Threads와 X.com에도 영상을 자동으로 올릴 수 있습니다.
이제 5개 플랫폼입니다.

### 연결하는 방법
1. Buffer에서 쓰실 Threads 또는 X.com 채널을 먼저 연결합니다.
2. 쇼핑렌즈의 설정 > Buffer 계정 관리에서 그 Buffer 계정을 연결합니다.
3. 7. 자동 업로드 화면에서 연결한 Threads와 X.com 계정을 선택합니다.

플랫폼 하나에 여러 계정을 연결하셨어도 원하는 계정만 골라서 올릴 수 있습니다.

자동 업로드 화면에서 업로드 계정을 여시고 아래로 내리시면 Threads와 X.com이 보입니다.
각 채널을 붙이는 것은 Buffer 사이트에서 하시고, 거기서 받은 인증키를 쇼핑렌즈에 넣으시면 자동으로 인식합니다.

### 설정의 Buffer 계정 관리도 바뀌었습니다
- 버튼이 [추가]와 [관리]로 나뉘었습니다.
- [추가] : 예전처럼 인증키를 넣으시면 됩니다.
- [관리] : 계정마다 어떤 채널이 붙어 있는지 볼 수 있습니다.
- 계정을 지우실 때는 [연결 해제] 버튼이나 [삭제] 버튼 어느 쪽으로도 됩니다.
- 인증키 추가는 관리 화면에서도 하실 수 있습니다.

### 플랫폼별로 넣을 수 있는 내용
- Threads : 설명글, 주제, 쿠팡 링크 댓글
- X.com : 설명글, 쿠팡 링크 댓글

Threads와 X.com의 쿠팡 링크 댓글은 따로 떨어진 게시물로 올라가지 않습니다.
영상 게시물 바로 아래에 이어지는 댓글로 함께 올라갑니다.

댓글 없이 영상과 설명글만 올리고 싶으시면
쿠팡 링크 댓글 칸의 내용을 전부 지우고 발행하시면 됩니다.


## 업로드 문구 선택 화면 개편

문구를 만든 뒤 플랫폼마다 화면을 다시 열어 고를 필요가 없어졌습니다.
한 화면에서 전부 고르실 수 있습니다.

### 만들어지는 문구
- YouTube 제목 3개
- YouTube 설명글 3개
- Instagram & TikTok 설명글 3개
- Threads & X.com 설명글 3개
- Threads 주제 5개
- Threads & X.com 쿠팡 댓글용 한마디 3개

### 설명글을 플랫폼에 적용하는 방법
1. [업로드 문구 만들기]를 눌러 문구를 만듭니다.
2. 원하는 설명글 아래에 있는 YouTube, Instagram, TikTok, Threads, X.com 아이콘을 누릅니다.
3. 색이 들어오고 체크 표시가 나타나면 그 플랫폼에 적용된 상태입니다.
4. 같은 설명글을 여러 플랫폼에 함께 써도 되고, 플랫폼마다 다른 설명글을 고르셔도 됩니다.
5. 화면 아래쪽의 5개 플랫폼 적용 완료 표시로 빠진 플랫폼이 없는지 확인합니다.

### 아이콘 색과 체크 표시가 뜻하는 것
- 색이 들어오고 체크가 있다 : 지금 보고 계신 이 설명글이 그 플랫폼에 적용된 상태
- 흑백인데 체크가 있다 : 다른 설명글이 그 플랫폼에 이미 적용된 상태
- 흑백이고 체크도 없다 : 아직 아무것도 안 골라진 상태

### 인스타그램과 틱톡 설명글이 왜 하나로 묶여 있나요
두 곳은 설명글의 결이 비슷해서 같이 쓰셔도 문제가 없기 때문입니다.
심지어 YouTube 설명글을 가져다 쓰셔도 괜찮습니다.
원하시는 것을 고르시고 직접 고쳐서 쓰시는 것을 권합니다.

Threads와 X.com 설명글 3개는 그냥 만들어지는 것이 아닙니다.
Threads와 X.com에 올라온 쇼핑 글 중에서 조회수가 높은 것부터 분석해서, 그 스타일대로 만들어 드립니다.

처음 문구를 만들었을 때는 설명글이 저절로 선택되지 않습니다.
직접 플랫폼 아이콘을 눌러 적용하셔야 합니다.

YouTube 제목은 제목 목록에서 하나를 고르면 YouTube에만 적용됩니다.
Threads 주제는 Threads에만 적용됩니다.


## Threads 주제 선택

Threads에는 설명글과 별도로 게시물을 대표하는 주제를 하나 넣을 수 있습니다.

### 쓰는 방법
1. 업로드 문구 선택 화면에서 추천 주제 5개 중 하나를 누릅니다.
2. 원하는 주제가 없으면 입력 칸에 직접 적습니다.
3. 적용한 뒤 자동 업로드 화면의 Threads 내용에서 최종 문구를 확인하거나 고치시면 됩니다.

Threads 주제는 태그나 카테고리 정도로 생각하시면 됩니다.
Threads에서 글을 보시면 주제가 붙어 있는 글도 있고 아무것도 없는 글도 있는데, 그 자리에 들어가는 것입니다.

원하는 키워드를 직접 넣으셔도 되고, 아예 안 넣으셔도 됩니다. 필수가 아닙니다.
Threads 주제는 최대 50자까지 넣을 수 있습니다.
X.com에는 주제 입력 항목이 없습니다.


## 쿠팡 링크 댓글

Threads와 X.com은 영상 설명글과 별도로 쿠팡 링크를 댓글에 넣을 수 있습니다.

댓글은 아래 세 가지가 한 번에 들어가도록 만들어집니다.
1. 제품을 자연스럽게 소개하는 한마디
2. 쿠팡 파트너스 링크
3. 쿠팡 파트너스 제휴 안내 문구
   (이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다)

### 왜 본문이 아니라 댓글에 넣나요
Threads는 본문에 외부 링크가 있으면 노출을 잘 안 해준다는 이야기가 있습니다.
그래서 많은 분들이 본문에는 링크를 안 넣고 첫 번째 댓글에 답니다.
쇼핑렌즈도 그 방식에 맞춰서, 본문과 영상을 올린 뒤 첫 번째 댓글에 링크를 자동으로 답니다.

본문에 직접 링크를 넣고 싶으시면, 쿠팡 링크 댓글 칸을 비우시고 설명글 안에 넣으시면 됩니다.

### 만드는 방법
1. 업로드 문구 선택 화면에서 쿠팡 댓글용 한마디 3개 중 하나를 고릅니다.
2. 업로드 문구 선택 화면에서 사용할 쿠팡 파트너스 링크를 직접 입력합니다.
3. 고르시면 Threads와 X.com의 쿠팡 링크 댓글 칸에 문구가 들어갑니다.
4. 발행하시기 전에 각 플랫폼 화면에서 자유롭게 고치실 수 있습니다.

쿠팡 링크가 필요한 자리에 링크를 안 넣으시면 발행 전에 안내가 뜹니다.

### 댓글 포함 예약 제한 (중요)

무료 Buffer에서는 Threads와 X.com의 댓글 포함 예약을 계정별로 동시에 1개만 두실 수 있습니다.

예를 들어 같은 X.com 계정에 댓글 포함 예약이 이미 하나 있으면,
그 예약이 발행되기 전에는 같은 계정으로 댓글 포함 예약을 하나 더 넣을 수 없습니다.

이럴 때는 둘 중 하나를 하시면 됩니다.
- 쿠팡 링크 댓글 칸을 전부 지운 뒤 댓글 없이 예약하기
- 기존 댓글 포함 예약이 발행된 뒤 다시 예약하기

댓글이 없는 일반 예약은 예전처럼 계정당 최대 10개까지 넣으실 수 있습니다.

### ★ 이 제한은 예약 발행에만 해당합니다
지금 발행은 예약을 걸지 않기 때문에 이 제한과 상관없습니다. 댓글을 달아도 계속 하실 수 있습니다.

한 줄로 정리하면 이렇습니다.
- 댓글이 없으면 : 어느 채널이든 예약 발행이 채널당 10개까지
- 댓글을 쓰면 : Threads와 X.com만 예약 발행이 계정당 1개까지
- 지금 발행 : 댓글이 있든 없든 제한 없음


## 글자 수 제한

플랫폼 제한을 넘는 문구는 발행 전에 확인하실 수 있습니다.

- Threads 설명글 : 최대 500자
- Threads 쿠팡 링크 댓글 : 최대 500자
- Threads 주제 : 최대 50자

- X.com 쿠팡 링크 댓글 : X.com 계산 기준 최대 280자

280자 안으로 줄이시면 다시 원래 색으로 돌아옵니다.

쇼핑렌즈가 서버에 영상을 올리고, 그것을 다시 각 채널에 발행하기 때문입니다.
바로 안 올라간다고 잘못된 것이 아니니 잠시 기다려 주세요.

## Buffer 계정과 채널 순서 고정

프로그램을 켤 때마다 Buffer 계정이나 채널 위치가 바뀌어 헷갈리던 부분을 고쳤습니다.

## 영상 길이와 용량 사전 확인

발행 버튼을 누르면 고르신 플랫폼에 올릴 수 있는 영상인지 먼저 확인합니다.

### 영상 길이 기준
- YouTube Shorts, Instagram Reels, TikTok, Threads : 3분 이하
- X.com : 2분 이하

### 영상 용량 기준
- 5개 플랫폼 공통 : 95MB 이하

각 플랫폼이 받을 수 있는 최대 용량과는 별개로,
쇼핑렌즈가 영상을 자동으로 전달할 때 적용되는 기준입니다.
96MB 이상인 영상은 업로드를 시작하기 전에 안내창으로 알려드립니다.

제한을 넘으면 지금 영상의 길이 또는 용량과, 제한을 넘긴 플랫폼의 기준이 함께 나옵니다.

예를 들어 3분 1초 영상으로 YouTube와 X.com을 함께 고르시면 이렇게 나눠서 안내합니다.
- X.com : 2분 이하
- YouTube Shorts : 3분 이하

영상을 줄이시거나, 제한을 넘긴 플랫폼의 계정 선택을 푸시고 다시 발행하시면 됩니다.

### 안내창 제목
- 영상 길이를 넘은 경우 : 영상 길이 확인
- 영상 용량을 넘은 경우 : 영상 용량 확인
- 지금 발행 전 다른 확인이 필요한 경우 : 발행 전 확인
- 예약 전 다른 확인이 필요한 경우 : 예약 전 확인


## X.com만 2분인 이유

X.com은 원래 유료 회원이면 훨씬 긴 영상을 올릴 수 있습니다.
그런데 그건 X.com 앱이나 홈페이지에서 직접 올릴 때만 해당됩니다.

쇼핑렌즈는 Buffer를 거쳐 올립니다.
Buffer 공식 안내에 따르면 Buffer 같은 외부 도구로 X.com에 올릴 때는
유료 회원이라도 최대 140초까지만 가능합니다.

쇼핑렌즈는 여기서 조금 더 여유를 두어 120초, 즉 2분으로 정했습니다.
이유는 두 가지입니다.
- 140초에 딱 맞춰두면 영상이 아주 조금만 넘쳐도 발행이 실패합니다. 여유를 두면 한 번에 올라갑니다.
- 쇼핑렌즈는 쇼핑 쇼츠를 만드는 프로그램이라 대부분 1분 안쪽입니다. 2분이면 충분합니다.

정리하면 이렇습니다.
- X.com에 직접 올릴 때 : 유료 회원은 길게 가능
- Buffer로 올릴 때 : 최대 140초 (Buffer 공식 기준)
- 쇼핑렌즈 자동 업로드 : 120초 (실패를 줄이기 위한 여유분)

참고 : Buffer 공식 안내 https://support.buffer.com/article/561-using-twitter-with-buffer

영상을 다시 내보내시면 새로 검수합니다.

AI는 아래 다섯 가지만 확인합니다.

### 1. 워터마크나 다른 앱 표시가 보입니다
남의 계정 아이디(@로 시작하는 글자)나 TikTok, 도우인, Instagram 표시가 화면에 남아 있는 경우입니다.

### 2. 따라 하면 다칠 수 있는 행동이 나옵니다
사람이 제품 위에 올라서거나 매달리는 장면, 불을 붙이는 장면, 칼날이 사람 쪽을 향하는 장면입니다.

### 3. 병이 낫는다는 말이나 자막이 나옵니다
병 이름과 함께 낫는다, 없어진다, 예방된다 같은 표현이 나오는 경우입니다.
화면 자막뿐 아니라 음성으로 말한 내용까지 확인합니다.

### 4. 아이가 나옵니다
아이가 나오는 영상은 노출이 제한되는 경우가 있어 알려 드립니다.

### 5. 화면 문구와 소개하는 물건이 다릅니다
화면에 계속 떠 있는 문구가 실제 물건과 전혀 다른 물건을 말하는 경우입니다.
예를 들어 문구는 요거트 제조기인데 화면에는 빨래 건조대가 나오는 경우입니다.
주방 필수템 처럼 물건을 콕 집지 않는 문구는 알리지 않습니다.


## 결과 화면 보는 법

항목마다 화면에서 무엇이 보였는지가 가장 위에 큰 글씨로 나옵니다.
그 아래에 몇 초에 나왔는지와, 무엇을 하면 되는지가 적혀 있습니다.

왼쪽에 그 시점 화면이 작게 붙어 있습니다.
작은 화면을 누르시면 크게 보실 수 있습니다.
확인 화면이 네 장 이상이면 마우스 휠로 옆으로 넘겨 보실 수 있습니다.
큰 화면은 아무 곳이나 누르시면 닫힙니다.

확인할 것이 하나도 없으면 초록색 표시와 함께 확인된 항목이 없습니다 라고 나옵니다.
결과 화면 아래에는 위 내용은 참고용이고 업로드한 영상의 책임은 쇼핑렌즈가 지지 않는다는 문구가 적혀 있습니다.

### 실제로 이렇게 나옵니다
- 워터마크가 잡힌 경우 : 워터마크나 다른 앱 표시가 보입니다 라고 나오고, 1초, 8초, 10초처럼 시점이 적힙니다.
  눌러 보시면 그 시점 화면이 나옵니다. 직접 만드신 로고라면 그냥 넘어가시면 되고,
  남의 표시가 남아 있으면 그 부분을 고치시면 됩니다.
- 아이가 잡힌 경우 : 아이가 나오면 유튜브에서 노출이 제한될 수도 있다고 알려줍니다.
  눌러 보시면 어느 구간에 나오는지 확인하실 수 있습니다. 고칠지 말지는 직접 정하시면 됩니다.


## 알아 두실 점 (중요)

이 기능은 화면에 보이는 것과 소리로 들리는 것만 확인합니다.

## Vmake 자막 제거와 화질 개선 (Vmake 유료 사용자용)

Vmake는 영상 속 자막을 지워 주는 외부 유료 서비스입니다.
쇼핑렌즈의 무료 자막 지우개는 박스가 있는 자막에서 흔적이 남을 수 있는데,
그 마무리용으로 Vmake를 연결해 쓰실 수 있게 했습니다.

⚠️ Vmake에 따로 가입하고 요금제를 결제하신 분만 쓰실 수 있는 기능입니다.
  쇼핑렌즈 이용권에 포함된 것이 아닙니다.

### 어떤 경우에 쓰나요
자막 정리 탭의 쇼렌 무료 자막 제거는 앞으로도 무료 무제한입니다.
저사양 컴퓨터에서도 돌아가도록 최소화하면서 성능을 끌어낸 것입니다.

다만 자막이 크거나 화면 움직임이 많은 영상에서는 지운 자리가 울퉁불퉁하게 남을 수 있습니다.
그럴 때는 먼저 자막 블러 방식을 써 보시길 권합니다.
그래도 부족하다고 느끼시는 분들을 위해 Vmake를 붙일 수 있게 한 것입니다.

### 준비
1. Vmake에 가입하고 유료 요금제를 결제합니다.

   자막 제거와 화질 개선을 합쳐서 세는 횟수입니다.
   쇼핑 쇼츠 작업에는 Plus로도 충분합니다.
2. Vmake에서 키 두 개를 발급받습니다.
3. 쇼핑렌즈 설정의 Vmake 연동 칸에 두 키를 넣고 저장을 누릅니다.

### Vmake API 키 받는 법 (자세히)

키 받는 법 영상 : https://youtu.be/UL5pBgFxfls

#### 1) Vmake 사이트로 들어갑니다
쇼핑렌즈 설정으로 들어가서 세 번째에 있는 Vmake를 누릅니다.
가운데 Vmake 연동 항목에 있는 [Vmake에서 키 발급받기] 버튼을 누르면 Vmake로 바로 연결됩니다.
구글에 Vmake 라고 검색해서 들어가셔도 됩니다.

#### 2) 가입하고 요금제를 고릅니다

### 자막 제거 쓰는 법
1. 편집 준비 버튼을 누르면 나오는 설정 창에서 [Vmake 자막 제거] 스위치를 켭니다.
2. 평소처럼 편집 준비를 진행합니다.
3. 장면들이 한 편으로 합쳐져 Vmake로 보내지고, 자막이 지워진 영상이 돌아옵니다.
4. 미리보기부터 내보내기, 캡컷 내보내기까지 전부 그 지워진 영상으로 진행됩니다.

### ★★ 가장 많이 하는 실수 - 반드시 읽어 주세요

Vmake 자막 제거를 쓰실 거면, 자막 정리 탭에서 쇼렌 무료 자막 제거를 하지 마세요.
원본 그대로 Vmake로 보내셔야 합니다.

이유는 이렇습니다.
무료 자막 제거로 이미 지운 장면이 있으면, 그 지워진 결과가 그대로 Vmake로 갑니다.
즉 울퉁불퉁하게 지워진 화면을 보내는 것이라, Vmake를 켜도 그 자국이 그대로 남습니다.
돈만 쓰고 결과는 똑같아집니다.

이미 무료 자막 제거를 하셨다면 이렇게 되돌리시면 됩니다.
1. 자막 정리 탭으로 갑니다.
2. 지웠던 장면들을 대기 또는 원본 사용 상태로 되돌립니다.
3. 최종편집으로 가서 편집 준비를 다시 실행합니다.
4. 이때 [Vmake 자막 제거] 스위치를 켠 상태로 실행합니다.

이렇게 하시면 자막이 있는 원본이 Vmake로 가서 훨씬 깔끔하게 지워집니다.

알아두실 점입니다.
- 장면이 몇 개든 한 편으로 합쳐 한 번만 보내므로 사용 횟수는 1회만 빠집니다.
- 같은 상태로 편집 준비를 다시 누르면 보내지 않고 저장해 둔 결과를 다시 씁니다. 횟수가 안 빠집니다.
- 장면, 음성, 전환, 영상 효과를 바꾼 뒤 편집 준비를 다시 누르면 새로 보내므로 1회가 더 빠집니다.

### Vmake 화질 개선 쓰는 법
1. 최종편집의 내보내기 메뉴에서 [Vmake 화질 개선 (유료)] 스위치를 켭니다.
2. 영상 내보내기가 끝나면 완성본이 자동으로 Vmake에 보내져 화질이 좋아집니다.
3. 완성된 파일은 이름 뒤에 _V1080up 이 붙고, 원래 내보낸 파일을 대신합니다.
   앞의 V는 Vmake로 개선했다는 뜻입니다.

화질 개선은 화면 크기를 키우는 것이 아니라 뭉개진 부분을 또렷하게 만드는 기능입니다.
결과물은 원래와 같은 1080 크기로 저장되므로 용량 부담 없이 자동 업로드까지 그대로 쓰실 수 있습니다.

### 알아 두실 점
- Vmake는 하루 사용 횟수 제한이 있습니다. 요금제에 따라 하루 10회(Plus) 또는 50회(Pro)입니다. (2026년 8월 기준)
- 남은 횟수는 Vmake 사이트에 로그인하신 뒤 개발자 화면에서 확인하실 수 있습니다.
- 영상이 Vmake의 해외 서버(도쿄)로 올라갔다 옵니다.
- 지울 자리를 지정하실 수는 없습니다. 전부 자동입니다.
- 박스가 있는 자막은 흔적이 남을 수 있고, 제품 위에 자막이 겹쳐 있으면 제품이 함께 뭉개질 수 있습니다.
- 시간이 꽤 걸립니다. 26초 영상 기준으로 자막 제거에 2분 남짓 걸린 사례가 있습니다.
  화질 개선은 같은 26초 영상에 6분이 넘게 걸린 경우도 있습니다.
  컴퓨터 성능, 인터넷 속도, 그리고 Vmake 쪽이 얼마나 빨리 처리해 주느냐에 따라 크게 달라집니다.
  오래 걸린다고 고장난 것이 아니니 기다려 주셔야 합니다.


## 쇼렌 화질 개선 (무료)

Vmake 없이도 화질을 조금 더 또렷하게 만들 수 있게 했습니다.
쇼핑렌즈 안에서 처리하므로 가입도 결제도 필요 없고 사용 횟수 제한도 없습니다.

받아온 소스 영상이 화질이 나쁜 경우가 많은데, 그것을 1080으로 키워 쓰다 보니
뭉개진 채로 나가는 일이 있었습니다. 그럴 때 쓰시면 됩니다.

### 사용법
1. 최종편집의 내보내기 메뉴에서 [쇼렌 화질 개선 (무료)] 스위치를 켭니다.
2. 영상 내보내기가 끝나면 이어서 자동으로 화질 개선이 됩니다.
3. 완성된 파일은 이름 뒤에 _S1080up 이 붙고, 원래 내보낸 파일을 대신합니다.
   앞의 S는 쇼핑렌즈로 개선했다는 뜻입니다.

파일 이름만 보고도 어느 쪽으로 개선했는지 알 수 있습니다.
- 그냥 내보내기 : 프로젝트명_날짜_시간
- _S1080up : 쇼렌 화질 개선 (무료)로 만든 것
- _V1080up : Vmake 화질 개선 (유료)로 만든 것

한 번 켜 두시면 다른 프로젝트를 열거나 프로그램을 껐다 켜도 계속 켜져 있습니다.

### 알아 두실 점
- 쇼렌 화질 개선과 Vmake 화질 개선은 둘 중 하나만 켜집니다. 하나를 켜면 다른 하나가 꺼집니다.
- 20초 영상 기준으로 3초 정도 걸립니다. 오래된 컴퓨터에서는 15초 정도 걸릴 수 있습니다.
- 화면 크기는 그대로 1080입니다. 커지지 않습니다.
- 용량이 15% 정도 늘어납니다. 20MB짜리가 23MB 정도가 됩니다.
- 화질 개선 뒤 용량이 95MB를 넘으면 자동 업로드를 쓰실 수 없습니다. 그때는 안내해 드립니다.
- 저장 공간이 모자라면 화질 개선을 건너뛰고 내보내기만 마칩니다.
- 화질 개선이 실패하더라도 내보낸 영상은 그대로 남습니다. 영상이 없어지지 않습니다.

### Vmake 화질 개선과 무엇이 다른가

성격이 조금 다릅니다.
- 쇼렌 화질 개선 : 잡티를 없애고 선명도를 높입니다.
- Vmake 화질 개선 : 좀 더 쨍하면서 선명하게 만듭니다.

⚠️ Vmake가 유료라고 해서 항상 더 좋은 것은 아닙니다.
  실제로 비교해 보면 두 가지가 비슷한 경우가 많습니다.
  장면에 따라서는 쇼렌 무료 쪽이 더 선명하게 나오기도 합니다.
  천 같은 재질에서는 Vmake가 깨끗하긴 하지만 약간 뭉개지는 경향도 있습니다.

속도와 비용은 차이가 큽니다.
- 쇼렌 : 무료, 20초 영상에 3초 정도
- Vmake : 유료, 26초 영상에 6분 넘게 걸린 경우도 있음

그래서 대부분은 쇼렌 무료로 충분합니다.
Vmake를 이미 쓰고 계시거나 더 쨍한 느낌을 원하실 때 Vmake를 골라 보세요.

원본 소스가 이미 화질이 좋다면 두 스위치를 다 끄고 내보내셔도 됩니다.

## 도구 탭의 자동 업로드

도구 탭에 자동 업로드가 새로 생겼습니다.
쇼핑렌즈로 만들지 않은 영상도 여러 채널에 한 번에 올리거나 예약하실 수 있습니다.

### 사용법
1. 도구 탭에서 [자동 업로드] 카드를 누릅니다.
2. [📁 불러오기] 버튼으로 영상을 고르시거나, 영상 파일을 화면에 끌어다 놓으시면 됩니다.
   끌고 들어오시면 화면에 놓는 자리가 표시됩니다.
3. [✨ 업로드 문구 만들기]를 누르면 AI가 영상을 직접 보고 제목과 설명글을 만들어 줍니다.
4. 계정을 고르고 지금 발행 또는 예약 발행을 누릅니다.

작업실의 문구 만들기와 다른 점이 있습니다.
작업실에서는 대본을 토대로 만들고, 도구 탭에서는 영상 자체를 분석해서 만듭니다.
그래서 시간이 다소 걸릴 수 있습니다.
대신 화면에 보이는 것과 소리로 들리는 말을 근거로 만들기 때문에 대본이 없어도 됩니다.

### 알아 두실 점
- 작업실의 자동 업로드는 지금까지처럼 그 프로젝트의 완성 영상 전용입니다.
- 자동 업로드는 95MB 이하 영상만 보낼 수 있습니다.
  넘는 영상은 안내가 뜨며, 그 영상은 각 채널에 직접 올려 주셔야 합니다.
- 작업실과 도구 양쪽 모두 화면 위쪽에 지금 업로드될 파일 이름과 용량이 표시됩니다.
  95MB 이하면 초록색, 넘으면 빨간색으로 나옵니다.


## 그록 화면 변경 대응

그록이 8월 말에 화면 구성을 또 바꾸면서 AI 영상 만들기가 중간에 멈추는 문제가 있었습니다.

- 그록에서 화질 개선 단계가 없어져서, 그 단계를 기다리다 멈추는 일이 없게 정리했습니다.
- 생성이 오래 걸릴 때 너무 일찍 실패로 판정하던 것도 여유 있게 고쳤습니다.

프로그램과 확장앱을 최신으로 업데이트하시면 자동으로 반영됩니다.
앞으로도 그록은 화면 변경이 잦을 것으로 예상되니 참고 부탁드립니다.
